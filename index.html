Self-hosted media server

Your media. Your library. Your Phlix.

An open-source PHP media server that streams to your Roku, Samsung TV, Windows desktop, phone, and any DLNA device — with SyncPlay, Live TV, transcoding, and a hub that follows you anywhere.

Get Phlix Read the docs

Free and open source — server and hub under MPL-2.0, shared libraries, plugins and clients under MIT. Run Phlix on your own hardware.

  • 100% self-hostable — your library never leaves your hardware unless you say so
  • Real-time SyncPlay with NTP-style time sync so movie night actually stays in sync
  • Adaptive HLS streaming, FFmpeg transcoding, per-device quality profiles
  • Plugin system with a versioned manifest contract

Install Phlix

One line, on a fresh Ubuntu or Debian host

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

PHP 8.3+, MySQL, ffmpeg. The installer targets a fresh Ubuntu/Debian host and also compiles the Swoole and php-uv extensions from source, skipping the build when they already load.

Prompts for install path, database credentials and hostname when run in a terminal; runs fully unattended when piped or given -y. Default ports: HTTP on :8096 behind HAProxy on :80/:443, DLNA discovery on 1900/udp.

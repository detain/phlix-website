Download

Self-host in minutes. One line on Ubuntu or Debian.

Server

PHP 8.3+, MySQL, FFmpeg. The installer targets a fresh Ubuntu/Debian host.

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

This installs system packages, creates a dedicated phlix system user, a MySQL database, an env file at /etc/phlix/env, runs database migrations, and sets up a systemd service with HAProxy and Let's Encrypt.

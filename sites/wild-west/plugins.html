Plugins

Extend Phlix with a versioned plugin contract — drop in, the loader picks it up.

Plugin Model

Every plugin implements LifecycleInterface and ships a manifest. Drop the plugin folder into plugins/ and Phlix auto-loads it.

1. Create

Implement LifecycleInterface

2. Manifest

Ship manifest.json with version, name, events

3. Drop in

Place in plugins/ directory

4. Go

Loader auto-discovers and activates

{
  "name": "my-metadata-provider",
  "version": "1.0.0",
  "events": ["metadata.scan", "metadata.resolve"],
  "class": "MyMetadataProvider\\Plugin"
}

Server

PHP 8.3+, MySQL, FFmpeg required. The installer handles everything on Ubuntu or Debian.

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

Prompts for install path, database credentials and hostname when run in a terminal; runs fully unattended when piped or given -y. Default ports: HTTP on :8096 behind HAProxy on :80/:443, DLNA discovery on 1900/udp.

Full install docs →

Provision HTTPS

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh \
  | sudo bash -s -- --domain phlix.example.com --admin-email you@example.com

Build from source (development)

git clone https://github.com/detain/phlix-server.git
cd phlix-server
composer install

This is a development checkout only. It does not create a database, a service, or run migrations.

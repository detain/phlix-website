Three Steps to Blooming

A warm, illustrated preamble about planting: the server is the soil, the clients are the seeds you choose, and your library is what grows.

Step one — prepare the soil

Plant the server

One line, on a fresh Ubuntu or Debian host. The installer handles everything — PHP 8.3+, MySQL, ffmpeg, a dedicated system user, the database, environment setup, migrations, and a systemd service. It even provisions HTTPS with Let's Encrypt.

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash
  • → Prompts for install path, database credentials and hostname; runs fully unattended with -y
  • → Default: HTTP :8096 behind HAProxy on :80/:443, DLNA discovery on 1900/udp
  • → Requirements: PHP 8.3+, MySQL, ffmpeg
  • → Full installation docs →

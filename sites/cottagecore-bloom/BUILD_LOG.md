## Deviations and judgement calls

All resolved under §19.6 and recorded in `REGEN_PLAN.md` §5. Summary:

1. **Contrast (§19.1).** The kit's claimed 4.8:1 for Garden Rose on Warm Ivory
   measures **4.02:1**; Sage Green is 2.88:1 and Warm Taupe 2.41:1. Six derived
   ink tokens (kit pigment ⊕ kit Bark Brown) now carry all small coloured text
   and the primary button fill. Pure hues keep display type, rules, borders and
   glows. Full table in `SITE.md`.
2. **Two vs three download steps.** `page_blueprints.download.spec` says "two";
   `conversion_funnel.cta_ladder` and `download_opening` say three. The
   structured field is the authority for counts — three steps ship.
3. **`scroll_experience` sepia → saturate.** `sepia()` shifts luminance;
   `saturate(0.72)` does not. §12 wins over a field.
4. **Two `click:5` eggs.** Topbar sigil ×5 = petal shower + reward copy;
   Primrose ×5 = loop-de-loop curtsy. Different targets, both shipped (§19.8).
5. **Primrose is hidden below 720px.** The kit places her bottom-right with
   anchored tips and also says "never push unrequested tips on a phone" — at
   320px both cannot be true without covering the CTA (§19.11). Below 720px she
   appears only as inline illustration (hero diorama, 404).
6. **`proof_strategy` "quotes-from-docs"** is quoted from `content.json`'s FAQ
   answer, not from an unverifiable sentence in `phlix-docs` (§19.7). No star
   counts, download totals or testimonials appear anywhere.
7. **Docs sub-page URLs are not invented.** The old build and the pilot each
   invented four different `phlix-docs` paths. Only the two URLs that exist in
   `content.json` are linked; the four documentation sections are described in
   prose beside the one canonical link.
8. **Mascot tip anchors.** The kit names `home:#hero`; the home hero's `id` is
   `gate-opens` because `homepage_narrative` owns the section ids, so the tip is
   anchored to `.hero` on the same element. `features:.feature-grid`,
   `download:#server` and `about:.faq-list` are matched **exactly** — the
   features room-tour container carries `class="room-tour feature-grid"` for
   that reason.
9. **`sound_identity` not implemented** — autoplaying audio on a marketing page
   is a WCAG 1.4.2 hazard. Recorded in `SITE.md` as identity instead.
10. **Header is not sticky.** `navigation_model` asks for a topbar, not a sticky
    one, and every fixed/sticky element is another way to cover the primary CTA.

## Two render-only defects inherited from the predecessor

Both were invisible to source review and both were found by `render-check`:

1. **The old `body` had no `background-color` at all.** The "warm ivory" kit
   therefore shipped on browser-default white, and the contrast probe resolved
   every text element's backdrop to transparent-black, reporting 27 phantom
   "1.25:1" failures. Fixed with an explicit opaque `background-color` on both
   `html` and `body`; the linen texture uses the `background-image` longhand so
   the colour survives.
2. **`render-check`'s contrast probe ignores alpha**, so the old active nav link
   (`background: rgba(200,85,106,.1)` with `color: #C8556A`) measured 1.00:1.
   Adopted site-wide: no semi-transparent background behind text.

Also corrected from the predecessor: the home JSON-LD claimed
`license: BSD-3-Clause`, which is factually wrong — it is now MPL-2.0 per
`content.json`. The `url(%23n)` reference in the old `components.css` (an
unresolvable CSS `url()`) is gone; the only `url()` left anywhere is the ten font
faces.

## Two 200%-zoom traps worth passing on

`render-check`'s reflow pass sets the root font-size to 32px at a 320px viewport.
Two things failed there and neither is obvious:

1. **`.visually-hidden` needs `overflow: hidden`.** The `clip-path: inset(50%)`
   recipe hides the text visually but does **not** stop it contributing to
   `document.scrollWidth` — a `white-space: nowrap` heading in a 1px box reported
   ~520px of overflow.
2. **`overflow-wrap: break-word` is not enough; use `anywhere`.** Only
   `anywhere` lowers an element's **min-content** size, and min-content is what
   makes a grid or flex track refuse to shrink. A single token like
   `ContentDirectory,` widened a features-page track to 345px. Neither value
   breaks a word that fits, so normal rendering is identical.

## Known follow-ups

- `render-check.mjs` `parseRgb` drops the alpha channel, so any site that
  legitimately tints a surface with `rgba()` gets a false FAIL. Escalated in
  `REGEN_PLAN.md` §6, not changed (`tools/**` is read-only to this build).
- `selfcheck.mjs` resolves every CSS `url()`, including same-document SVG
  fragment refs like `url(#gradient)`, which can never resolve on disk. Worked
  around by using no `url()` other than the font faces.
- `shared/content.json` `meta.og_image` is `/img/og.svg` — an SVG and an absolute
  path, both of which every site has to ignore. Escalated, not changed.
- `render-check` covers no `extra_pages`; a `--pages` flag or a glob would make
  kit-declared extra pages gateable.

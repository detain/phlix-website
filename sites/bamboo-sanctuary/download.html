Download

Phlix is MPL-2.0 and MIT, open source. The server runs on Linux, macOS, or any system with PHP 8.3+.

Becoming the Gardener

One line, on a fresh Ubuntu or Debian host. Installs PHP 8.3+, MySQL, ffmpeg, creates a dedicated phlix system user, a MySQL database, an env file, runs migrations, and sets up a systemd service. 

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

Default ports: HTTP on :8096 behind HAProxy on :80/:443, DLNA discovery on 1900/udp. Full docs →

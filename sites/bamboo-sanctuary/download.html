Download

Phlix is BSD-3-Clause, open source. The server runs on Linux, macOS, or any system with PHP 8.3+.

Server

phlix-server

Requires PHP 8.3+ and Workerman 5.x. 

composer require detain/phlix-server
# or clone directly from GitHub
git clone https://github.com/detain/phlix-server.git
cd phlix-server
composer install
php start.php start

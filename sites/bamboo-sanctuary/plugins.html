Plugins

A real contract, not a suggestion. Implement LifecycleInterface, ship a manifest, drop it in the plugins directory.

The plugin model

1

Create a manifest

A manifest.json declares your plugin's name, version, and the services it provides. The loader reads it on startup.

2

Implement LifecycleInterface

Your plugin class implements LifecycleInterface: onInstall(), onEnable(), onDisable(), onUninstall(). Each is called at the right moment — no polling, no guessing.

3

Drop it in

Place your plugin folder under plugins/. The autoloader discovers it, the loader verifies the manifest, and the lifecycle hooks fire in order. 

{
  "name": "my-metadata-provider",
  "version": "1.0.0",
  "entry": "MyMetadataProvider.php",
  "services": ["metadata.provider"]
}

About

A media server that gets out of the way — built for people who choose what they watch and press play with intention.

Philosophy

Phlix was built on the belief that your media library is yours. Not a platform's. Not an algorithm's. Yours. Every design decision — from the way SyncPlay keeps movie night in sync, to the Hub that connects you to your server without exposing it — serves that one idea: the experience should feel like settling into a room you chose, not navigating a storefront.

Phlix is open source under BSD-3-Clause. The server is PHP 8.3+. The clients are native. The Hub can be self-hosted or skipped entirely. Nothing is locked in.

License

BSD-3-Clause across the board. Phlix server, all official clients, the Hub, and the documentation are freely available for personal and commercial use. There is no hidden license, no trial, no telemetry.

Contributing

All Phlix projects live under the detain GitHub organization. Issues, pull requests, and plugin contributions are welcome. If you want to write a client for a new platform or extend the plugin system, the reference implementations in the ecosystem are the place to start.

FAQ

Is Phlix like Plex / Jellyfin / Emby?
Yes — same job, different stack. Phlix is built in PHP 8.3+ on Workerman, ships with a versioned plugin contract, and includes a hub for accessing remote servers behind NAT without a third-party tunnel.
Do I need to expose my server to the internet?
No. Run Phlix on your LAN and use the Phlix Hub's reverse-tunnel relay to reach it from your phone or Roku at a friend's house. You can self-host the hub, or use the public one.
What formats are supported?
Anything FFmpeg can read. Direct play when the client supports it; transcoded HLS otherwise. Per-device quality profiles pick the right bitrate automatically.
Is there a mobile app?
Yes — React Native, available on iOS and Android. Currently in beta.
Can I write plugins?
Yes. Implement LifecycleInterface, ship a manifest, drop it in the plugins directory. See phlix-plugin-example for the smallest working starter.

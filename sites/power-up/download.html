Download

Self-host your media in minutes. One line on Ubuntu or Debian.

Install the server

Requires: PHP 8.3+, MySQL, ffmpeg. The installer targets a fresh Ubuntu/Debian host and also compiles the Swoole and php-uv extensions from source, skipping the build when they already load.

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

Installs system packages, creates a dedicated phlix system user, a MySQL database and user, an env file at /etc/phlix/env, runs database migrations, installs a systemd phlix-server service, and sets up HAProxy with Let's Encrypt.

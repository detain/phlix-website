Our Story

An altar built by the community, for the community. Phlix is the conviction that your media should live on hardware you own, under rules you set.

The conviction

The best library is the one you built. The best watching experience is the one you control. Phlix exists because the alternative — renting access to your own media through someone else's server, on someone else's terms, with someone else's rules — is an altar that isn't yours.

Phlix is open source because the point is not to own the software — it is to own the server that runs it. Every line of code is public. Every protocol is documented. You can audit it, fork it, extend it, or host it for your family without asking permission.

License

Phlix Server and the Hub are MPL-2.0 — open source, and you can build on them commercially. If you modify a Phlix file, that file stays open; anything you add alongside it is yours. The shared libraries, plugins, and clients are MIT so you can build on them freely.

MPL-2.0 is weak copyleft. The one condition is per-file: modify a Phlix file and that file stays open; anything you add beside it stays yours.

Contributing

All development happens on GitHub. Issues, pull requests, and plugin submissions are welcome. The detain GitHub org hosts the server, hub, all clients, the shared libraries, and the documentation.

Start with phlix-plugin-example if you want to write a plugin. Start with phlix-server if you want to touch the core.

Frequently asked

Is Phlix like Plex / Jellyfin / Emby?
Yes — same job, different stack. Phlix is built in PHP 8.3+ on Workerman, ships with a versioned plugin contract, and includes a hub for accessing remote servers behind NAT without a third-party tunnel.
Do I need to expose my server to the internet?
No. Run Phlix on your LAN and use the Phlix Hub's reverse-tunnel relay to reach it from your phone or Roku at a friend's house. You can self-host the hub, or use the public one.
What formats are supported?
Anything FFmpeg can read. Direct play when the client supports it; transcoded HLS otherwise. Per-device quality profiles pick the right bitrate automatically.
Is there a mobile app?
Yes — React Native, available on iOS and Android. Currently in beta.
Can I write plugins?
Yes. Implement LifecycleInterface, ship a manifest, drop it in the plugins directory. See phlix-plugin-example for the smallest working starter.

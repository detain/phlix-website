Prepare the Altar

Requires a host running Ubuntu or Debian. The installer handles PHP 8.3+, MySQL, FFmpeg, the systemd service, and an HAProxy reverse proxy with auto-renewing Let's Encrypt certificate. 

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

Installs PHP 8.3+, MySQL and FFmpeg, creates the phlix system user and database, registers the systemd service, and sets up HTTPS — on a fresh Ubuntu or Debian host. Default ports: HTTP on :8096 behind HAProxy on :80/:443, DLNA discovery on 1900/udp.

Full install guide View source
Not an install — build from source instead

For development: git clone https://github.com/detain/phlix-server.git && cd phlix-server && composer install. This does not create a database, a service, or run migrations. It is a development checkout only — never present it as the way to install Phlix.

Set Camp (Install) Install the Server

One line, on a fresh Ubuntu or Debian host

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

Installs PHP 8.3+, MySQL, ffmpeg, creates a dedicated phlix system user, sets up a MySQL database, runs migrations, and starts a systemd service with an auto-renewing Let's Encrypt certificate via HAProxy. Prompts for install path, database credentials, and hostname when run in a terminal; runs fully unattended with -y.

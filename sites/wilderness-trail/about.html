Chapter I — The philosophy

Why Phlix exists.

The first ranger station at the trailhead opened with a hand-painted wooden sign, a pot of coffee, and a topographic map pinned above the door. Visitors arrived with dusty boots and wide eyes, having crossed granite passes, forded snowmelt creeks, and slept under more stars than they had ever counted. The trail asked something of them; they gave it freely and came back changed.

Phlix carries that same invitation indoors. Your media collection is the terrain — every film, series, or album a different route through country worth knowing. Press play and start walking.

You own the hardware. The server runs on a box you plug in, in a closet you control. No subscription, no tracking, no content routed through someone else's business.

You own the software. Open-source means the code is yours to audit, fork, modify, and extend. If Phlix doesn't do something you need, you can add it.

The library stays yours. Your watch history, your ratings, your profile data — all of it lives on your server. The Hub relay connects you to it remotely, but the data never leaves your hardware unless you put it there.

Chapter II — The licence

What "open source" actually means here.

Phlix Server and the Hub are MPL-2.0. Open source, and you can build on them commercially. If you modify a Phlix file, that file stays open. Anything you add alongside it is yours. The one condition is file-level: modify a Phlix file and that file stays open.

The shared libraries, plugins, and clients are MIT. So you can build on them freely, without the file-level copyleft. Use them in proprietary plugins if you want.

MPL is weak copyleft — it is not "no strings attached" (that's MIT), and it is not "share-alike everything" (that's GPL). It is file-level: touch a Phlix file, that file stays open. Build a proprietary plugin alongside it, that's fine.

Full licence text: https://github.com/detain/phlix-server/blob/master/LICENSE

Scout's Q&A

Questions from the trailhead.

Is Phlix like Plex / Jellyfin / Emby?

Yes — same job, different stack. Phlix is built in PHP 8.3+ on Workerman, ships with a versioned plugin contract, and includes a hub for accessing remote servers behind NAT without a third-party tunnel.

Do I need to expose my server to the internet?

No. Run Phlix on your LAN and use the Phlix Hub's reverse-tunnel relay to reach it from your phone or Roku at a friend's house. You can self-host the hub, or use the public one.

What formats are supported?

Anything FFmpeg can read. Direct play when the client supports it; transcoded HLS otherwise. Per-device quality profiles pick the right bitrate automatically.

Is there a mobile app?

Yes — React Native, available on iOS and Android. Currently in beta.

Can I write plugins?

Yes. Implement LifecycleInterface, ship a manifest, drop it in the plugins directory. See phlix-plugin-example for the smallest working starter.

What's the licence?

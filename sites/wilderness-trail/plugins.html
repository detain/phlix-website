Plugin Tools

Tools for the seasoned scout.

A versioned manifest contract. Implement LifecycleInterface, ship a manifest, drop it in the plugins directory. The loader picks it up.

The contract

Versioned. Documented. Stable.

The plugin manifest declares the plugin's identity, version, and lifecycle hooks. The loader validates it before touching anything.

{
  "name": "my-metadata-provider",
  "version": "1.0.0",
  "manifest": "1.0",
  "lifecycle": {
    "onEnable": "enable",
    "onDisable": "disable"
  },
  "provides": ["metadata-provider"],
  "requires": {
    "phlix": ">=2.0.0",
    "php": ">=8.3"
  }
}

LifecycleInterface

Implement onEnable and onDisable hooks. The loader calls them at the right moments in the server lifecycle.

Manifest schema

A JSON manifest with versioned schema. The loader rejects plugins whose manifest it can't parse — no partial loads.

Plugin discovery

Drop a plugin directory into plugins/. The scanner finds it, validates the manifest, and registers it on the next startup.

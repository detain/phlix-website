Getting Started

Your first expedition.

Lace up, pick your trail, and get to camp. This walkthrough takes you from a fresh install to your first watch session.

First Expedition Guide

Waypoint 1 — Set up camp

Open the ranger station.

Run the install script on a fresh Ubuntu or Debian host. It handles everything:

One line, on a fresh Ubuntu or Debian host

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

Once it's done, your server is at http://your-host:8096 (or :80/:443 with HTTPS if you passed --domain). Create your first admin account in the web UI.

Waypoint 2 — Stock the pantry

Add your media.

Phlix watches folders you point it at. Drop files into a directory, tell Phlix where it lives via the web UI under Library → Add a path. The scanner picks up S01E02 episode naming, (2020) movie title formats, and pulls metadata from TMDB, TVDB, and Fanart.tv.

The folder-watcher hashes mtimes on change, so new files appear automatically.

Waypoint 3 — Brief the household

Set up user profiles.

Phlix supports up to 5 profiles per user, each with its own watchlist, rating history, and continue-watching position. Add PIN protection to restrict content ratings.

Parental controls accept a rating filter from G to NC-17. Set it once, and each profile is gated independently.

Waypoint 4 — Pick your outpost

Choose how you watch.

Install the app for your main viewing device. Each client is a separate outpost — they all reach the same library.

Roku Samsung Tizen Windows Mobile (beta)

Or use any DLNA device — no app install needed. Smart TV from the last decade? It probably works out of the box.

Waypoint 5 — Find the high ground

Try SyncPlay.

Start a SyncPlay session on a movie. Share the room code with a second user, anywhere in the world. Play, pause, seek — everyone moves together. The weighted-mean NTP offset over 5 samples keeps every device locked to the same frame.

No account linking, no setup dance. One person hosts, shares the code, and everyone joins.

Waypoint 6 — Keep exploring

The trail goes on.

Live TV + DVR, plugins, Hub relay for remote access, per-device transcoding profiles — the waypoints are all documented on the docs site.

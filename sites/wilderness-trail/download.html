Ranger Station

Three steps to camp.

The ranger station opens with one line. Pick your outpost after. Set up your relay when you're ready.

Step one

Open the ranger station.

Run this on a fresh Ubuntu or Debian host. PHP 8.3+, MySQL, and ffmpeg install automatically. One line.

One line, on a fresh Ubuntu or Debian host

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

Installs system packages (PHP 8.3+, MySQL, ffmpeg), creates a dedicated phlix system user, a MySQL database and user, an env file at /etc/phlix/env with a generated PHLIX_SECRET_KEY, runs database migrations, installs a systemd phlix-server service, and sets up an HAProxy reverse proxy with an auto-renewing Let's Encrypt certificate. Prompts for install path, database credentials, and hostname in a terminal; runs fully unattended with -y. Default ports: HTTP on :8096 behind HAProxy on :80/:443, DLNA discovery on 1900/udp.

Full install docs
Show: Provision HTTPS in the same run
curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh \ | sudo bash -s -- --domain phlix.example.com --admin-email you@example.com

Adds --domain and --admin-email to provision a Let's Encrypt certificate in the same run.

Show: Build from source (development)
git clone https://github.com/detain/phlix-server.git cd phlix-server composer install

This is a development checkout only. It does not create a database, a service, or run migrations. Never present it as the way to install Phlix.

Step two

Choose your outpost.

Pick the app that fits your main viewing device. All of them reach the same library.

Roku

Samsung Tizen

Windows

Desktop app, Electron, Hub mode

iOS + Android, offline downloads

Or use any DLNA device — no app install needed.

Step three (optional)

Set up your relay.

The Hub relay lets you reach your server from outside your network — without opening ports. Self-host it or use the public relay.

Use the public relay

No configuration. Sign in at phlix-hub and point your server at it.

Learn about Hub

Self-host the relay

Run phlix-hub on your own VPS. Full control, no third-party relay.

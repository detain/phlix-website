Plugins

A versioned contract. Drop a plugin in, the loader picks it up.

Plugin model

Every plugin implements LifecycleInterface and ships a manifest. The loader scans the plugins/ directory at startup, validates the manifest schema, and registers the plugin's hooks. 

plugins/
└── my-plugin/
    ├── manifest.json    # version, name, hooks, dependencies
    ├── Plugin.php       # implements LifecycleInterface
    └── assets/          # optional static files

Ecosystem plugins

The plugin ecosystem is growing. Browse the phlix-plugin-example to get started, then check the docs for the full plugin API.

  • Metadata providers (TMDB, TVDB, Fanart.tv)
  • Channel integrations
  • Custom transcoding profiles
  • Authentication backends

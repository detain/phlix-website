One command to install. Works on Ubuntu and Debian.

Phlix Server

PHP 8.3+, MySQL, FFmpeg. The installer handles everything — packages, database, systemd service, and HTTPS with Let's Encrypt.

PHP 8.3+ required Ubuntu / Debian MPL-2.0 
curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

One line, on a fresh Ubuntu or Debian host. Installs system packages, creates database, sets up systemd service, and provisions HTTPS with Let's Encrypt.

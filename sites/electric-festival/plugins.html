Plugins

Extend Phlix with a versioned plugin contract — LifecycleInterface + manifest schema.

Plugin model

Every plugin implements LifecycleInterface and ships a manifest.json. Drop the plugin into plugins/ and the loader picks it up automatically.

How it works

1

Implement LifecycleInterface

Define onEnable, onDisable, and any event handlers.

2

Create manifest.json

Declare name, version, dependencies, and entry point.

3

Drop into plugins/

The loader discovers and activates your plugin on startup.

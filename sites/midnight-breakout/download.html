Download

Install the server, grab a client, start streaming. One line gets you everything.

Server

Requires PHP 8.3+ and MySQL. The installer targets a fresh Ubuntu/Debian host. Full requirements.

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

One line, on a fresh Ubuntu or Debian host. Installs system packages (PHP 8.3+, MySQL, ffmpeg), creates a dedicated phlix system user, a MySQL database and user, an env file at /etc/phlix/env with a generated PHLIX_SECRET_KEY, runs database migrations, installs a systemd phlix-server service, and sets up an HAProxy reverse proxy with an auto-renewing Let's Encrypt certificate. Prompts for install path, database credentials and hostname when run in a terminal; runs fully unattended when piped or given -y.

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh \ | sudo bash -s -- --domain phlix.example.com --admin-email you@example.com

Provision HTTPS in the same run. Prompts for everything else.

Plugins

The versioned plugin contract that makes extending Phlix feel like unlocking a door — not picking a lock.

Plugin Model

Every plugin implements LifecycleInterface and ships a manifest. Drop it in the plugins/ directory and the loader picks it up automatically. No config files, no registration calls — the manifest is the contract.

// See the reference plugin: github.com/detain/phlix-plugin-example

Ecosystem Plugins

The plugin contract makes it easy to add metadata providers, transcode pipelines, or anything you can imagine. If you can write PHP, you can extend Phlix.

Metadata providers tap into the TMDB/TVDB/Fanart.tv source chain. Transcode pipelines can intercept the quality selection and re-encode on the fly. There's no built-in ceiling on what a plugin can touch.

Write Your Own

Start from phlix-plugin-example for the smallest working starter. It shows the manifest format, the LifecycleInterface implementation, and the minimal bootstrap to get a plugin recognized by the loader.

The manifest declares the plugin name, version, and PHP compatibility range. The LifecycleInterface gives Phlix hooks into enable, disable, and shutdown. Everything else is up to you.

Plugins

Drop a plugin in, the loader picks it up. LifecycleInterface + manifest schema — no fork needed.

How it works

Versioned Manifest

Every plugin ships with a manifest.json. The loader validates the contract version before loading. Your plugins won't break on server upgrades.

Lifecycle Hooks

onEnable, onDisable, onScan, onTranscode — the server calls your plugin at the right moment. No polling, no hacks.

Starter template

The phlix-plugin-example repo has the full annotated template.

git clone https://github.com/detain/phlix-plugin-example.git
cd phlix-plugin-example
# Edit manifest.json and src/MyPlugin.php
# Drop the whole directory into your Phlix plugins/ folder
php biny plugins:scan

Available hooks

onEnable / onDisable
Called when the plugin is activated or deactivated. Use for setup and teardown.
onScan
Called after every library scan. Receive the full list of new/changed items.
onTranscode
Called before and after transcoding. Inject your own quality tweaks or format handlers.
onPlaybackStart
Called when a user starts playing something. Hook in SyncPlay events, analytics, or parental controls.

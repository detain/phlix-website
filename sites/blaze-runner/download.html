Server, clients, and source — all free and open. The install takes under five minutes.

Server

Requires PHP 8.3+, MySQL 8+, and a web server. Clone, configure, install.

git clone https://github.com/detain/phlix-server.git
cd phlix-server
composer install
cp config/app.sample.php config/app.php
# Edit config/app.php with your database credentials
php biny install

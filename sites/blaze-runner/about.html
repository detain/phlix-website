The story

About Phlix

Open-source software that puts you in control of your media. No subscriptions, no cloud lock-in, no ads.

Philosophy

Phlix exists because media servers shouldn't require a monthly fee and a cloud account to work. Your library is yours. Your server is yours. The software should stay out of the way and just work.

We build for the person who has a NAS in a closet, a Plex-shaped hole in their budget, and enough technical comfort to run a web server. That's the audience. Everything is calibrated to that person.

FAQ

Is Phlix a replacement for Plex?
Phlix has a different scope. It covers library management, SyncPlay, transcoding, Live TV, and DLNA — the core features. It doesn't try to match every Plex feature. If you need something specific, open an issue or write a plugin.
Does Phlix expose my server to the internet?
Only if you enable Hub or manually configure port forwarding. By default, Phlix is local-only. Hub is opt-in and end-to-end encrypted.
What formats does Phlix support?
Through FFmpeg, virtually everything. Video: H.264, H.265/HEVC, VP9, AV1. Audio: AAC, MP3, FLAC, DTS, Dolby Atmos. Subtitles: SRT, ASS/SSA, VOBSUB, burn-in, and external.
Is there a mobile app?
Android and Android TV are stable. iOS/iPadOS is in TestFlight beta. External player mode on iOS uses the device's native playback for any codec.
Can I use Phlix without an account?
On your local network, yes — DLNA works without any auth. For multi-user, profiles, and Hub, accounts are required. Local accounts on your own server — no cloud dependency.

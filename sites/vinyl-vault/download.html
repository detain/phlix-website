Self-host Phlix on your own hardware. One line to install, no credit card required.

Phlix Server

Requires PHP 8.3+, MySQL, and ffmpeg. Install on a fresh Ubuntu or Debian host.

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

Installs system packages, creates a dedicated phlix system user, MySQL database, env file at /etc/phlix/env, runs migrations, sets up systemd service, and configures HAProxy with Let's Encrypt.

Download

Install Phlix on your own server. One line, on a fresh Ubuntu or Debian host.

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

Server

Phoenix is built on PHP 8.3+ and Workerman 5.x. The installer sets up system packages, a dedicated phlix user, MySQL database, environment configuration, systemd service, and HAProxy with Let's Encrypt.

Requirements: PHP 8.3+, MySQL, ffmpeg. Targets a fresh Ubuntu/Debian host.

One line install

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

Installs system packages, creates database, runs migrations, sets up systemd service and HAProxy with auto-renewing Let's Encrypt certificate.

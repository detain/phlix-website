Plugins

Extend Phlix with a versioned plugin contract. No fork required.

Plugin model

Phlix plugins implement LifecycleInterface and ship a manifest. Drop the plugin into the plugins/ directory and the loader picks it up automatically.

The manifest declares:

  • Plugin name and version
  • Phlix version compatibility
  • Extension points (metadata providers, player backends, etc.)
  • Any dependencies

The loader handles install, enable, disable, and uninstall lifecycle events — so your plugin code stays focused on what it actually does.

Example manifest

{
  "name": "my-metadata-provider",
  "version": "1.0.0",
  "phlix": {
    "version": ">=1.0.0",
    "extension": "metadata-provider"
  }
}

See phlix-plugin-example for a complete working reference.

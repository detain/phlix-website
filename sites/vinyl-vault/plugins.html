Plugins

Extend Phlix with a versioned plugin contract. Drop in a plugin, the loader picks it up.

Plugin Model

Phlix plugins implement the LifecycleInterface and ship a manifest.json. Drop the plugin directory into plugins/ and Phlix automatically discovers, initializes, and manages it.

The contract is versioned — plugins declare their compatible Phlix version range — so upgrades won't break your extensions.

Ecosystem Plugins

Browse community and reference plugins on GitHub. The phlix-plugin-example repository demonstrates a minimal working metadata-provider plugin.

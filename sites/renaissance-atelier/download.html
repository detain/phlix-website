Three brush strokes to the studio

The first stroke is the server install — the foundation everything else rests on. The second is choosing your clients. The third is lighting the lamp.

1 The Server — your foundation

Requires a fresh Ubuntu or Debian host. PHP 8.3+, MySQL, and FFmpeg are installed automatically. The installer also compiles Swoole and php-uv from source, skipping the build when they already load.

One line, on a fresh host

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

This installs system packages, creates a dedicated phlix system user, a MySQL database and user, an env file at /etc/phlix/env with a generated PHLIX_SECRET_KEY, runs database migrations, installs a systemd service, and sets up HAProxy with auto-renewing Let's Encrypt — all in one run.

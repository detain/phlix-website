Plugins

A versioned contract. Implement the interface, ship a manifest, drop it into the plugins directory — the loader picks it up from there.

The plugin contract

Phlix plugins implement LifecycleInterface and provide a versioned manifest. The loader reads the manifest on startup, validates the contract version, and integrates the plugin without any further configuration.

Minimal plugin structure

plugins/
  my-plugin/
    manifest.json     # name, version, contract version, author
    src/
      MyPlugin.php    # implements LifecycleInterface

LifecycleInterface

The core interface every plugin must implement. It covers initialization, startup, shutdown, and configuration retrieval — the full lifecycle of a plugin within the Phlix runtime.

See phlix-plugin-example for a complete, annotated reference implementation that covers every method and hook.

Manifest schema

manifest.json

{
  "name": "my-metadata-provider",
  "version": "1.0.0",
  "contract_version": "1.0",
  "author": "Your Name",
  "description": "Metadata provider for custom formats",
  "entry": "src/MyPlugin.php"
}

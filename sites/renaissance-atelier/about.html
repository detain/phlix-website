Our Craft

The philosophy, the licence, and how to contribute. A few notes before you explore the collection.

Philosophy

Phlix is built for people who want to own their media experience. Not rent it, not lease it — own it, the way a patron owns the paintings on their wall. The server runs on hardware you control, the library lives on drives you chose, and the software is open source you can read, modify, and extend.

We believe the tools we use to experience our media should be as thoughtful as the media itself. Phlix in this guise — the Renaissance Atelier — is a statement of that belief: that a private collection deserves a private gallery, and that gallery deserves to be built with care.

Craft over convenience. Curation and intentionality. Humanist attention to detail. Reverence for the work.

License

Phlix Server and Phlix Hub are MPL-2.0. The shared libraries, plugins, and clients are MIT. MPL is weak copyleft: if you modify a Phlix file, that file stays open. Anything you add alongside it stays yours.

This means you can build on Phlix commercially, fork it, or extend it — with one condition: modifications to the core files remain open. The licence is at the file level, not the project level.

The complete licence text is available at github.com/detain/phlix-server/blob/master/LICENSE.

Contributing

Phlix lives under the detain GitHub org. Issues, pull requests, and plugin submissions are all welcome. The plugin example repository is the best starting point for extension work.

If you are considering a larger contribution — a new client platform, a major feature, or a rearchitecture — open an issue first so we can discuss it before you invest the time.

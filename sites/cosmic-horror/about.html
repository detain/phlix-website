What We Know

The archive holds what it has observed. Below is the record of why it exists, how it operates, and what questions arise most frequently from those who consult it.

Philosophy

Phlix was built on the premise that media belongs to the person who paid for the storage it occupies. A self-hosted server that runs on hardware you own, serves clients you already have, and requires no account, no subscription, and no data leaving your LAN unless you explicitly choose otherwise.

The design prioritises correctness of implementation over breadth of features. Every protocol is fully implemented before it is offered. Every client that claims compatibility with a standard works with that standard, not a partial approximation of it.

License

Phlix Server and the Hub are MPL-2.0 — open source, and you can build on them commercially. If you modify a Phlix file, that file stays open; anything you add alongside it is yours. The shared libraries, plugins, and clients are MIT so you can build on them freely.

MPL-2.0 is weak copyleft. The one condition is per-file: modify a Phlix file and that file stays open. See the full license text on GitHub.

Contributing

The project operates under the detain GitHub org. Issues, pull requests, and plugin submissions are welcome. Before opening a large pull request, open an issue to discuss the change — this saves both parties time.

Frequently Asked Questions

Is Phlix like Plex / Jellyfin / Emby?
Yes — same job, different stack. Phlix is built in PHP 8.3+ on Workerman, ships with a versioned plugin contract, and includes a hub for accessing remote servers behind NAT without a third-party tunnel.
Do I need to expose my server to the internet?
No. Run Phlix on your LAN and use the Phlix Hub's reverse-tunnel relay to reach it from your phone or Roku at a friend's house. You can self-host the hub, or use the public one.
What formats are supported?
Anything FFmpeg can read. Direct play when the client supports it; transcoded HLS otherwise. Per-device quality profiles pick the right bitrate automatically.
Is there a mobile app?
Yes — React Native, available on iOS and Android. Currently in beta.
Can I write plugins?
Yes. Implement LifecycleInterface, ship a manifest, drop it in the plugins directory. See phlix-plugin-example for the smallest working starter.

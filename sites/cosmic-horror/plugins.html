Plugins

The plugin system exists because one archive cannot contain all knowledge. Extend what the server observes, and by what means it observes it.

The Plugin Contract

Every plugin implements LifecycleInterface and ships a manifest. The manifest declares version, dependencies, and entry points. Drop the plugin into the plugins/ directory. The loader observes it. The archive integrates it.

plugins/ my-plugin/ manifest.json # name, version, lifecycle hooks src/ MyPlugin.php # implements LifecycleInterface

The Lifecycle Interface

Implement LifecycleInterface and the server calls your plugin at each phase of its lifecycle: on install, on enable, on each request, on disable, on uninstall. The contract is typed, versioned, and documented.

interface LifecycleInterface { public function onInstall(): void; public function onEnable(): void; public function onRequest(): void; public function onDisable(): void; public function onUninstall(): void; }

Ecosystem Plugins

Plugins developed and maintained by the community extend metadata providers, authentication backends, transcoding pipelines, and notification systems. Watch the detain org on GitHub for new additions.

Write Your Own

The smallest working plugin is a manifest and a single PHP class. Follow the example, read the interface, and begin. The archive accepts what you add to it.

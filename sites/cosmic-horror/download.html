Descend Below

The archive has always existed. The ritual to enter it is documented below. One line on a fresh host. The consequences are yours.

The Server

PHP 8.3+ required. MySQL. ffmpeg. The installer handles all dependencies on Ubuntu or Debian.

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

One line, on a fresh Ubuntu or Debian host. Installs system packages (PHP 8.3+, MySQL, ffmpeg), creates a dedicated phlix system user, a MySQL database and user, an env file at /etc/phlix/env with a generated PHLIX_SECRET_KEY, runs database migrations, installs a systemd phlix-server service, and sets up an HAProxy reverse proxy with an auto-renewing Let's Encrypt certificate.

Full Install Guide View Source

Build from Source

Not an install — a development checkout. It creates no database, no service, and runs no migrations.

git clone https://github.com/detain/phlix-server.git cd phlix-server composer install

The Ecosystem

Five repositories. Each a component of the archive's architecture.

phlix-hub Cloud directory + reverse-tunnel relay
phlix-shared Shared interfaces, DTOs, event types — Composer package
phlix-docs End-user, developer, and hub-admin docs (VitePress)

Plugins

Extend Phlix with a real versioned contract — not just a folder to drop stuff in.

Plugin Model

Phlix uses a LifecycleInterface + manifest schema contract. Drop a plugin in the plugins/ directory and the loader picks it up automatically.

  • LifecycleInterface — defines install, enable, disable, uninstall hooks
  • Versioned manifest manifest.json — declares plugin name, version, dependencies
  • Autoloader integration via Composer
  • Per-plugin configuration storage

Ecosystem Plugins

The Phlix ecosystem includes plugins for metadata providers and more. Browse the phlix-plugin-example to get started.

Write Your Own

Implement LifecycleInterface, ship a manifest.json, drop it in the plugins directory. The loader handles the rest.

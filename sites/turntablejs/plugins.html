Plugins

Extend Phlix with a versioned plugin contract. Drop a plugin in, the loader picks it up.

Plugin Model

Phlix uses a LifecycleInterface + manifest schema for plugin discovery. Implement the interface, ship a manifest, drop your plugin into the plugins/ directory.

Plugin Manifest (manifest.json)

{ "name": "my-metadata-provider", "version": "1.0.0", "entry": "MyPlugin.php", "lifecycle": "metadata" }

The loader scans plugins/ on startup, validates the manifest, and registers your plugin's lifecycle hooks. See phlix-plugin-example for the smallest working starter.

Ecosystem Plugins

The plugin ecosystem is growing. See the phlix-plugin-example repository for a reference implementation.

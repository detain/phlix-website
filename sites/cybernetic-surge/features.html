System modules

Calibrate Your Upgrade

Every module is an implant. Add only what your system needs.

SyncPlay — Neural Synchronization

Weighted-mean NTP offset over 5 samples keeps every device locked to the same frame. Play, pause, seek — everyone moves together across the room or across the country. Latency compensation algorithms adjust for network delay. The group watch session becomes a shared consciousness.

Transcoding — Adaptive Quality

QualitySelector profiles for mobile-low, mobile-high, web, and tv-4k. CRF 23/28 libx264/libx265 with HLS master and variant playlists. The system learns your bandwidth patterns and pre-buffers at the optimal quality before you press play.

Neural Relay — Private Access

Sign in once. Reverse-tunnel relay handles NAT traversal. Your server stays behind your firewall — only an outbound connection is needed. Self-host the relay, or use the public node. Zero port forwarding. Full encryption.

Library — Self-Organizing

Folder-watcher monitors your media directories. On new file detection, scanner parses S01E02 and (2020) title patterns. ItemRepository hydrates metadata from TMDB/TVDb. Poster art, summaries, and cast data attach themselves automatically.

Authentication — Multi-Profile Security

JWT access tokens with refresh rotation. Argon2ID password hashing. Up to 5 profiles per account, each with a 4- or 6-digit PIN lock. Rating filter from G to NC-17. Parental controls that actually work.

Live TV — DVR + EPG

ChannelManager discovers DVB-T/T2, ATSC, and IPTV streams. GuideManager aggregates schedule data. Recorder handles scheduled and manual recordings. Your media server becomes a full cord-cutter replacement.

DLNA — Universal Casting

ContentDirectory, AvTransport, and RenderingControl via the DLNA protocol stack. Your existing smart TV, game console, or DLNA receiver sees Phlix as a native media source. No app required.

Plugin System — Extend the Neural Network

LifecycleInterface defines install, enable, disable, and uninstall hooks. Manifest schema validates configuration. Drop a plugin into the plugins directory — the loader discovers and registers it. See phlix-plugin-example for the reference implementation.

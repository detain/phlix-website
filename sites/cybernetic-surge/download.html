Neural installation

Begin the Upgrade

One line. Any Ubuntu or Debian host. The installation protocol is permanent.

Server — Step into the interface

bash <(curl -sSL https://phlix.io/install)

Runs on Ubuntu 20.04+ or Debian 11+. Requires 2GB RAM, 10GB storage. Installs as a systemd service.

Requirements

Ubuntu 20.04+ or Debian 11+
2GB RAM minimum (4GB recommended)
10GB storage minimum
Outbound HTTPS (for metadata and relay)

Post-install calibration

After installation, access the web interface at http://your-server:7777. Set your media directories, create the first user, and the upgrade begins.

sudo systemctl enable --now phlix-server
# Access: http://localhost:7777

Plugin Architecture

Plugins implement the LifecycleInterface. Each plugin has a manifest.json defining its name, version, and configuration schema. The plugin loader discovers, validates, and registers plugins from the plugins directory. 

{
  "name": "my-plugin",
  "version": "1.0.0",
  "description": "A neural extension",
  "lifecycle": {
    "install": "scripts/install.php",
    "enable": "scripts/enable.php",
    "disable": "scripts/disable.php",
    "uninstall": "scripts/uninstall.php"
  },
  "config": {
    "api_key": { "type": "string", "required": true }
  }
}

Plugins

Extend Phlix with a versioned contract. LifecycleInterface + manifest. Drop a plugin in, the loader picks it up.

Plugin model

The plugin system uses a versioned manifest contract. Implement LifecycleInterface, ship a manifest, drop it in the plugins directory.

Plugin lifecycle interface 
interface LifecycleInterface
{
    public function onInstall(): void;
    public function onEnable(): void;
    public function onDisable(): void;
    public function onUninstall(): void;
}
manifest.json 
{
  "name": "my-phlix-plugin",
  "version": "1.0.0",
  "description": "A Phlix plugin",
  "author": "Your Name",
  "requires": {
    "phlix": ">=1.0.0"
  }
}

Write your own

The phlix-plugin-example repo contains the smallest working starter. Clone it, implement your plugin logic, and drop the result into your Phlix plugins directory.

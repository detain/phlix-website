System Reference

Philosophy, architecture, and frequently asked calibration questions.

Philosophy

Phlix is built on a single conviction: your media server should be an extension of your body, not a box in a closet. The interface adapts to you. The upgrade is permanent. The code is open.

Frequently Asked Questions

How is this different from Plex or Jellyfin?
Phlix is self-hostable with no account required. SyncPlay is built in at the protocol level, not as a plugin. The Hub relay is designed for true privacy — the relay cannot decrypt your media stream.
Does it need internet to work?
Once installed, your server runs entirely offline. Internet is required only for initial metadata download (posters, summaries, cast data) and for the optional Hub relay access.
What formats does it support?
Phlix handles H.264, H.265/HEVC, VP9, AV1, and more through FFmpeg. Subtitles in SRT, SSA/ASS, and embedded. Audio passthrough for AC3, DTS, TrueHD, and Atmos.
Is there a mobile app?
Yes — iOS and Android clients are available. Android supports Chromecast. iOS supports AirPlay 2 and CarPlay.
Can I extend it with plugins?
Yes. The plugin system uses a LifecycleInterface with manifest schema. See phlix-plugin-example on GitHub for the reference implementation.
What is the license?
Phlix Server and the Hub are MPL-2.0. Shared libraries, plugins, and clients are MIT. You can modify and redistribute everything.

Contributing

Issues, pull requests, and plugin submissions are welcome on GitHub. The project follows a code of conduct and requires signed commits.

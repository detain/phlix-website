Neural relay

Reach Anywhere

Zero-configuration relay. No port forwarding. Your server stays behind your firewall.

How the Relay Works

Phlix Hub creates an outbound tunnel from your server to a relay node. Your client connects to the same relay node. The relay brokers the connection — your server's port never faces the internet.

Outbound HTTPS only — your server initiates
End-to-end encrypted — relay cannot read media
Self-hostable — run your own relay node
Public relay at hub.phlix.io — zero configuration

Enable Hub Access

In your Phlix Server settings, add your Hub account token. The server will establish the tunnel automatically on startup. 

# In /etc/phlix/server.conf
[hub]
enabled = true
token = YOUR_HUB_TOKEN
relay = hub.phlix.io

Self-Host the Relay

Run your own relay node for full control. The relay software is open source and runs on any Linux host with a public IP.

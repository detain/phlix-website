Five ways into the same library, listed as specifications rather than sales copy. Status is stated, not implied.

01Five ways in

Roku

stable

Native Roku channel

Capabilities
  • HLS playback
  • Hub mode
  • Skip intro/outro
  • SyncPlay
Source
github.com/detain/phlix-roku-client

Samsung Tizen

stable

Smart TV app

Capabilities
  • Vanilla JS + webpack
  • Direct play + HLS transcoded
  • Remote-optimized UI
Source
github.com/detain/phlix-tizen-client

Windows

stable

Native desktop

Capabilities
  • Electron + React + TypeScript
  • System tray
  • Media keys
  • Hub mode
Source
github.com/detain/phlix-windows-client

Mobile (iOS + Android)

beta

React Native app

Capabilities
  • Movies, TV, Music, Photos
  • Offline downloads
  • Token refresh
Source
github.com/detain/phlix-mobile-client

Any DLNA device

stable

No install required

Capabilities
  • ContentDirectory
  • AvTransport
  • Discovery via SSDP
Source
No app to install — discovery over SSDP reaches the server directly.

Pick one and install the server.

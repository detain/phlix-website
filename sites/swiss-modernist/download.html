04Download

One line to server. Below it: the five clients, then every repository in the ecosystem. No steps, no funnel.

01Server

composer create-project detain/phlix-server && cd phlix-server && php start.php

Requires PHP 8.3+, Composer, and the extensions listed in the documentation. The server runs on Workerman 5.x with an async coroutine core.

Download

Self-host in minutes. PHP 8.3+. No subscription. No data collection.

Server

Phlix Server runs on any system that supports PHP 8.3+ — Linux, macOS, Windows (WSL recommended), NAS devices, or a spare machine.

composer create-project detain/phlix-server cd phlix-server php start.php

Requires: PHP 8.3+, Composer, and the extensions listed in the documentation.

02Built on principle

An open-source media server built on Swiss precision: multi-user profiles, real-time SyncPlay, transcoding that knows your network, and hub access without the internet.

  • 01100% self-hostable — your library never leaves your hardware unless you say so
  • 02Native clients on Roku, Samsung Tizen, Windows, Mobile, plus any DLNA device
  • 03Real-time SyncPlay with NTP-style time sync so movie night actually stays in sync
  • 04Multi-source metadata: TMDB, TVDB, Fanart.tv, and local NFO with 24-hour cache
  • 05Adaptive HLS streaming, FFmpeg transcoding, per-device quality profiles
  • 06Live TV with DVR + EPG guide integration
  • 07Plugin system with a versioned manifest contract

03The grid. Complete.

Eight subsystems. Two carry the weight, four support them, two are noted for completeness. Every one of them is in the server you install.

Cast 1 · library

Library that organizes itself

Drop a file, see it organized. Structure builds itself.

Folder-watcher hashes mtimes, scanner parses S01E02 / (2020) titles, ItemRepository hydrates metadata_json. Add a file, see it appear.

Cast 2 · auth

Multi-user, multi-profile, parental controls

Multi-user, multi-profile, ratings locked down. Precision control.

JWT auth with refresh tokens, Argon2ID password hashing, up to 5 profiles per user, 4- or 6-digit PINs, rating filter from G to NC-17.

03 · syncplay

SyncPlay across the room or across the country

Every device locked to the same frame.

04 · transcode

Transcoding that picks the right quality

Four quality profiles, chosen per device.

05 · livetv

Live TV with DVR + EPG

Scheduled recordings and a guide you can read.

06 · dlna

DLNA for the devices you already own

Plugins

Extend Phlix with a versioned plugin contract. Drop a plugin in, the loader picks it up. The contract is stable — your plugin will not break across minor versions.

The Plugin Contract

Every Phlix plugin must implement LifecycleInterface and ship a manifest.json. The loader scans the plugins/ directory, validates the manifest, and registers the plugin's hooks.

Manifest Schema

  • name — Unique plugin identifier
  • version — Semantic version
  • phlix_version — Minimum Phlix server version
  • description — Human-readable description
  • author — Author name and contact
  • hooks — Array of lifecycle hooks to register

See phlix-plugin-example for a minimal working implementation.

Writing Your Own Plugin

The plugin example repository contains the smallest possible working plugin — a metadata provider that fetches posters from a custom source. Use it as a starting point.

Key steps:

  1. Clone phlix-plugin-example
  2. Implement onLoad() to register your hooks
  3. Set the plugin name and version in manifest.json
  4. Drop the folder into your server's plugins/ directory

The loader activates it on the next server start. No configuration required.

Have a plugin to share?

The Phlix ecosystem is open. Publish your plugin on GitHub and open a PR to add it to the ecosystem list.

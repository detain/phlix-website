Plugin system

A versioned contract, a manifest schema, and a loader that picks up what you drop in.

The contract

'my-metadata-provider', 'version' => '1.0.0', 'type' => 'metadata', ]; } public function onEnable(): void { /* ... */ } public function onDisable(): void { /* ... */ } }

Implement LifecycleInterface, define your manifest, drop the class in the plugins directory. Phlix's loader discovers it at startup and calls your lifecycle hooks in the right order. No configuration files, no registration calls.

Reference implementation

The phlix-plugin-example repository is the smallest working starter — a metadata provider plugin you can read end to end in an afternoon.

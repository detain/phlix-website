Plugins

Extend Phlix with a versioned plugin contract — drop a plugin in, and the garden tends itself.

Plugin model

Every plugin implements LifecycleInterface and ships a manifest. Drop it in the plugins/ directory and the loader picks it up automatically — no configuration, no ceremony.

// See the reference plugin:
github.com/detain/phlix-plugin-example

Ecosystem plugins

The plugin contract makes it easy to add metadata providers, transcode pipelines, or anything your garden of media needs to flourish. Watch this space grow — or plant your own.

Write your own

Start from phlix-plugin-example for the smallest working starter. The manifest schema is versioned, so your plugin will always find a welcome corner of the garden.

Plugins

A specialist's corner — nice for tinkerers, but not the main draw for someone pouring a first drink.

The Plugin Model

Phlix ships with a versioned plugin contract. Implement LifecycleInterface, ship a manifest.json, and drop your plugin into the plugins/ directory. The loader picks it up automatically. 

{
  "name": "my-metadata-provider",
  "version": "1.0.0",
  "entry": "MyPlugin.php",
  "lifecycle": ["onServerStart", "onMetadataResolve"]
}

See phlix-plugin-example for the smallest working starter.

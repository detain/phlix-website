Plugins

Extend Phlix with a versioned plugin contract. Drop in, it just works.

Plugin Model

Every plugin implements LifecycleInterface and ships a manifest.

LifecycleInterface

Implement the interface, drop into plugins/. The loader discovers and initializes your plugin automatically.

Versioned Manifest

Declare your plugin's name, version, and dependencies in a JSON manifest. Schema is versioned — no breaking changes.

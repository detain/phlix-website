Plugins

Extend Phlix with a real plugin contract — not a hack, not a workaround.

The Plugin Model

Phlix plugins implement the LifecycleInterface and ship a versioned manifest. Drop your plugin into the plugins/ directory and the loader discovers it automatically.

plugins/ my-metadata-plugin/ manifest.json # Plugin metadata and version src/ MyPlugin.php # Implements LifecycleInterface

LifecycleInterface

Your plugin receives lifecycle events: onInstall, onEnable, onDisable, onUninstall. The manifest declares which events your plugin cares about.

Manifest Schema

The manifest declares your plugin's name, version, description, and dependencies. The schema is versioned — plugins built against manifest v1 work with servers that support v1, and the server rejects incompatible plugins cleanly.

{ "manifest_version": 1, "name": "my-metadata-plugin", "version": "1.0.0", "description": "Fetches metadata from MyAnimeList", "events": ["onEnable", "onDisable"], "dependencies": {} }

Write Your Own

Start with phlix-plugin-example — it shows the minimum viable plugin structure and comments on every decision.

Plugins can:

  • Add metadata providers (TMDB, TVDB, custom sources)
  • Extend transcoding pipelines
  • Integrate with external services (Plex, Jellyfin, trakt)
  • Add custom library types
  • Hook into playback events

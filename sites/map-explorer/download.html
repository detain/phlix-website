Download

Self-host your media in minutes. One command install on Ubuntu or Debian.

Phlix Server

Requirements: PHP 8.3+, MySQL, ffmpeg. The installer targets a fresh Ubuntu/Debian host and also compiles the Swoole and php-uv extensions from source.

One line, on a fresh Ubuntu or Debian host

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

Installs system packages, creates a dedicated phlix system user, a MySQL database and user, an env file at /etc/phlix/env with a generated PHLIX_SECRET_KEY, runs database migrations, installs a systemd phlix-server service, and sets up an HAProxy reverse proxy with an auto-renewing Let's Encrypt certificate.

Provision HTTPS in the same run

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh \ | sudo bash -s -- --domain phlix.example.com --admin-email you@example.com

Build from source (development)

git clone https://github.com/detain/phlix-server.git cd phlix-server composer install

Note: This is a development checkout only. It does not create a database, a service, or run migrations.

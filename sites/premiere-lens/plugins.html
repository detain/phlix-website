Plugins

Extend Phlix with a versioned plugin contract. Drop in a plugin, the loader picks it up.

Plugin Model

  • LifecycleInterface — implement this to hook into server events
  • manifest.json — versioned contract declaring plugin metadata and dependencies
  • Drop into plugins/ — the auto-loader discovers and initializes it

Server

Install Phlix Server

PHP 8.3+, MySQL, ffmpeg required. The installer targets a fresh Ubuntu/Debian host and also compiles the Swoole and php-uv extensions from source.

One line, on a fresh Ubuntu or Debian host 
curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

Default ports: HTTP on :8096 behind HAProxy on :80/:443, DLNA discovery on 1900/udp.

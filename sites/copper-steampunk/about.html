The Logbook

Philosophy, license, contributing — and questions from the catalogue.

Philosophy

Phlix is built for people who run their own infrastructure. It respects your hardware, your network, and your data — because you own all three. Every decision prioritises self-hostability, transparency, and a plugin system that doesn't lock you in.

The media server is written in PHP because PHP is everywhere, and Workerman because async I/O without a framework taxonomy is the right tool for a daemon that spends most of its time waiting on network and disk. The client ecosystem spans from a Roku channel to a React Native app because your screens shouldn't dictate your server choice.

License

Phlix Server and the Hub are MPL-2.0 — open source, and you can build on them commercially. If you modify a Phlix file, that file stays open; anything you add alongside it is yours.

The shared libraries, plugins, and clients are MIT so you can build on them freely.

See the full license at github.com/detain/phlix-server/blob/master/LICENSE

Contributing

Everything lives under the detain GitHub org. Open issues for bugs and feature requests. Pull requests welcome — open one against the relevant repo and it will be reviewed promptly.

Questions from the Catalogue

Is Phlix like Plex / Jellyfin / Emby?
Yes — same job, different stack. Phlix is built in PHP 8.3+ on Workerman, ships with a versioned plugin contract, and includes a hub for accessing remote servers behind NAT without a third-party tunnel.
Do I need to expose my server to the internet?
No. Run Phlix on your LAN and use the Phlix Hub's reverse-tunnel relay to reach it from your phone or Roku at a friend's house. You can self-host the hub, or use the public one.
What formats are supported?
Anything FFmpeg can read. Direct play when the client supports it; transcoded HLS otherwise. Per-device quality profiles pick the right bitrate automatically.
Is there a mobile app?
Yes — React Native, available on iOS and Android. Currently in beta.
Can I write plugins?
Yes. Implement LifecycleInterface, ship a manifest, drop it in the plugins directory. See phlix-plugin-example for the smallest working starter.
What's the license?
Phlix Server and the Hub are MPL-2.0 — open source, and you can build on them commercially. If you modify a Phlix file, that file stays open; anything you add alongside it is yours. The shared libraries, plugins, and clients are MIT so you can build on them freely.
Will this work on my ten-year-old television?
Anything FFmpeg can read. If your TV supports DLNA (most smart TVs do), it works without an app install. Otherwise, try the web interface or any DLNA renderer app.
Must I connect my workshop to the entire internet?
No. Run Phlix on your LAN. The Phlix Hub is an opt-in relay — your server reaches out to it, not the other way around. You can disable Hub enrollment entirely and stay fully offline.
Can I build a plugin for my own inventory?
Yes. Implement LifecycleInterface, ship a manifest, drop it in the plugins directory. The reference example at phlix-plugin-example is the fastest way to see how it all fits together.

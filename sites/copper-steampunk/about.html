About Phlix

A media server built with the precision of a master watchmaker, the ambition of an airship engineer, and the soul of an eternal explorer.

Philosophy

Phlix exists because your media archive deserves better than a vendor's cloud. It should live on hardware you own, in a format you control, behind a connection you manage.

We built Phlix to deliver a media experience as precisely crafted and rewarding to operate as the finest Victorian instrument — powerful, reliable, and a pleasure to engage with.

The plugin system ensures Phlix grows with your collection. The Hub ensures it travels with you. The BSD-3-Clause license ensures it stays yours forever.

License

Phlix is BSD-3-Clause licensed. Use it, modify it, fork it, and ship products built on it — no strings attached. The obligation is attribution and the preservation of the license on any redistributed source code.

Contributing

All Phlix projects live under the @detain GitHub org. Issues, pull requests, and plugin contributions are welcome. For major changes, open an issue first to discuss the direction.

The plugin ecosystem is the most direct way to extend Phlix without touching the server core. If you've built something useful, open a PR against phlix-plugin-example to show the pattern, then link your implementation.

Frequently Asked

Is Phlix like Plex / Jellyfin / Emby?
Yes — same job, different stack. Phlix is built in PHP 8.3+ on Workerman, ships with a versioned plugin contract, and includes a hub for accessing remote servers behind NAT without a third-party tunnel.
Do I need to expose my server to the internet?
No. Run Phlix on your LAN and use the Phlix Hub's reverse-tunnel relay to reach it from your phone or Roku at a friend's house. You can self-host the hub, or use the public one.
What formats are supported?
Anything FFmpeg can read. Direct play when the client supports it; transcoded HLS otherwise. Per-device quality profiles pick the right bitrate automatically.
Is there a mobile app?
Yes — React Native, available on iOS and Android. Currently in beta.
Can I write plugins?
Yes. Implement LifecycleInterface, ship a manifest, drop it in the plugins directory. See phlix-plugin-example for the smallest working starter.
What's the license?
BSD-3-Clause across the board.

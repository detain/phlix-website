The Plugin Craft

A real contract. A working example. Build precisely, drop cleanly.

The Contract

Implement LifecycleInterface, ship a manifest.json, drop the plugin into plugins/. The loader discovers it, validates it, and starts it. Versioned so the contract is stable as the ecosystem grows.

The Plugin Model

LifecycleInterface
Four methods: onEnable(), onDisable(), onInstall(), onUninstall(). Your plugin's entry point for every state transition.
manifest.json
Declares name, version, required Phlix version, dependencies, and the fully-qualified class name of your LifecycleInterface implementation.
Drop-in loading
Drop the plugin folder into plugins/. The loader scans on startup, validates the manifest, and enables it automatically.
Versioned contract
The interface is versioned. Adding methods is backward-compatible. Check phlix_version in your manifest to gate feature availability.

The Reference Implementation

phlix-plugin-example is the smallest working metadata-provider plugin. Clone it, read it, run it. It does one thing correctly — everything you need to see the contract in motion.

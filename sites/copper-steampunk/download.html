Download

Full steam ahead into your library. The Phlix server runs on any platform that supports PHP 8.3+.

Server Requirements 

PHP 8.3+     — async/coroutine extensions preferred
Workerman 5.x — async TCP server
FFmpeg       — transcoding engine
4 GB RAM     — minimum for transcoding
Storage      — as much as your media library requires

Clone the repository and point your web server at the public_html/ directory, or use the built-in Workerman server for development. 

git clone https://github.com/detain/phlix-server.git
cd phlix-server
composer install
php start.php start

The Engine

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

PHP 8.3+, MySQL, ffmpeg. Installs system packages, creates database, sets up systemd service and HAProxy with Let's Encrypt. Default ports: HTTP on :8096 behind HAProxy on :80/:443, DLNA discovery on 1900/udp.

Requirements: PHP 8.3+, MySQL, ffmpeg. Targets a fresh Ubuntu/Debian host. Full install docs →

Not an install — build from source (development):

git clone https://github.com/detain/phlix-server.git cd phlix-server composer install

# Void Walker - Site

Traversing the emptiness between dimensions for content.

## Structure

```
void-walker/
├── index.html          # Home page
├── features.html       # Features documentation
├── download.html       # Download/install
├── clients.html        # Client applications
├── hub.html           # Plugins & community
├── about.html         # About the void
├── 404.html           # Lost in the void
├── manifest.json      # PWA manifest
├── css/
│   ├── portal.css     # Portal & void aesthetics
│   ├── animations.css # Motion & animation
│   ├── responsive.css # Responsive styles
│   └── styles.css     # Main styles
├── js/
│   ├── particles.js   # Floating debris system
│   ├── portal.js      # Portal animations
│   ├── glitch.js      # Glitch effects
│   └── main.js        # Initialization
└── img/
    └── favicon.svg    # Site favicon
```

## Brand Kit

See `brand-kits/void-walker.js` for the complete brand specification.

## Development

This site uses vanilla HTML/CSS/JS with no external CDN dependencies
(except the system font stack). All animations respect
`prefers-reduced-motion`.

## Palette

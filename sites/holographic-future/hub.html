Access without exposure

Phlix Hub

Your server, reachable from anywhere — without touching your router.

What the Hub does

Reverse-tunnel relay

The Hub maintains an outbound tunnel from your server to a relay broker. When you open the Phlix client from a hotel, a friend's house, or another city, the client reaches the Hub — and the Hub routes the session back through the same tunnel to your server. No port forwarding. No UPnP. No third-party tunnel service.

Security model

Private by architecture

Your server never opens an inbound port. The Hub relay sees only encrypted session traffic — it has no access to your library metadata, credentials, or files. The tunnel is established from your server outward, so NAT is never a problem.

Two ways to run

Self-host or use the public Hub

Public Hub

Use the Phlix project's public relay. No configuration, no server to maintain. Sign in with your Phlix credentials and your server appears automatically.

View on GitHub

Self-hosted

Run your own Hub instance on a VPS or a always-on machine. Full control over the relay, no traffic leaving your infrastructure.

Hub admin docs

In the clients

Hub mode

Every native Phlix client supports Hub mode: once signed in, the client automatically discovers remote servers through the Hub relay. Switch between local and remote servers without re-configuring anything.

Roku — Hub mode via channel settings
Samsung Tizen — Hub mode in the app connect screen
Windows — Hub mode via the system tray menu
Mobile (iOS + Android) — Hub mode on the server select screen

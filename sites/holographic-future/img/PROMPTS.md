# Image Generation Prompts — Holographic Future

> These prompts can regenerate all visual assets for the holographic-future brand kit site.
> All prompts use the kit's image_prompt_prefix and image_prompt_suffix.

## Prefix (prepended to every prompt)
```
Holographic prismatic chrome aesthetic, iridescent foil surfaces refracting rainbow spectrum light, electric blue accents, midnight deep background, glassmorphism layered panels, ultra-precise geometric forms, cool studio lighting with inner luminosity,
```

## Suffix (appended to every prompt)
```
, premium tech-luxury quality, deep midnight and chrome white palette, electric blue glow accents, sharp clean edges, no warm tones, no paper texture, hyper-precise.
```

## Negative Prompt
```
warm colors, orange tones, brown, paper texture, hand-drawn, watercolor, retro, nostalgic, cartoon, soft blur, bokeh overload, HDR glow halo, lens flare (unintentional), dark horror, heavy grain, earthy, rustic
```

## Logo
```
Design a Holographic Future Phlix logo: Orbitron wordmark in chrome white on midnight, optional thin hexagonal badge border in electric blue, minimal, zero organic curves.
```
**Allowed symbols**: prism, diffraction grating stripe, thin geometric diamond, spectral sweep
**Forbidden symbols**: popcorn, film reel, warm circles, rounded organic blobs, stars (cliché)

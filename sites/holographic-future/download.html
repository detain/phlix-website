Download

Self-hostable. No CDN dependencies. No subscription. Your hardware, your library.

Server Requirements

PHP 8.3+ required — async/coroutine server powered by Workerman 5.x 

# Clone the server
git clone https://github.com/detain/phlix-server
cd phlix-server

# Install dependencies
composer install

# Start the server
php server.php start

Plugins

A real contract. A versioned manifest. Drop a plugin in and the loader picks it up.

Plugin Model

LifecycleInterface + Manifest

// manifest.json { "name": "my-metadata-provider", "version": "1.0.0", "entry": "MyPlugin.php" } // MyPlugin.php class MyPlugin implements LifecycleInterface { public function onInstall(): void { } public function onEnable(): void { } public function onDisable(): void { } public function onUninstall(): void { } }

Implement LifecycleInterface, ship a manifest, drop the plugin into plugins/. The loader handles the rest.

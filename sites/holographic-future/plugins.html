Plugin system

A versioned contract that makes plugins first-class citizens, not afterthoughts.

The contract

LifecycleInterface + manifest schema

Every plugin implements LifecycleInterface and ships a manifest.json that declares its version, dependencies, and the hooks it registers. The loader validates the manifest against the current schema version before activating the plugin.

The directory

Drop in, the loader picks it up

Place a plugin in plugins/ with its manifest. Phlix will scan, validate, and activate it on the next startup. No config editing, no manual registration.

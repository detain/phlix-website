About Phlix

Open-source software built by developers who care about media, ownership, and craft.

Chapter I

Why a Library?

A great media server is not a pile of files. It is a curated collection — ordered, annotated, and presented with the care that makes a library valuable. Phlix was built by people who believe your media deserves the same respect as your books. Every decision prioritises permanence, ownership, and the long-term pleasure of a well-maintained collection.

Most streaming platforms treat your library as a transient catalogue to be algorithmically surfaced and monetised. Phlix treats yours as a private collection worthy of curation. The software stays out of your way once it has helped you find what you want to watch.

Chapter II

Open as the Air

Phlix Server and the Hub are MPL-2.0 — open source, and you can build on them commercially. If you modify a Phlix file, that file stays open; anything you add alongside it is yours. The shared libraries, plugins, and clients are MIT so you can build on them freely.

This is not "no strings attached" — MPL-2.0 is weak copyleft with a simple rule: modify a Phlix file and it stays open. That is the only condition. Your additions beside Phlix are yours. The licence exists to keep the core project open, not to restrict what you build with it.

Chapter III

All Are Welcome

Phlix is built and maintained by a community of developers on GitHub. Whether you want to fix a bug, add a feature, write a plugin, or improve the documentation — the repository is open and contributions are welcome.

The detain GitHub org manages the core projects. File issues, open pull requests, and join the discussions. The project rewards careful, thoughtful contributions.

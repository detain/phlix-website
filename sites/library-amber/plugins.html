Plugins

Phlix has a versioned plugin contract. Implement LifecycleInterface, ship a manifest, drop it in the plugins directory.

Plugin model

1

Implement LifecycleInterface

Define onLoad, onReady, and onShutdown for your plugin class.

2

Write manifest.json

Declare name, version, dependencies, and the class Phlix should instantiate.

3

Drop into plugins/

Place your plugin folder in the plugins directory. The loader finds it automatically.

4

Phlix activates it

On next startup, Phlix instantiates your plugin and calls the lifecycle methods.

Ecosystem plugins

The community has built plugins for metadata providers, channel integrations, and more. See the phlix-plugin-example for the reference implementation.

Write your own

The smallest working plugin is the reference example. Clone it, rename the namespaces, and you have a starting point. The docs cover the full LifecycleInterface API.

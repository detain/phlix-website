Get Groovy

Ready for warm, groovy streaming?

One line to install. The rest is just spinning records.

One line, on a fresh Ubuntu or Debian host

Terminal — the one-line special
$ curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

Prompts for install path and database credentials in terminal; runs fully unattended with -y.

What it does

  • Installs system packages (PHP 8.3+, MySQL, ffmpeg)
  • Creates a dedicated phlix system user and MySQL database
  • Sets up an env file at /etc/phlix/env with a generated PHLIX_SECRET_KEY
  • Runs database migrations
  • Installs a systemd phlix-server service
  • Sets up HAProxy reverse proxy with auto-renewing Let's Encrypt certificate

Default ports: HTTP on :8096 behind HAProxy on :80/:443, DLNA discovery on 1900/udp.

Self-hosted. No subscription. No accounts required. Your server. Your library. Your rules.

Server

PHP 8.3+ required. Workerman 5.x async/coroutine server. Clone, configure, run. 

git clone https://github.com/detain/phlix-server
cd phlix-server
composer install
php start.php start

Server source: github.com/detain/phlix-server

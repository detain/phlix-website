Take It

Here's what you need.

Ubuntu or Debian. One line. No account, no signup, no middleman.

One line, on a fresh Ubuntu or Debian host

Server install — one line

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

Installs PHP 8.3+, MySQL, ffmpeg, creates the database, sets up the service, and provisions an HAProxy reverse proxy with Let's Encrypt. Prompts for install path and credentials in terminal; runs fully unattended with -y.

Not on Ubuntu or Debian? See all install options in the docs →

Plugins

A real contract. A versioned manifest. Drop in, load up, play. No registry required.

Plugin model

  • Implement LifecycleInterface in your plugin class. Define onInstall(), onEnable(), onDisable(), and onUninstall() lifecycle hooks.

  • Ship a manifest.json with your plugin's name, version, and dependencies. The loader validates it against the current schema before loading.

  • Drop the plugin directory into plugins/. The server scanner picks it up, validates the manifest, and registers it. No restart required for enable/disable.

  • Write your provider — metadata, transcoder, scanner, or renderer — and access Phlix internals through the published service interface.

    Reference metadata-provider plugin — the smallest working starter. Implement LifecycleInterface, write a manifest, drop it in.

Plugin System

A versioned contract. Drop a plugin in, the loader picks it up. Extend metadata, add new data sources, hook into playback events.

Plugin model

Minimal plugin structure

plugins/
  my-plugin/
    manifest.json    # name, version, lifecycle interface
    src/
      MyPlugin.php  # implements LifecycleInterface

Implement LifecycleInterface, ship a manifest.json, drop the folder into plugins/. The loader discovers it on startup. No registration, no config file to update.

The contract is versioned — Phlix declares which interface version it supports, and plugins declare which version they target. A mismatch fails gracefully rather than crashing your server.

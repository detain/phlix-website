Plugins

Extend Phlix with a versioned plugin contract. Drop it in. The loader picks it up.

Plugin model

Every plugin implements LifecycleInterface and ships a manifest. Drop it in the plugins/ directory and the loader picks it up automatically. 

// See the reference plugin:
github.com/detain/phlix-plugin-example

Ecosystem plugins

The plugin contract makes it easy to add metadata providers, transcode pipelines, or anything else you can imagine. The manifest schema is versioned — Phlix knows what your plugin needs and what it provides.

Write your own

Start from phlix-plugin-example for the smallest working starter. Implement LifecycleInterface, write the manifest, drop the folder into plugins/.

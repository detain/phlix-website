Phlix Hub

Sign in once. Reach any of your servers from anywhere. No port forwarding. No dynamic DNS setup. No third-party tunnel service required.

What the Hub does

The Hub is a reverse-tunnel relay. When your Phlix server starts, it establishes an outbound connection to the Hub. When you open a client, the client connects to the Hub and the Hub bridges the two. Neither device needs an open inbound port.

The Hub also maintains a server directory — sign in once, see all your servers, pick which one to stream from. Travel to a friend's house and your library follows you.

Self-host or use the public hub

The public Hub at github.com/detain/phlix-hub is free to use. It routes no data — it only bridges the connection handshake. Your media streams direct from your server to your client.

Run your own Hub for full control. Deploy phlix-hub anywhere that can handle WebSocket connections. Point your server config at it and the directory is yours.

Hub mode in clients

Every official client has Hub mode. Toggle it on, authenticate to the Hub, and all connections route through it automatically. No configuration beyond your Hub URL and credentials.

  • Roku

    Hub mode ships in the stable channel.

  • Windows

    Hub mode ships in the stable channel.

  • Mobile

    Hub mode ships in the beta channel.

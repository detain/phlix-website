Plugin System

Extend everything. Themes, metadata, notifications, storage backends — all through a clean PHP plugin API.

Extension Points

Plugin Types

Themes

Full UI customization through Smarty templates and CSS variables. Brand kits, dark modes, custom layouts.

Metadata Enrichers

Fetch additional metadata from TMDB, TVDB, IMDB, Steam, IGDB, and any custom API. Auto-tag, artwork, summaries.

Notification Hooks

Send to Pushover, Discord, Telegram, email, Slack, Matrix, Gotify, NTfy, or any custom webhook.

Storage Backends

Local disk, NFS, CIFS/SMB, S3-compatible object storage, B2, Google Drive, Dropbox, and custom adapters.

Scanner Plugins

Custom library scanners. Parse any file structure, any naming convention, any metadata format you throw at it.

Player Plugins

External player integrations. Push to MPV, VLC, Kodi, external projectors, or any custom playback hardware.

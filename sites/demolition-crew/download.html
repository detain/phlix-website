One Command to Demolish

Download Phlix

PHP 8.3+ required. MySQL/MariaDB for metadata. That's it — no Java, no Node, no Electron.

Quick Start

Install Now

Clone, configure, launch. The install script handles everything.

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash View on GitHub

Requirements

PHP 8.3+ with extensions: pdo_mysql, json, curl, fileinfo, gd, mbstring, xml, zip. MySQL 8+ or MariaDB 10.5+. Web server (Apache2, Nginx, Caddy, or PHP built-in server).

Manual Install

Download the latest release from GitHub, extract, point your web root at the public/ directory, create your config/local.php, and run database migrations.

Docker

docker run -d -p 8080:80 -v /path/to/media:/media -v phlix-db:/var/lib/mysql detain/phlix Full Docker and Docker Compose configs available in the repository.

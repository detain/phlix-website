Native Apps

Roku, Samsung TV, Windows, macOS, Linux, Android, iOS, Android TV, Fire TV — 50+ native applications. No Electron, no Java, no compromises.

DLNA / Chromecast

Cast to any DLNA device, Chromecast, AirPlay. Push content to your TV without lifting a finger.

Live TV + DVR

HDHomeRun, OpenHD, tuner hardware support. Electronic Program Guide, scheduled recordings, timeshift. Cut the cord permanently.

Plugin System

Full PHP plugin API. Themes, metadata enrichers, notification integrations, storage backends — extend everything.

Auto-Update

Rolling release model. Built-in update system checks for new versions and applies them without manual intervention.

Security First

HTTPS enforcement, secure session management, granular permission system, audit logging. Your media, your fortress.

Multi-Library

Organize across multiple directories, drives, or network shares. Tag, sort, and browse by anything you define.

Subtitles

Embedded, external, and auto-downloaded subtitles. OpenSubtitles.org integration. SRT, SSA/ASS, VobSub support.

Parental Controls

Per-user content restrictions, PIN locks, rating-based filtering. Keep the demolition crew in check.

API Access

Full REST API and WebSocket events. Build your own integrations, dashboards, or mobile apps on top of Phlix.

Transcoding

On-the-fly transcoding for incompatible formats. FFmpeg-powered, hardware acceleration support where available.

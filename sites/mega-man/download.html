Download

Get Phlix running on your own server. One command. No credit card.

Server

Requires PHP 8.3+ on a Linux system (Ubuntu/Debian recommended). The installer handles all dependencies including MySQL and FFmpeg.

Install on Ubuntu or Debian curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

For HTTPS with auto-certificate, add --domain yourdomain.com --admin-email you@example.com

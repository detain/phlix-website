Plugins

Extend Phlix with a versioned plugin contract. Drop in, the loader picks it up.

Plugin Model

Phlix plugins implement the LifecycleInterface and ship a manifest file. The plugin loader validates the manifest and manages the plugin lifecycle.

  • LifecycleInterface — required methods for initialization, startup, and shutdown
  • Manifest — version, dependencies, and metadata in manifest.json
  • Drop-in discovery — place in plugins/, loader auto-scans
composer require phlix-plugin-example

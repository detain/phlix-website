Plugins

Extend Phlix with a versioned plugin contract. Drop in, the loader picks it up.

The Plugin Model

Phlix plugins implement the LifecycleInterface and ship a manifest file. The loader scans the plugins/ directory, validates the manifest, and runs your plugin's lifecycle hooks.

Core concepts

LifecycleInterface — defines onEnable, onDisable, and onInstall hooks.
Manifest — JSON file declaring plugin name, version, dependencies, and autoloader path.
Drop-in — place your plugin folder in plugins/, the loader discovers it on next startup.

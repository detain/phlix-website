About Phlix

Before the age of kings there were the tales — carved in runes, spoken by firelight, carried across grey seas on ships that had no business surviving the crossing.

Philosophy

Phlix was forged in the belief that your media should live on your iron, not in someone else's cloud. We build in PHP 8.3+ because the stack is everywhere, and we ship a versioned plugin contract because the first version of any feature is never the last word.

We value craft, permanence, and earned weight. Every feature should feel like it was carved, not printed. Every release should outlast the one before it. The goal is not to be the largest media server — it is to be the one that earns the most respect.

Craft

Every line earns its place. Nothing is decorative. Everything has purpose.

Honor

Open-source. BSD-3. No paywalls on core features. No telemetry.

Epic Depth

Deep lore, full metadata, SyncPlay, Live TV. The feature set is not shallow.

Permanence

Versioned contracts. Semantic plugin versioning. Nothing breaks silently.

Primal Power

Adaptive HLS, FFmpeg transcoding, per-device quality profiles. Power where it matters.

Contributing

The detain GitHub org houses every piece of the Phlix ecosystem. Issues, pull requests, and plugin submissions are welcome. The maintainers respond to the most actionable reports — bug reports with reproduction steps and feature requests with clear scope.

The most valued contributions are: working code with tests, clear documentation improvements, and plugin implementations that demonstrate the contract. See each repository's CONTRIBUTING file for specifics.

FAQ

Is Phlix like Plex / Jellyfin / Emby?
Yes — same job, different stack. Phlix is built in PHP 8.3+ on Workerman, ships with a versioned plugin contract, and includes a hub for accessing remote servers behind NAT without a third-party tunnel.
Do I need to expose my server to the internet?
No. Run Phlix on your LAN and use the Phlix Hub's reverse-tunnel relay to reach it from your phone or Roku at a friend’s house. You can self-host the hub, or use the public one.
What formats are supported?
Anything FFmpeg can read. Direct play when the client supports it; transcoded HLS otherwise. Per-device quality profiles pick the right bitrate automatically.
Is there a mobile app?
Yes — React Native, available on iOS and Android. Currently in beta.
Can I write plugins?
Yes. Implement LifecycleInterface, ship a manifest, drop it in the plugins directory. See phlix-plugin-example for the smallest working starter.

Plugin System — LifecycleInterface

Phlix ships a versioned plugin contract: LifecycleInterface + manifest schema. Implement the interface, ship a manifest, drop the plugin in the plugins directory. The loader handles the rest.

The contract is stable — a plugin written for Phlix 1.x works until you choose to upgrade. No lock-in, no breakage on update.

// phlix-plugin-example/manifest.json
{
"name": "my-metadata-provider",
"version": "1.0",
"lifecycle": "metadata-provider",
"phlix_version": ">=1.0"
}

Download

Get Phlix running on your own hardware in minutes.

Server

PHP 8.3+ required. Install on a fresh Ubuntu or Debian host.

One-line install
curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

Installs system packages (PHP 8.3+, MySQL, ffmpeg), creates a dedicated phlix system user, a MySQL database and user, an env file at /etc/phlix/env with a generated PHLIX_SECRET_KEY, runs database migrations, installs a systemd phlix-server service, and sets up an HAProxy reverse proxy with an auto-renewing Let's Encrypt certificate.

With HTTPS
curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh \
  | sudo bash -s -- --domain phlix.example.com --admin-email you@example.com

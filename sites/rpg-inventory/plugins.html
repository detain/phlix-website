Plugins

Extend Phlix with a versioned plugin contract — drop in, the loader picks it up.

Plugin Model

LifecycleInterface + Manifest

  • Implement LifecycleInterface in your plugin class
  • Add a manifest.json with name, version, and dependencies
  • Drop the plugin folder into plugins/
  • The plugin loader discovers and initializes it automatically

The bazaar awaits. Install the server, pick your clients, and light the lanterns.

Server

Requires PHP 8.3 or higher with the mbstring, json, and curl extensions. Workerman 5.x powers the async server.

composer create-project detain/phlix-server cd phlix-server php start.php start

View on GitHub for requirements, configuration, and deployment guides.

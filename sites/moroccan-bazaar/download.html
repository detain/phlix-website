Your Passage In

Bring the bazaar to your hardware

Phlix Server runs on your own Linux host. One line, a fresh Ubuntu or Debian — and your media is yours again.

Phlix Server

PHP 8.3+, MySQL, ffmpeg required. The installer targets a fresh Ubuntu/Debian host and also compiles the Swoole and php-uv extensions from source, skipping the build when they already load. Default ports: HTTP on :8096 behind HAProxy on :80/:443, DLNA discovery on 1900/udp.

One line, on a fresh Ubuntu or Debian host
curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

Prompts for install path, database credentials and hostname when run in a terminal; runs fully unattended when piped or given -y.

Provision HTTPS in the same run
curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh \ | sudo bash -s -- --domain phlix.example.com --admin-email you@example.com
Build from source (development, not an install)
Not an install — development checkout only
git clone https://github.com/detain/phlix-server.git cd phlix-server composer install

This creates no database, no service, and runs no migrations. Never present it as the way to install Phlix.

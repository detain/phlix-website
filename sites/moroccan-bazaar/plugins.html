Plugins

A real contract. A versioned manifest. Drop a plugin in and the loader picks it up — no ceremony required.

The plugin model

Every plugin implements LifecycleInterface and ships a manifest.json with a versioned schema. The server's plugin loader scans the plugins/ directory on startup, validates the manifest, and registers the plugin's hooks.

Plugins can extend metadata providers, add new endpoints, contribute to the EPG, or hook into playback events. The contract is documented and stable.

Ecosystem plugins

Browse the detain GitHub org for community and reference plugins. The phlix-plugin-example repo is the canonical starting point.

Phlix Hub

Your dome does not have to be the only one you can see. The Hub is a directory and a relay: sign in once, and every server you own answers — even the ones sitting behind a home router.

What the Hub does

The Hub keeps a cloud directory of your servers and holds the far end of a reverse-tunnel relay, which is how it handles NAT: the server dials out, the Hub passes your client through, and nothing needs to be exposed inward.

The precise term: NAT traversal

Plainly: your router hides your server from the outside, on purpose. Rather than punching a hole in it, the server keeps an outbound line open to the Hub, and your phone or Roku is passed along that same line.

Self-host it, or use the public hub

phlix-hub is its own repository — the cloud directory and the relay together. Run it on a box you control, or use the public hub and skip the extra deployment. Both are the same software.

Hub mode in the clients

The Roku channel and the Windows desktop app both carry a hub mode: sign in to the Hub instead of typing a server address, pick the observatory you want, and watch. The mobile app carries the same sign-in, with token refresh.

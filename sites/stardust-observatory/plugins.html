Shelved in the library — the plugin bench

Plugins

The interchangeable lenses of the observatory. A plugin is a small PHP package with a versioned manifest; the loader finds it, and the lifecycle hooks tell it when to wake.

The plugin model

Every plugin implements LifecycleInterface and ships a manifest that declares its version and capabilities. Drop it into the plugins/ directory and the loader picks it up — no core patching, no rebuild.

Write your own

Copy phlix-plugin-example, rename the manifest, implement the lifecycle methods you care about, and drop the folder in. The manifest is versioned, so the loader can tell you plainly when a plugin was written against an older contract.

One server. All your clients. Everything stays on your hardware, behind your own four walls.

Server

The Phlix server is a PHP 8.3+ application built on Workerman 5.x. Drop it on any PHP 8.3 host, point it at your media folders, and you're live. 

composer create-project detain/phlix-server
cd phlix-server
php start.php start

Plugins

The wall has room for more spray cans. Phlix has a real plugin contract — not just a hook, not just a directory. A versioned interface.

The Plugin Model

1

Implement LifecycleInterface. Four methods: onInstall(), onEnable(), onDisable(), onUninstall(). The loader calls them at the right moment — not when you feel like it.

2

Ship a manifest. manifest.json declares your plugin's name, version, schema version, and which Phlix version it targets. The loader validates it before your code ever runs.

3

Drop it into plugins/. That's it. The scanner picks it up on the next startup. No symlinks, no registration calls, no config edits.

Write Your Own

Start from phlix-plugin-example. It has the skeleton, the manifest, and the four lifecycle methods wired up. Replace the logic, update the manifest, and drop it in plugins/.

Read the developer docs for the full LifecycleInterface reference and the manifest schema.

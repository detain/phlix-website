Plugins

Drop in a plugin, the server picks it up. No restart, no config gymnastics. A real contract, not a hack.

Plugin model

Every plugin implements LifecycleInterface and ships a manifest. The server loader scans the plugins directory on boot, validates the manifest, and registers hooks automatically.

1

Implement LifecycleInterface — onInstall(), onBoot(), onUninstall() hooks.

2

Write a manifest.json with version, name, author, and the services your plugin provides.

3

Drop the plugin folder into plugins/. The loader picks it up on the next boot. 

{
  "name": "my-metadata-provider",
  "version": "1.0",
  "author": "Your Name",
  "class": "MyMetadataProvider\\Plugin",
  "services": ["metadata.provider"]
}

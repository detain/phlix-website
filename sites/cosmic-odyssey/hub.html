What the Hub Does

Phlix Hub is a reverse-tunnel relay. Your server initiates an outbound connection to the hub and keeps it alive. When a client reaches the hub looking for your server, the hub routes the traffic through that already-open tunnel — no port forwarding, no dynamic DNS, no exposing your server to the internet.

Sign in once, and every client configured with your Hub credentials can reach your server from anywhere. The hub handles NAT traversal automatically.

Self-Host or Use the Public Hub

The public hub at hub.phlix.io is free to use for personal setups. For organisations or those wanting full control, you can self-host phlix-hub on your own infrastructure.

Either way, the client experience is identical — the hub is transparent to the end user.

Hub Mode in Clients

Every native Phlix client — Roku, Samsung Tizen, Windows, and Mobile — ships with Hub mode built in. When Hub mode is enabled, the client connects via the relay instead of looking for the server on the local network. Toggle it from the client's connection settings.

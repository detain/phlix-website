Plugins

A real contract, a manifest schema, and a reference starter. Extend any orbit of the Phlix system.

Plugin Model

LifecycleInterface + manifest

Every plugin implements LifecycleInterface and ships a manifest.json that describes its identity, dependencies, and entry points. Drop the plugin into plugins/ and the loader picks it up automatically.

manifest.json { "name": "my-metadata-provider", "version": "1.0.0", "entry": "MyPlugin.php", "lifecycle": "metadata-provider" }

See phlix-plugin-example for the smallest working starter — a reference metadata-provider plugin you can fork and adapt.

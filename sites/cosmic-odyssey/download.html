Launch Sequence

Server — One line, on a fresh Ubuntu or Debian host

php 8.3+ · mysql · ffmpeg · ubuntu / debian curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

Installs system packages (PHP 8.3+, MySQL, ffmpeg), creates a dedicated phlix system user, a MySQL database and user, an env file at /etc/phlix/env with a generated PHLIX_SECRET_KEY, runs database migrations, installs a systemd phlix-server service, and sets up an HAProxy reverse proxy with an auto-renewing Let's Encrypt certificate. Prompts for install path, database credentials and hostname when run in a terminal; runs fully unattended when piped or given -y.

Provision HTTPS in the same run

With domain and admin email

single command — includes letsencrypt curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh \ | sudo bash -s -- --domain phlix.example.com --admin-email you@example.com
Not an install — development checkout

Build from source

development only — no database, no service, no migrations git clone https://github.com/detain/phlix-server.git cd phlix-server composer install

A development checkout only. Does not create a database, a service, or run migrations. Never present it as the way to install Phlix.

Philosophy

Phlix started with a simple observation: the best media server is the one you control. Not the one that decides when your library is unavailable, or which features require a subscription, or where your viewing data travels. Phlix is built to be self-hosted, plugin-extensible, and transparent in its operation — a server that stays out of your way and lets you focus on the library, not the tool.

Every decision in the project traces back to that principle: local-first, open-source, and built for people who want to own their infrastructure the way they own their media.

License

Phlix Server and the Hub are MPL-2.0 — open source, and you can build on them commercially. If you modify a Phlix file, that file stays open; anything you add alongside it is yours. The shared libraries, plugins, and clients are MIT so you can build on them freely.

MPL-2.0 is weak copyleft. See the full licence text on GitHub.

Contributing

Phlix lives under the detain GitHub org. All repos accept issues and pull requests. The fastest path to contributing is to fork phlix-server or phlix-plugin-example and open a PR.

Common Queries

Answers to the questions we receive from the void.

Is Phlix like Plex / Jellyfin / Emby?
Yes — same job, different stack. Phlix is built in PHP 8.3+ on Workerman, ships with a versioned plugin contract, and includes a hub for accessing remote servers behind NAT without a third-party tunnel.
Do I need to expose my server to the internet?
No. Run Phlix on your LAN and use the Phlix Hub's reverse-tunnel relay to reach it from your phone or Roku at a friend's house. You can self-host the hub, or use the public one.
What formats are supported?
Anything FFmpeg can read. Direct play when the client supports it; transcoded HLS otherwise. Per-device quality profiles pick the right bitrate automatically.
Is there a mobile app?
Yes — React Native, available on iOS and Android. Currently in beta.
Can I write plugins?
Yes. Implement LifecycleInterface, ship a manifest, drop it in the plugins directory. See phlix-plugin-example for the smallest working starter.
Will this run on my old server?
Yes — if it runs Debian or Ubuntu with PHP 8.3+, MySQL, and ffmpeg. The install script handles the full dependency chain on a fresh host. Check the full requirements before starting.
Do I have to open my network to the void?
No. Run Phlix on your LAN and use the Phlix Hub's reverse-tunnel relay — your server initiates the connection outward, so no inbound ports need to be opened. You stay invisible unless you choose to be found.
Can I steer the ship myself — write my own systems?
Yes. Implement LifecycleInterface, ship a manifest, drop it in the plugins directory. See phlix-plugin-example for the smallest working starter — it's a reference metadata-provider plugin you can fork and adapt to any system you want to extend.

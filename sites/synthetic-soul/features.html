Features

Everything you need to build a personal media streaming platform that puts you in control.

Library that organizes itself

Folder-watcher hashes mtimes, scanner parses S01E02 / (2020) titles, ItemRepository hydrates metadata_json. Add a file, see it appear. Phlix monitors your media directories and automatically picks up new content, organizing it by type, season, and metadata without any manual intervention.

SyncPlay across the room or across the country

Weighted-mean NTP offset over 5 samples keeps every device locked to the same frame. Play, pause, seek — everyone moves together. Whether you're in the same room or across the country, SyncPlay ensures perfectly synchronized playback for movie nights with friends and family.

Transcoding that picks the right quality

QualitySelector profiles for mobile-low, mobile-high, web, and tv-4k. CRF 23/28 libx264/libx265 with HLS master and variant playlists. Phlix automatically selects the best quality for each device, transcode only when needed, and direct play when possible to preserve quality and reduce server load.

Multi-user, multi-profile, parental controls

JWT auth with refresh tokens, Argon2ID password hashing, up to 5 profiles per user, 4- or 6-digit PINs, rating filter from G to NC-17. Every family member gets their own profile with personalized recommendations, watch history, and parental controls to filter content by rating.

Live TV with DVR + EPG

ChannelManager, GuideManager, and Recorder give you scheduled recordings and a guide that doesn't make you click through menus. Watch live TV, schedule recordings, and browse the program guide — all integrated into the same interface as your on-demand library.

DLNA for the devices you already own

ContentDirectory, AvTransport, and a DeviceRegistry mean your old smart TV doesn't need a new app. Phlix speaks the universal DLNA protocol, so you can stream to any device that supports DLNA — gaming consoles, smart TVs, wireless speakers — without installing anything.

Plugin system with a real contract

LifecycleInterface + manifest schema. Drop a plugin in, the loader picks it up. See phlix-plugin-example for the reference implementation. The plugin system uses semantic versioning and a clear lifecycle interface, so you always know what you're getting and how to extend Phlix.

Phlix Hub — reach any of your servers from anywhere

Sign in once. Reverse-tunnel relay handles NAT. Self-hostable, or use the public hub. Phlix Hub lets you access your home server from anywhere without configuring routers, opening ports, or paying for dynamic DNS services.

Plugins

Extend Phlix with a versioned plugin contract that just works.

Plugin Model

A real contract, not a suggestion.

LifecycleInterface

Every plugin implements the LifecycleInterface. This gives Phlix a predictable lifecycle: install, enable, disable, uninstall. No guessing, no edge cases.

Required methods:

  • onInstall() — called when plugin is first added
  • onEnable() — called when plugin is activated
  • onDisable() — called when plugin is deactivated
  • onUninstall() — called when plugin is removed

Manifest Schema

Each plugin ships a manifest.json that declares its identity, version, dependencies, and the services it provides. The loader validates everything before touching your server.

manifest.json
{ "name": "my-metadata-provider", "version": "1.0.0", "description": "Fetches metadata from MyAPI", "lifecycle": { "interface": "LifecycleInterface" }, "provides": ["metadata-provider"] }

Drop-in Loading

Drop a plugin folder into plugins/, and the loader picks it up automatically. No configuration, no symlinks, no service restarts — just drop and go.

plugins/ my-metadata-provider/ manifest.json src/ MyProvider.php another-plugin/ manifest.json src/

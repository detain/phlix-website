Access from anywhere

Phlix Hub

Sign in once. Reach any of your servers from anywhere. No port forwarding, no third-party tunnel service.

What the Hub does

Reverse-tunnel relay

Phlix Hub sits between your clients and your servers. When you configure a server with Hub mode, it establishes an outbound connection to the Hub — your server never opens an inbound port.

When you're away from home and want to watch something on your server back home:

  • Your client connects to the Hub (outbound — no firewall changes needed)
  • The Hub routes traffic through the existing server connection
  • No NAT traversal configuration, no dynamic DNS, no port forwarding
Deployment

Self-host or use the public hub

Public Hub

Use the hosted hub at hub.phlix.app. Register your servers and clients, sign in once, and access your media from anywhere. No setup required beyond enabling Hub mode in your server config.

Self-hosted

Run your own Phlix Hub instance. Full control over the relay infrastructure. All traffic stays within your network or your chosen hosting provider.

Clients

Hub mode in clients

Roku, Windows, and Mobile clients all support Hub mode — when enabled, the client connects through the Hub instead of directly to your server. Switch between your home server and remote servers without reconfiguring.

  • Roku — Hub mode with automatic server discovery
  • Windows — System tray toggle for Hub vs direct mode
  • Mobile — Token refresh handles seamless reconnection

Any DLNA device connects directly — DLNA doesn't use Hub mode, so it works only on your local network.

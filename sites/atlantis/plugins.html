Plugin system with a real contract

LifecycleInterface + manifest schema. Drop a plugin in, the loader picks it up. Versioned contract means your plugins won't break across upgrades.

Plugin Model

How plugins work

1. Implement LifecycleInterface

Every plugin implements LifecycleInterface with onInstall(), onEnable(), onDisable(), and onUninstall() hooks. The loader calls these at the right moments during the plugin lifecycle.

2. Ship a manifest

Every plugin has a manifest.json declaring its name, version, dependencies, and the interfaces it implements. The loader validates this before touching any code.

3. Drop into plugins/

Place your plugin directory under plugins/. Phlix scans this directory on startup, validates manifests, and enables plugins in dependency order. No configuration required.

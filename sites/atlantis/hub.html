The Relay

Phlix Hub

Sign in once. Reverse-tunnel relay handles NAT. Self-hostable, or use the public hub. Your server behind a firewall? The Hub punches through so you can watch anywhere.

What the Hub does

Reach any server, anywhere

Reverse-tunnel relay

Phlix Hub establishes an outbound tunnel from your server to the Hub relay. When you want to connect, the Hub routes traffic through that tunnel. No port forwarding. No dynamic DNS. No exposing your network.

NAT traversal

Your server is behind a router? The Hub's relay handles the NAT problem by being the one endpoint that's always reachable. Your server calls out to it, and the Hub keeps the connection warm.

Cloud directory

The Hub maintains a registry of your servers. Sign in once, see all your servers. Pick which one you want and the Hub connects you.

Hosting options

Self-host or use the public hub

Public Hub

Use the public Hub at hub.phlix.dev. No setup, no server. Just register your Phlix server with the Hub and you're reachable anywhere. Run by the Phlix team, free for personal use.

Self-hosted Hub

Host your own Hub. Full control, same protocol. Clone phlix-hub, run it on a VPS with a public IP, and point your servers at it. All traffic stays on infrastructure you own.

View phlix-hub on GitHub

Hub in clients

Built into every client

Every Phlix client has Hub mode built in. When you enable Hub mode, your client connects through the Hub relay instead of directly to your server. The same sign-in, the same library, just reachable from anywhere.

Hub mode is available in the Roku, Windows, and Mobile clients. Samsung Tizen support coming soon.

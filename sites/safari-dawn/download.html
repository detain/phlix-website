Download Phlix

Self-host your media in minutes. One line on Ubuntu or Debian.

Server

Requires PHP 8.3+, MySQL, ffmpeg. The installer targets a fresh Ubuntu/Debian host and also compiles the Swoole and php-uv extensions from source.

Install curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

One line, on a fresh Ubuntu or Debian host. Installs system packages, creates a dedicated phlix system user, a MySQL database and user, an env file at /etc/phlix/env, runs database migrations, installs a systemd phlix-server service, and sets up an HAProxy reverse proxy with an auto-renewing Let's Encrypt certificate.

HTTPS curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh \ | sudo bash -s -- --domain phlix.example.com --admin-email you@example.com

Provision HTTPS in the same run with your domain and email.

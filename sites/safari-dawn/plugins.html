Plugins

Extend Phlix with a versioned plugin contract — no forks, no patches.

Plugin Model

Phlix's plugin system is built around a clear contract: implement LifecycleInterface, ship a manifest, drop it in the plugins/ directory. The loader handles the rest.

1

Implement LifecycleInterface

Define onInstall, onEnable, onDisable, and onUninstall hooks.

2

Create manifest.json

Declare name, version, dependencies, and autoload.

3

Drop into plugins/

The loader scans and picks up your plugin automatically.

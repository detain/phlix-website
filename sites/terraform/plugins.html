Plugins

Extend Phlix with a real versioned plugin contract.

Plugin model

Phlix plugins implement LifecycleInterface and ship a manifest file. Drop a plugin into the plugins/ directory and the loader picks it up automatically.

manifest.json 
{
  "name": "my-metadata-provider",
  "version": "1.0.0",
  "type": "metadata-provider",
  "entry": "MyMetadataProvider.php",
  "extends": {
    "LifecycleInterface": "src/MyMetadataProvider.php"
  }
}

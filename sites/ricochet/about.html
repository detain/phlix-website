About Phlix

Self-hosted media server built for power users.

Phlix is an open-source PHP media server that puts you in control. No subscriptions, no cloud dependency, no data harvesting. Just your media, on your hardware, accessible everywhere.

Started as a personal project to solve a specific problem: how do you self-host a media server that's powerful enough for power users but simple enough to actually use? Years later, Phlix runs on everything from Raspberry Pis to dedicated servers, serving thousands of users worldwide.

The Ricochet brand kit represents Phlix's personality: fast, kinetic, and unapologetically bold. It's a media server that refuses to travel in a straight line.

# Ricochet Site

## Brand Kit
- **Name**: Ricochet
- **Archetype**: Outlaw (kinetic, unpredictable, bouncy)
- **Experience**: immersive
- **Palette**: #FF9F1A (Electric Orange), #2EC4B6 (Teal), #E71D36 (Crimson), #011627 (Navy), #FDFFFC (Ghost White)

## Visual Identity
- Bullet holes and spark ricochets
- Wall penetration reveals
- Trajectory lines between sections
- Bounce physics animations
- Speed-line backgrounds

## Files
- `index.html` - Main landing page
- `features.html` - Features showcase
- `download.html` - Download/install instructions
- `docs.html` - Documentation
- `plugins.html` - Plugins listing
- `hub.html` - Plugin hub
- `clients.html` - Client apps
- `about.html` - About page
- `404.html` - Error page
- `css/` - Stylesheets (base, theme, components, animations)
- `js/` - JavaScript (ricochet-physics, spark-particles, main)
- `img/` - Favicon and assets

## Design Principles
- Dark Navy backgrounds
- Electric Orange primary CTA
- Teal bounce-point markers
- Crimson impact/featured glow
- Spark particle trails following cursor
- Trajectory lines mapping navigation paths
- Wall penetration reveals on cards

Installation

Phlix requires PHP 8.3 or higher, a web server (Apache or Nginx), and MySQL/MariaDB. The recommended way to install is via our one-line installer:

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

This will download the latest release, set up the database, create the configuration, and configure your web server.

Manual Installation

If you prefer to install manually:

  1. Download the latest release from GitHub
  2. Extract to your web root
  3. Create a MySQL database and user
  4. Import the schema from install/schema.sql
  5. Copy config/config.php.example to config/config.php and edit

Configuration

Phlix stores configuration in config/config.php. Key settings include database credentials, media paths, and server options.

// Database
define('DB_HOST', 'localhost');
define('DB_NAME', 'phlix');
define('DB_USER', 'phlix');
define('DB_PASS', 'your-password');

// Media Paths
define('MEDIA_ROOT', '/mnt/media');

// Server
define('SITE_URL', 'https://phlix.yourdomain.com');
define('ADMIN_EMAIL', 'admin@yourdomain.com');

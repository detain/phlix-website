Download

Self-host your media in minutes. PHP 8.3+, MySQL, FFmpeg required.

Server

Install Phlix on a fresh Ubuntu or Debian host. The installer sets up PHP 8.3+, MySQL, FFmpeg, a systemd service, and HAProxy with Let's Encrypt.

One line, on a fresh Ubuntu or Debian host
curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

The installer provisions HTTPS automatically. See the installation docs for full details.

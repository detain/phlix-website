Plugins

Extend Phlix with a versioned plugin contract. Drop in a plugin, the loader picks it up.

Plugin model

Phlix plugins implement the LifecycleInterface and ship a manifest that declares the plugin version, its entry point, and any dependencies. Drop the plugin into the plugins/ directory and Phlix discovers and loads it automatically.

The contract is versioned, so plugins continue working across Phlix updates without breaking your install.

Ecosystem plugins

The Phlix ecosystem includes reference plugins that demonstrate the contract in action. Once you understand the model, you can write plugins for metadata providers, subtitle sources, hardware integrations, or anything else.

Write your own

The phlix-plugin-example repository is the smallest working starter — a reference metadata-provider plugin you can use as a template. It shows the manifest format, the lifecycle hooks, and how to wire up custom functionality.

https://github.com/detain/phlix-plugin-example

Download

Self-host in minutes. The server runs on PHP 8.3+ with Workerman 5.x.

Server requirements

PHP 8.3 or higher with the gd, mbstring, curl, and json extensions. FFmpeg for transcoding. That's it. 

composer create-project detain/phlix-server
cd phlix-server
composer install
php server.php start

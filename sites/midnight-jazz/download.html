Get Tickets

One line and you're the projectionist.

PHP 8.3+, MySQL, ffmpeg. The install handles everything else.

Ubuntu / Debian — one line, fresh host 
$ curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

Provision HTTPS in the same run — add --domain phlix.example.com --admin-email you@example.com

PHP 8.3+ Requires PHP 8.3 or newer
~5 min Typical install time
:8096 Default HTTP port (behind HAProxy :80/:443)

Not an install? Build from source — git clone + composer install. This creates no database, no service, and runs no migrations. It's a development checkout only.

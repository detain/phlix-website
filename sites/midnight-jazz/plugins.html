Plugins

Extend Phlix with a real contract. No forks, no hooks-to-nowhere.

Plugin model

Every plugin implements LifecycleInterface and ships a manifest.json. Drop the plugin directory into plugins/ and the loader picks it up on the next start. No config editing, no restart rituals. 

// YourPlugin/src/Plugin.php
use Detain\Phlix\Plugin\LifecycleInterface;

class Plugin implements LifecycleInterface {
    public function onEnable(): void { /* ... */ }
    public function onDisable(): void { /* ... */ }
    public function getManifest(): array {
        return [
            'name'        => 'my-metadata-provider',
            'version'     => '1.0.0',
            'author'      => 'You',
            'description' => 'Grabs metadata from MyAPI',
        ];
    }
}

Start from phlix-plugin-example and build a metadata provider, a new scanner, or anything else the loader can discover. The manifest schema is versioned — your plugin states which Phlix version it targets.

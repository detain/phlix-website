Build on the contract.

LifecycleInterface + manifest schema. Drop a plugin in, the loader picks it up.

The plugin model

Phlix ships with a versioned plugin contract. Implement the LifecycleInterface, write a manifest, and your plugin loads automatically when dropped into the plugins/ directory.

manifest.json 
{
  "name": "my-metadata-provider",
  "version": "1.0.0",
  "description": "Custom metadata fetcher",
  "entry": "MyPlugin.php",
  "lifecycle": "metadata",
  "compat_version": "1.0"
}
MyPlugin.php 
use Phlix\Plugin\LifecycleInterface;

class MyMetadataProvider implements LifecycleInterface {
    public function bootstrap() : void {
        // Called when plugin is loaded
    }

    public function shutdown() : void {
        // Called on server stop
    }
}

Plugins

A versioned contract means plugins just work — drop them in, the loader picks them up.

The plugin model

Phlix plugins implement the LifecycleInterface and ship a manifest file. Drop the plugin directory into plugins/, and Phlix loads it on the next restart.

What's in a plugin

  • manifest.json — name, version, API version, entry point
  • src/Plugin.php — implements LifecycleInterface
  • Any supporting files the plugin needs

Ecosystem plugins

These plugins are maintained by the Phlix team and demonstrate the range of what's possible:

phlix-plugin-anidb Anime metadata from AniDB
phlix-plugin-anilist Anime metadata from AniList
phlix-plugin-myanimelist Anime metadata from MyAnimeList
phlix-plugin-trakt Watch history sync with Trakt.tv
phlix-plugin-omdb Movie metadata from OMDb
phlix-plugin-opensubtitles Subtitle search via OpenSubtitles
phlix-plugin-lastfm Scrobble listens to Last.fm
phlix-plugin-musicbrainz Music metadata from MusicBrainz

Write your own

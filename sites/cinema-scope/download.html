Download

Self-hosted media server for Ubuntu and Debian. PHP 8.3+, MySQL, FFmpeg required.

Install on Ubuntu or Debian

One line, on a fresh host. Installs PHP 8.3+, MySQL, FFmpeg, creates a system user, sets up the database, and configures systemd and HAProxy with Let's Encrypt.

Terminal 
curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

The installer prompts for install path, database credentials and hostname when run in a terminal; runs fully unattended when piped or given -y. Default ports: HTTP on :8096 behind HAProxy on :80/:443, DLNA discovery on 1900/udp.

For HTTPS in the same run:

Terminal 
curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh \
  | sudo bash -s -- --domain phlix.example.com --admin-email you@example.com

Requirements

PHP 8.3+, MySQL, FFmpeg. The installer targets a fresh Ubuntu/Debian host and also compiles the Swoole and php-uv extensions from source, skipping the build when they already load.

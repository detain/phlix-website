Phlix Hub

Access your servers from anywhere. No ports to open, no dynamic DNS to manage.

What the Hub Does

The Phlix Hub is a cloud directory and reverse-tunnel relay that solves the NAT traversal problem. When your Phlix server is behind a router or firewall, the Hub lets your clients reach it without any port forwarding configuration.

Reverse-Tunnel Relay

Your server establishes an outbound connection to the Hub. When a client wants to connect, it authenticates through the Hub, which routes traffic through the existing tunnel. No inbound ports needed.

NAT Traversal

Most home networks don't have a public IP or can't port-forward. The Hub's relay architecture means your server just needs an outbound internet connection — the same way your browser reaches websites.

Self-Host or Use the Public Hub

Public Hub: The maintainers run a free public Hub at hub.phlix.dev. Sign up, add your server, and you're done.

Self-Hosted: Deploy your own Hub instance. Full control, no data leaves your infrastructure. See phlix-hub on GitHub for deployment options.

Self-hosted Hub 
git clone https://github.com/detain/phlix-hub.git
cd phlix-hub
docker compose up -d

Hub Mode in Clients

Every native Phlix client supports Hub mode. When enabled:

  • Sign in once with your Hub account
  • Your servers appear automatically wherever you are
  • Switch between home and remote servers seamlessly
  • All traffic routes through the Hub's encrypted tunnel

Hub mode is available in the Roku, Samsung Tizen, Windows, and Mobile clients.

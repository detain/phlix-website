Plugins

Extend Phlix with a versioned plugin contract.

Plugin Model

Phlix plugins implement the LifecycleInterface and ship a manifest. Drop the plugin into the plugins/ directory and the loader picks it up automatically.

  • LifecycleInterface — defines onEnable, onDisable, and onInstall hooks
  • Manifest — version, dependencies, and autoload mapping
  • Versioned contract — plugins声明 their compatible Phlix version range

Ecosystem Plugins

The plugin ecosystem includes providers for metadata, storage adapters, and more. Check the GitHub org for community plugins.

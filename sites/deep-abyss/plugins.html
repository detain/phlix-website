Plugins

Extend Phlix with a versioned plugin contract.

Plugin model

Phlix plugins implement LifecycleInterface and ship a manifest. Drop a plugin into plugins/, the loader picks it up.

Minimal manifest (manifest.json)

{
  "name": "my-metadata-provider",
  "version": "1.0.0",
  "entry": "MyPlugin.php",
  " lifecycle": "metadata-provider"
}

The plugin loader calls your LifecycleInterface methods at the right moment — no hooking, no events to register manually.

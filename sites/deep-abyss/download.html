Download

Install the server and connect your devices.

Server

PHP 8.3+, MySQL, ffmpeg required. The installer targets a fresh Ubuntu/Debian host and also compiles the Swoole and php-uv extensions from source.

One line, on a fresh Ubuntu or Debian host 
curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

The installer provisions HTTPS automatically. Default ports: HTTP on :8096 behind HAProxy on :80/:443, DLNA discovery on 1900/udp.

For custom domain + HTTPS in the same run:
curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash -s -- --domain phlix.example.com --admin-email you@example.com

Building from source?
git clone https://github.com/detain/phlix-server.git && cd phlix-server && composer install
(Development checkout only — does not create a database, service, or run migrations.)

Phlix Hub

Reach any of your servers from anywhere — without opening a port.

What the Hub does

The Hub is a cloud directory and reverse-tunnel relay. Sign in once, and your devices can find your server regardless of where you are — no DMZ, no port forwarding, no dynamic DNS.

The Hub uses a reverse-tunnel relay to bridge your LAN-hosted server to any external client. NAT traversal happens automatically.

Self-host or use the public hub

You have options:

  • Public Hub: Use the hosted hub at phlix-hub — zero configuration, works immediately.
  • Self-hosted: Run your own Hub instance on any VPS. Full control, same protocol.

Hub mode in clients

The Roku, Windows, and Mobile clients all support Hub mode — authenticate once and your servers appear automatically, wherever they are.

Try the public Hub

No account required for local use. Hub mode is optional.

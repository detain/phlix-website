# Image Generation Prompts — Cavern Depths

This file documents the generation prompts used to create image assets.

## Logo (logo.svg)

**Tool:** Inline SVG (hand-crafted)

**Concept:** Stalactite/crystal formation spelling "Phlix" with bioluminescent glow

**Prompt:** Create a wordmark logo featuring stalactite/crystal formations with "PHLIX" text, using the cavern-depths palette (#4A90D9, #7FFFD4, #0A0F1A). Include bioluminescent dot accents.

## Favicon (favicon.svg)

**Tool:** Inline SVG (hand-crafted)

**Concept:** Stalactite formation in a 32×32 square

**Prompt:** Create a simple stalactite favicon in square format using the cavern-depths palette (#4A90D9, #7FFFD4, #0A0F1A).

## OG Image (og.png)

**Tool:** `node tools/gen-og.mjs --site cavern-depths`

**Concept:** Social share card with cave/underground theme

**Prompt:** 1200×630 social share card with deep cave background (#0A0F1A), bioluminescent teal accent (#7FFFD4), glowing crystal blue (#4A90D9), "Your media. Your library. Your Phlix." headline.

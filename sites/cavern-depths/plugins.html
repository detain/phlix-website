Plugins

Extend Phlix with a versioned plugin contract. Drop a plugin in, the loader picks it up.

Plugin Model

Phlix plugins implement the LifecycleInterface and ship a manifest file. The plugin loader discovers and manages them automatically.

Plugin Structure

plugins/
└── your-plugin/
    ├── manifest.json    # Plugin metadata and configuration
    └── src/
        └── Plugin.php   # Implements LifecycleInterface

The manifest defines the plugin's version, dependencies, and lifecycle hooks. See phlix-plugin-example for the smallest working starter.

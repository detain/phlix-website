Plugins

Extend Phlix with a versioned plugin contract — drop in, the loader picks it up.

Plugin Model

Every plugin implements the LifecycleInterface and ships a manifest.json. Drop the plugin folder into plugins/ and Phlix discovers it on the next startup.

The manifest declares the plugin version, entry point, and any dependencies — giving you a safe, auditable contract. 

{
  "name": "my-metadata-provider",
  "version": "1.0.0",
  "entry": "MyPlugin.php",
  " lifecycle": "metadata-provider",
  "requires": {
    "phlix": ">=2.0.0"
  }
}

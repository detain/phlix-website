About

The philosophy, license, and community behind Phlix.

Philosophy

Phlix exists because your media library is yours. It should live on your hardware, under your control, and follow you anywhere — without subscription fees, vendor lock-in, or data harvesting.

Built in PHP 8.3+ on Workerman, Phlix brings modern async architecture to self-hosted media serving. The plugin system uses a versioned contract so extensions stay compatible across upgrades. The Hub uses reverse tunneling to connect you to your server from anywhere — no port forwarding required.

License

Phlix Server and Phlix Hub are MPL-2.0 — open source, and you can build on them commercially. If you modify a Phlix file, that file stays open; anything you add alongside it is yours.

The shared libraries, plugins, and clients are MIT — you can build on them freely without restrictions.

See MPL-2.0 on GitHub for the full license text.

Phlix is developed in the open on GitHub. Issues, pull requests, and plugin contributions are welcome.

Frequently Asked Questions

Is Phlix like Plex / Jellyfin / Emby?

Yes — same job, different stack. Phlix is built in PHP 8.3+ on Workerman, ships with a versioned plugin contract, and includes a hub for accessing remote servers behind NAT without a third-party tunnel.

Do I need to expose my server to the internet?

No. Run Phlix on your LAN and use the Phlix Hub's reverse-tunnel relay to reach it from your phone or Roku at a friend's house. You can self-host the hub, or use the public one.

What formats are supported?

Anything FFmpeg can read. Direct play when the client supports it; transcoded HLS otherwise. Per-device quality profiles pick the right bitrate automatically.

Is there a mobile app?

Yes — React Native, available on iOS and Android. Currently in beta.

Can I write plugins?

Yes. Implement LifecycleInterface, ship a manifest, drop it in the plugins directory. See phlix-plugin-example for the smallest working starter.

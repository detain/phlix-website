Bridge

Phlix Hub

Bridge any distance. Remote access to your core without exposing ports.

How the Hub works

Phlix Hub creates a secure reverse-tunnel relay between your server and the public Hub service. When you sign in from a remote client, the Hub brokers the connection — your server never exposes ports to the internet.

  • Zero-config: Enable Hub in settings, sign in once, done
  • End-to-end encrypted: All traffic through the relay is encrypted
  • Self-hostable: Run your own Hub relay for complete control
  • No port forwarding: Works behind CGNAT, firewalls, and routers

Using the Hub

Once your server is running, enabling Hub access takes moments:

  1. Open Phlix web interface at http://your-server:8096
  2. Navigate to Settings → Hub
  3. Enable Hub and sign in with your account
  4. Your server appears in the Hub dashboard
  5. Connect from any remote client using your Hub credentials

Self-hosted Hub

For complete control, you can run your own Hub relay server. Clone the phlix-hub repository and deploy on any VPS or cloud provider.

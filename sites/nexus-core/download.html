Server Installation

Run the following command on a fresh Ubuntu or Debian host:

curl -sSL https://phlix.io/install | bash

The installer will set up Phlix Server, configure the database, and start the core services. After installation, access the web interface at http://your-server:8080

System Requirements

  • Ubuntu 20.04+ or Debian 11+
  • 2GB RAM minimum (4GB recommended)
  • 20GB storage minimum
  • FFmpeg for transcoding

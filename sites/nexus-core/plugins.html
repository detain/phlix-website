Plugin System

Extend the nexus with custom functionality using the plugin contract.

Plugin Architecture

Phlix plugins implement the LifecycleInterface and define their capabilities in a manifest. Drop a plugin into the plugins directory and the loader picks it up automatically.

LifecycleInterface

All plugins must implement these methods: 

interface LifecycleInterface {
    onEnable(): void;
    onDisable(): void;
    onInstall(): void;
    onUninstall(): void;
}

Manifest Schema

Each plugin requires a manifest.json: 

{
  "name": "my-plugin",
  "version": "1.0.0",
  "description": "Plugin description",
  "author": "Your Name",
  "lifecycle": "MyPlugin\\MyPluginClass"
}

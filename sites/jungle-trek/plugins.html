Supplements

A versioned plugin contract means your extensions don't break when Phlix updates.

The Plugin Contract

Implement LifecycleInterface, ship a manifest, drop it in the plugins directory. Phlix's loader discovers it and hooks it into the event bus. That's it — no registry edits, no version patching.

manifest.json

{ "name": "my-metadata-provider", "version": "1.0.0", "phlix_version": ">=2.0.0", "entry": "MyMetadataProvider.php" }

Expedition Log

The story, the stack, and the people behind Phlix.

What Is Phlix?

Phlix is a self-hostable media server written in PHP. It streams video, audio, and photos to native clients on Roku, Samsung Tizen, Windows, and mobile (iOS/Android), plus any DLNA-compliant device already on your network.

Built in PHP 8.3+ on Workerman 5.x. The server and Hub are MPL-2.0; shared libraries, plugins, and clients are MIT.

Why PHP?

PHP runs everywhere. Shared hosting, home servers, NAS devices — if it can run PHP, it can run Phlix. Workerman gives us async I/O without sacrificing the simplicity of PHP deployment.

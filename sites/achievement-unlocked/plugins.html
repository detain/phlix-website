Plugins

Extend Phlix with a versioned plugin contract — drop in, the loader picks it up.

Plugin Model

Phlix uses LifecycleInterface + a manifest schema for plugin discovery. Implement the interface, ship a manifest, drop your plugin into the plugins/ directory. The loader handles the rest.

LifecycleInterface

Every plugin implements the lifecycle contract: onEnable(), onDisable(), onInstall(), and onUninstall() hooks.

Manifest Schema

A versioned manifest.json declares your plugin's name, version, dependencies, and which hooks it subscribes to.

Drop-in Loading

Placed in plugins/, the server automatically discovers, validates, and activates your plugin on restart.

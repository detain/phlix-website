Plugin system.

A versioned plugin contract. Install a plugin from Settings → Plugins and enable it.

A real contract.

Phlix plugins implement the LifecycleInterface and ship a versioned manifest. The loader validates the manifest, wires the plugin into the event system, and manages startup and shutdown.

Quick start — reference plugin

https://github.com/detain/phlix-plugin-example

The smallest working starter. Implements LifecycleInterface, defines a manifest, and demonstrates the event hook surface. Use it as a template.

What you can extend

Metadata providers

TMDB, TVDB, Fanart.tv, local NFO — add a new source or override an existing one.

Indexers

Transcoders

Plugin authoring guide

The official catalog

Plugins from the official phlix-plugins catalog are pinned by commit and SHA-256 checksum, so what you install is exactly what was reviewed. Browse and install them from the admin Plugins page; the Phlix docs cover the details.

Flagship plugins in the catalog:

  • Trakt — scrobble playback to Trakt.tv
  • Last.fm — scrobble music playback to Last.fm
  • AniList — anime metadata and watchlist sync
  • OpenSubtitles — download subtitles from OpenSubtitles

Around the catalog sit the shared pieces plugins build on: phlix-contracts (versioned server and app contracts), phlix-syncplay (SyncPlay protocol and time-sync) and phlix-tokens (design tokens).

Extensibility

Plugin system.

LifecycleInterface + manifest schema. Drop a plugin in, the loader picks it up.

A real contract.

Phlix plugins implement the LifecycleInterface and ship a versioned manifest. The loader validates the manifest, wires the plugin into the event system, and manages startup and shutdown.

Quick start — reference plugin

https://github.com/detain/phlix-plugin-example

The smallest working starter. Implements LifecycleInterface, defines a manifest, and demonstrates the event hook surface. Use it as a template.

What you can extend

Metadata providers

TMDB, TVDB, Fanart.tv, local NFO — add a new source or override an existing one.

Indexers

Watch a new folder structure, parse a new naming scheme, trigger scans on external events.

Transcoders

Add a new codec path, a custom quality profile, or a hardware acceleration backend.

UI panels

Extend the web lobby with custom settings panels, dashboard widgets, or admin views.

About Phlix

Philosophy, license, and community

Phlix is built by the detain GitHub org. We build tools we wanted to exist, and share them under MPL-2.0.

Philosophy

Media servers are infrastructure. They should be quiet, reliable, and stay out of your way. Phlix is built on the principle that your library belongs on your hardware — not in someone else's cloud.

We believe a good media server is a tool for people who care about their collection: lossless quality, accurate metadata, synchronised playback across every device, and a plugin system that lets you extend it without forking the core.

The brand kit "Bollywood Dreams" is our first South Asian aesthetic identity — a celebration of the rich visual culture of Indian cinema applied to the experience of watching. Every interface decision in this site is a frame from the most romantic film never made.

License

Phlix Server and the Hub are MPL-2.0. All official clients, phlix-shared, and the plugin example are MIT.

MPL-2.0 means you can use Phlix for any purpose, modify it, redistribute it, and build commercial products on top of it. The one condition is file-level: if you modify a Phlix source file, that file stays under MPL-2.0 — but anything you write alongside it remains entirely yours. The MIT parts carry no such condition at all.

The full license text is available at github.com/detain/phlix-server/blob/master/LICENSE.

Contributing

The Phlix GitHub org (github.com/detain) is where all development happens. Issues, pull requests, and plugin submissions are welcome.

If you're interested in the design system and brand kits — including the "Bollywood Dreams" identity you're currently viewing — the phlix-website repository contains all brand kit source files, the site scaffold, and this documentation.

Frequently asked questions

Priya here, your cinema usher. I have collected every question from the suggestion box — sit back, let me share what I have seen.

Is Phlix like Plex / Jellyfin / Emby?
Yes — same job, different stack. Phlix is built in PHP 8.3+ on Workerman, ships with a versioned plugin contract, and includes a hub for accessing remote servers behind NAT without a third-party tunnel.
Do I need to expose my server to the internet?
No. Run Phlix on your LAN and use the Phlix Hub's reverse-tunnel relay to reach it from your phone or Roku at a friend's house. You can self-host the hub, or use the public one.
What formats are supported?
Anything FFmpeg can read. Direct play when the client supports it; transcoded HLS otherwise. Per-device quality profiles pick the right bitrate automatically.
Is there a mobile app?
Yes — React Native, available on iOS and Android. Currently in beta.
Can I write plugins?
Yes. Implement LifecycleInterface, ship a manifest, drop it in the plugins directory. See phlix-plugin-example for the smallest working starter.
What's the license?
Phlix Server and the Hub are MPL-2.0 — open source, and you can build on them commercially. If you modify a Phlix file, that file stays open; anything you add alongside it is yours. The shared libraries, plugins, and clients are MIT so you can build on them freely.

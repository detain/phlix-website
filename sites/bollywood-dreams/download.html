Your Admission — One Line

Run this on a fresh Ubuntu or Debian host. The installer handles PHP 8.3+, MySQL, FFmpeg, systemd service, and an HAProxy reverse proxy with auto-renewing Let's Encrypt. 

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

Requirements: PHP 8.3+, MySQL, FFmpeg. Prompts for install path, database credentials and hostname; runs fully unattended when piped or given -y. Default ports: HTTP on :8096 behind HAProxy on :80/:443, DLNA discovery on 1900/udp.

Full install guide

Also from source (development checkout — not an install) 

git clone https://github.com/detain/phlix-server.git
cd phlix-server
composer install

The Projection Booth — Ecosystem

The server, the hub, the shared libraries, the docs, and the plugin example — all open source, all on GitHub.

  • phlix-server — The media server itself — PHP 8.3+, Workerman 5.x, async/coroutine
  • phlix-hub — Cloud directory + reverse-tunnel relay — self-hostable or use the public hub
  • phlix-shared — Shared interfaces, DTOs, event types — Composer package (MIT)
  • phlix-docs — End-user, developer, and hub-admin docs — VitePress
  • phlix-plugin-example — Reference metadata-provider plugin — smallest working starter

Get Phlix

Download Phlix

Self-host your media in minutes. Requires PHP 8.3+ and a web server.

Server

Phlix Server is a PHP 8.3+ application built on Workerman 5.x. It requires a web server (Apache or Nginx), a SQL database (MySQL 8+ or MariaDB 10.4+), and FFmpeg for transcoding. 

composer create-project detain/phlix-server
cd phlix-server
composer install
cp .env.example .env
# Edit .env with your database and admin credentials
php artisan key:generate
php artisan serve --port 8080

Full installation instructions are in the documentation.

Ecosystem

  • phlix-server — github.com/detain/phlix-server
    The media server itself — PHP 8.3+, Workerman 5.x
  • phlix-hub — github.com/detain/phlix-hub
    Cloud directory + reverse-tunnel relay
  • phlix-shared — github.com/detain/phlix-shared
    Shared interfaces, DTOs, event types — Composer package
  • phlix-docs — github.com/detain/phlix-docs
    End-user, developer, and hub-admin docs (VitePress)

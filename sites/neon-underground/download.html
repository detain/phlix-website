Download

Get Phlix up and running on your own hardware.

Server

Phoenix requires PHP 8.3+, MySQL, and ffmpeg. Run this on a fresh Ubuntu or Debian host:

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

The installer sets up system packages, creates a dedicated phlix system user, a MySQL database, an env file at /etc/phlix/env with a generated secret key, runs database migrations, installs a systemd service, and configures HAProxy with Let's Encrypt.

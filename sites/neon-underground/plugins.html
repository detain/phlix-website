Plugins

Extend Phlix with a versioned plugin contract.

Plugin Model

Phlix plugins implement LifecycleInterface and ship a manifest. Drop a plugin into the plugins/ directory and the loader picks it up automatically.

{ "name": "my-metadata-provider", "version": "1.0.0", "entry": "MyPlugin.php", " lifecycle": "metadata" }

The manifest declares the plugin's name, version, entry point, and lifecycle type. Plugins receive lifecycle events and can expose services through the standard DI container.

Write Your Own

Start with phlix-plugin-example as your template. Implement LifecycleInterface, write your manifest, and drop it into plugins/.

The plugin system uses semantic versioning so you can depend on specific contract versions. All plugins are MIT licensed.

Plugins

Extend Phlix with a versioned plugin contract — drop in, the loader picks it up.

Plugin Model

Phlix uses a LifecycleInterface + manifest schema for plugin discovery and lifecycle management. Implement the interface, ship a manifest, drop your plugin into the plugins/ directory. 

namespace Phlix\Plugin;

interface LifecycleInterface
{
    public function onEnable(): void;
    public function onDisable(): void;
    public function getManifest(): array;
}

The manifest declares your plugin's name, version, dependencies, and any services it provides. The loader validates the manifest on startup and calls your lifecycle hooks in order.

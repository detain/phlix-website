Plugins

A versioned contract, not a convention. Implement LifecycleInterface, ship a manifest, drop it in. The loader handles the rest.

How it works

1

Implement LifecycleInterface

Write a PHP class that implements the LifecycleInterface. This gives you hooks for install, uninstall, enable, disable, and configuration.

2

Write a manifest

Declare your plugin's name, version, dependencies, and autoload path in the versioned manifest schema.

3

Drop it in

Place the plugin directory in the plugins folder. The loader discovers it, validates the manifest, and registers it on the next server start.

{ "name": "my-metadata-provider", "version": "1.0.0", "lifecycle": "My\\Plugin\\Lifecycle", "provides": ["metadata-provider"], "requires": { "phlix": ">=2.0.0" } }

Ecosystem plugins

The community has plugins for additional metadata sources, hardware integration, and more. Check the GitHub org for what's available.

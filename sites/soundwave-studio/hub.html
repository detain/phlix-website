Relay

The session archive stays at home behind the NAT. Hub relay brings the full library to any device, anywhere.

How the relay works

Your Phlix Server
behind NAT ←→ Phlix Hub Relay
public endpoint ←→ Your Client
anywhere

No port forwarding

Hub handles the NAT traversal. Your server stays firewalled, your library stays accessible.

Sign in once

One authentication touchpoint. Hub routes you to whichever server you need, whenever you need it.

Self-hostable

Run your own Hub relay, or use the public one. Either way, you control the connection.

Hub mode in clients

Every Phlix client supports Hub mode: sign in through the Hub, select a server, and stream as if you were on the same network. Built into Roku, Tizen, Windows, and Mobile.

Connecting via Hub
Hub URL: wss://hub.phlix.io
Auth: OAuth 2.0 (Hub-managed)
Server: discovered via Hub directory

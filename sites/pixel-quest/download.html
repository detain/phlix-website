Download

Install Phlix on your own hardware. One line. Any Ubuntu or Debian host.

Server

Requires: PHP 8.3+, MySQL, FFmpeg. The installer targets a fresh Ubuntu/Debian host and also compiles the Swoole and php-uv extensions from source.

INSTALL COMMAND — UBUNTU / DEBIAN 
curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

Installs system packages, creates a dedicated phlix system user, a MySQL database, an env file at /etc/phlix/env with a generated secret key, runs migrations, sets up a systemd service, and configures HAProxy with auto-renewing Let's Encrypt.

HTTPS: Add --domain yourdomain.com --admin-email you@example.com to provision TLS in the same run.

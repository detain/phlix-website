Plugins

Extend Phlix with a versioned plugin contract — no fork required.

Plugin Model

Every plugin implements LifecycleInterface and ships a manifest.json. Drop the plugin directory into plugins/ and the loader picks it up on the next startup.

  • LifecycleInterface — boot, scan, serve lifecycle hooks
  • manifest.json — name, version, dependencies, permissions
  • Metadata provider plugins (like phlix-plugin-example)
  • Future: transcoder, auth, and storage backends

Ecosystem Plugins

  • phlix-plugin-example

    Reference metadata-provider plugin — the smallest working starter

Write Your Own

The phlix-plugin-example repo is the canonical starting point. It shows how to:

  • Structure your plugin directory
  • Write a manifest with correct schema
  • Implement LifecycleInterface hooks
  • Register metadata providers

Check the repo's README for the full walkthrough.

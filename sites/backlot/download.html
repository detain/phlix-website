Download

Get Phlix running on your own hardware in minutes.

Phlix Server

Requires: PHP 8.3+, MySQL, FFmpeg

One line, on a fresh Ubuntu or Debian host:

Install curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

This installs system packages (PHP 8.3+, MySQL, FFmpeg), creates a dedicated phlix system user, a MySQL database and user, an env file at /etc/phlix/env with a generated PHLIX_SECRET_KEY, runs database migrations, installs a systemd phlix-server service, and sets up an HAProxy reverse proxy with an auto-renewing Let's Encrypt certificate.

Default ports: HTTP on :8096 behind HAProxy on :80/:443, DLNA discovery on 1900/udp.

Provision HTTPS in the same run:

Install with HTTPS curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh \ | sudo bash -s -- --domain phlix.example.com --admin-email you@example.com

Plugin System

A versioned contract. Drop a plugin in; the loader picks it up. No config file to maintain, no framework to learn.

The Plugin Contract

Implement LifecycleInterface and ship a manifest.json. The plugin loader reads the manifest, registers your hooks, and your plugin is live. Nothing else required.

namespace Phlix\Plugin; interface LifecycleInterface { public function onInstall(): void; public function onEnable(): void; public function onDisable(): void; public function onUninstall(): void; }

Manifest schema lives at phlix-plugin-example — the smallest working starter you can fork and build from.

Ecosystem Plugins

Browse the detain org on GitHub for community-contributed plugins. Start with phlix-plugin-example as your template.

Write Your Own

The reference plugin at phlix-plugin-example shows the full structure. Fork it, implement your provider, and drop the result into your Phlix install's plugins/ directory.

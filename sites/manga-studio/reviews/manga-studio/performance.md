## Summary

The site is lightweight and static — no render-blocking JavaScript (all scripts are `defer`), images are SVG (no heavy rasters), CSS-only hero effects (no image requests for the speed-line radial). `font-display: swap` is correctly applied. However, the Google Fonts `@import` in base.css is a render-blocking resource that violates the explicit "No CDN dependencies" spec rule (new_site.md §1). The `@import` blocks CSS parsing and rendering until the Google Fonts CDN responds.

### ❌ MUST FIX

**1. Google Fonts @import is render-blocking CDN dependency (SPEC VIOLATION)**
- **File:** `css/base.css:7`
- **Issue:** `@import url('https://fonts.googleapis.com/css2?family=Black+Han+Sans&family=Rampart+One&family=Noto+Sans+JP:wght@400;700&family=M+PLUS+1p:wght@400;700;800&family=Source+Code+Pro:wght@400;700&display=swap');`
- **Spec rule (new_site.md §1, final paragraph):** "No CDN dependencies in the deployed page (no Google Fonts `<link>` to `fonts.googleapis.com`, no script CDNs). **Self-host fonts** as WOFF2 and declare them with `@font-face` + `font-display: swap`."
- **BUILD_LOG.md:41–52** acknowledges this as an "Intentional deviation" but also says it "should be swapped for local fonts in a fully self-hosted scenario"
- **Impact:** The `@import` is in base.css which is linked in `<head>` without `preload` — it blocks CSS rendering until the Google Fonts CDN responds. This adds latency on every first visit.
- **Fix:** Download all required WOFF2 files (Black Han Sans, Rampart One, Noto Sans JP, M PLUS 1p, Source Code Pro — with Latin + Japanese subsets as needed). Declare them with `@font-face { font-display: swap; }` in base.css. Remove the `@import`.

**2. Google Fonts CDN is the only external network request (privacy/performance)**
- Every page load makes a request to `fonts.googleapis.com` and `fonts.gstatic.com`
- This is a CDN dependency that could fail, be blocked, or add latency
- Even if the spec allowed CDN fonts, a self-hosted approach would be faster after first load (with proper caching headers)
- **Fix:** Same as finding #1 — self-host WOFF2 files

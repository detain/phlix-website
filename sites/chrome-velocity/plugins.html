Plugins

A versioned contract. Implement LifecycleInterface, ship a manifest, drop it in the plugins directory.

Plugin Model

Phlix uses a LifecycleInterface + manifest contract. When Phlix starts, it scans the plugins/ directory and loads any plugin with a valid manifest. There's no registry to update, no config file to edit.

Minimal manifest

{ "name": "my-metadata-provider", "version": "1.0.0", "entry": "MyPlugin.php", "interface": "MetadataProviderInterface" }

The loader calls your plugin's methods at the right points in the server lifecycle: on enable, on disable, on scan, on metadata request.

Write Your Own

Start from phlix-plugin-example, implement the interface methods you need, and drop the folder into your server's plugins/ directory. The loader handles the rest.

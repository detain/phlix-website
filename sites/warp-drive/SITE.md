# Warp-drive Brand Kit — Site Design Document

## Concept & Vision

**Warp-drive** is a brand kit that channels the raw energy of faster-than-light travel. The visual language draws from space distortion effects, light cones, and warp streaks — a high-velocity, high-contrast aesthetic that communicates speed, precision, and cosmic ambition.

## Aesthetic Direction

Futuristic, high-energy, cosmic. Deep black space with electric cyan as the primary accent, punctuated by hot magenta and deep purple for depth and energy.

## Typography

- **Display**: Orbitron / Exo 2 / Rajdhani — bold, geometric, uppercase for headings
- **UI**: Exo 2 / Rajdhani — clean, readable for navigation and UI elements
- **Body**: Exo 2 / Rajdhani — comfortable reading at all sizes
- **Mono**: JetBrains Mono / Fira Code — for code blocks

## Motion

Warp streak background effects, cyan glow on hover, fade-up scroll reveals. All motion respects `prefers-reduced-motion`.

## Assets

- Logo: SVG wordmark with warp streak gradient
- Favicon: Square mark in primary cyan with warp arcs
- OG image: Warp-burst composition with Phlix wordmark

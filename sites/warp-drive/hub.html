Phlix Hub

Sign in once. Reach any of your servers from anywhere.

What the Hub does

Phlix Hub serves two purposes: a cloud directory that lists all your servers, and a reverse-tunnel relay that connects clients to servers behind NAT or firewalls without any manual port forwarding.

Reverse-tunnel relay

When your Phlix server is on a home network behind a router, the Hub's reverse tunnel lets you reach it from anywhere. No exposed ports, no dynamic DNS, no third-party tunnel service.

Cloud directory

Sign in to the Hub once and see all your registered servers — at home, at a friend's place, in a data center. Connect to any of them directly from any client.

Self-host or use the public hub

The Hub is fully self-hostable. Run your own instance for complete control, or use the public Hub — both are functionally identical.

Self-host the Hub

git clone https://github.com/detain/phlix-hub.git
cd phlix-hub
composer install
# see docs for configuration and systemd setup

Hub admin docs

Hub mode in clients

Every Phlix client supports Hub mode — sign in with your Hub account and all your registered servers appear automatically. No IP addresses to remember, no manual server configuration on each device.

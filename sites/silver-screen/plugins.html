Plugins

Extend Phlix with a versioned plugin contract that just works.

LifecycleInterface + Manifest

Every plugin implements LifecycleInterface and ships a manifest file. Drop the plugin into plugins/ and the loader picks it up automatically.

{
  "name": "my-metadata-provider",
  "version": "1.0.0",
  "entry": "MyMetadataProvider.php",
  "api_version": "1.0"
}

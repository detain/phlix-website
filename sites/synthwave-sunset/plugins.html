Plugins

Extend Phlix with a versioned plugin contract. Drop in, the loader picks it up.

Plugin Model

Phlix plugins implement the LifecycleInterface and ship a manifest.json. Drop the plugin into plugins/ and the loader discovers it on the next startup.

// LifecycleInterface interface LifecycleInterface { public function onEnable(): void; public function onDisable(): void; public function getManifest(): array; } // manifest.json { "name": "my-plugin", "version": "1.0.0", "description": "What it does", "author": "Your Name", "requires": { "phlix": ">=3.0.0" } }

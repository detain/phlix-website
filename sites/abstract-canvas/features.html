Gallery wall

The Canvas

Eight features hang here. Two at eye level, four along the wall, two in the margin — and the plugin room next door.

I

Focal works

Two works at eye level

The two the whole studio is built around.

Focal work · SyncPlay

Synchronized watching — every device, every room, the same frame, the same moment.

Press play in one room and every other screen is already there.

The technical mark

Weighted-mean NTP offset over 5 samples keeps every device locked to the same frame. Play, pause, seek — everyone moves together.

Focal work · Library

A living collection that organizes itself the moment you add a file.

Drop a file in the folder; it is catalogued and on screen without you asking.

The technical mark

Folder-watcher hashes mtimes, scanner parses S01E02 / (2020) titles, ItemRepository hydrates metadata_json. Add a file, see it appear.

II

Studies

Studies on the side wall

Smaller marks, each one load-bearing.

Transcoding that picks the right quality

Each screen gets a version it can actually play.

The technical mark

QualitySelector profiles for mobile-low, mobile-high, web, and tv-4k. CRF 23/28 libx264/libx265 with HLS master and variant playlists.

Multi-user, multi-profile, parental controls

Everyone in the house gets their own way in.

The technical mark

JWT auth with refresh tokens, Argon2ID password hashing, up to 5 profiles per user, 4- or 6-digit PINs, rating filter from G to NC-17.

Live TV with DVR + EPG

Broadcast channels, recorded on a schedule you set.

The technical mark

ChannelManager, GuideManager, and Recorder give you scheduled recordings and a guide that doesn't make you click through menus.

Phlix Hub — reach any of your servers from anywhere

Away from home, your own server still answers.

The technical mark

Sign in once. Reverse-tunnel relay handles NAT. Self-hostable, or use the public hub.

III

Marginalia

Footnotes in the margin

Quieter work, and no less finished for it.

DLNA for the devices you already own

The television you already own can play from Phlix with nothing installed.

The technical mark

ContentDirectory, AvTransport, and a DeviceRegistry mean your old smart TV doesn't need a new app.

Plugin system with a real contract

Add a capability without forking the server.

The technical mark

LifecycleInterface + manifest schema. Drop a plugin in, the loader picks it up. See phlix-plugin-example.

Step into the plugin room

The plugin room, next door

Plugins are part of this canvas rather than a wall of their own: implement LifecycleInterface, ship a manifest, drop it in the plugins directory. The full model, and the smallest working starter, are one door away.

The plugin model

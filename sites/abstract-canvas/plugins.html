One door off the canvas

Plugins

A fine addition to the collection, and a small, honest contract: implement an interface, ship a manifest, drop it in.

I

The model

The plugin model

Two pieces

Implement LifecycleInterface and ship a manifest. Drop the plugin into the plugins directory and the loader picks it up — the manifest schema is versioned, so a plugin states what it expects rather than hoping.

The reference plugin in the ecosystem is itself a metadata provider, which is the shortest way to watch the contract work — alongside the TMDB, TVDB, Fanart.tv and local-NFO sources Phlix already reads.

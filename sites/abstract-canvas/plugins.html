Plugins

A real contract, not a suggestion. Implement the interface, ship the manifest, drop it in the plugins directory.

Plugin model

Phlix plugins implement LifecycleInterface and ship a manifest.json. The loader scans the plugins directory on startup, validates the manifest schema, and registers the plugin automatically.

// Minimal plugin structure
plugins/
└── my-plugin/
    manifest.json  // version, name, lifecycle hooks
    src/
        MyPlugin.php  // implements LifecycleInterface

See phlix-plugin-example for the smallest working implementation.

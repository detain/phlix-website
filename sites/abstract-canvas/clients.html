Installations

The Gallery

Five stations, five materials. Each one hangs the same collection in its own light.

01

Roku

stable

Material — native channel

Native Roku channel.

The station on the box already under your television: a native channel that plays HLS, joins a SyncPlay room, skips the intro, and can reach home through the hub.

HLS playback Hub mode Skip intro/outro SyncPlay

View the source for Roku

02

Samsung Tizen

stable

Material — vanilla JS + webpack

Smart TV app.

A Samsung smart-TV station built in vanilla JavaScript, playing files directly when the set can manage it and transcoded HLS when it cannot — laid out for a remote, not a mouse.

Vanilla JS + webpack Direct play + HLS transcoded Remote-optimized UI

View the source for Samsung Tizen

03

Windows

stable

Material — Electron, React, TypeScript

Native desktop.

The desk station: Electron with React and TypeScript, living in the system tray, answering the media keys, and able to work in hub mode when the server is elsewhere.

Electron + React + TypeScript System tray Media keys Hub mode

View the source for Windows

04

Mobile (iOS + Android)

beta

Material — React Native

React Native app.

The station in your pocket: React Native for iOS and Android, covering movies, TV, music and photos, with offline downloads and quiet token refresh. Still in beta.

Movies, TV, Music, Photos Offline downloads Token refresh

View the source for Mobile (iOS + Android)

05

Any DLNA device

stable

Material — no install required

No install required.

The station that needs no installation at all: ContentDirectory and AvTransport over SSDP discovery, so an older set can play from the collection as it is.

ContentDirectory AvTransport Discovery via SSDP

01

The ground

Canvas and brushes — one line to paint

Phlix Server runs on PHP 8.3+ with MySQL and ffmpeg, on a fresh Ubuntu or Debian host you own. One line primes the whole ground: the installer lays in the system packages, creates a dedicated phlix system user, a database and its user, an env file at /etc/phlix/env with a generated secret key, runs the database migrations, installs a phlix-server systemd service, and stands an HAProxy reverse proxy with an auto-renewing Let's Encrypt certificate in front of it. 

# One line, on a fresh Ubuntu or Debian host
curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

Run it in a terminal and it asks for the install path, the database credentials and the hostname; piped or given -y it runs unattended. When it is done the server is on :8096 behind HAProxy on :80 and :443, with DLNA discovery on 1900/udp.

The same line, with HTTPS provisioned in the same run 
curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh \
  | sudo bash -s -- --domain phlix.example.com --admin-email you@example.com
Building from source instead — a development checkout, not an install

Three lines, and deliberately not the same thing: a checkout creates no database, no service and no migrations. Reach for it when you intend to work on Phlix, not when you intend to run it. 

git clone https://github.com/detain/phlix-server.git
cd phlix-server
composer install

The documentation carries the authoritative first-run walkthrough — configuration, library paths, and the metadata keys for TMDB, TVDB and Fanart.tv.

Download

The server runs on your own hardware. The clients stream to your devices.

Server

Requirements: PHP 8.3+ with the mbstring, xml, gd, and zip extensions. Workerman 5.x. Install via Composer, point at your media folder, and start streaming.

# Install via Composer
composer require detain/phlix-server

# Or clone and run directly
git clone https://github.com/detain/phlix-server.git
cd phlix-server
composer install
php start.php start

Ecosystem

phlix-server

The media server itself — PHP 8.3+, Workerman 5.x, async/coroutine server.

phlix-hub

Cloud directory + reverse-tunnel relay for remote access without port forwarding.

phlix-shared

Shared interfaces, DTOs, event types — Composer package for plugin authors.

phlix-docs

End-user, developer, and hub-admin docs built with VitePress.

phlix-plugin-example

Reference metadata-provider plugin — the smallest working starter.

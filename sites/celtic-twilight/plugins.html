The Plugin Model

How Phlix Loads a Plugin

LifecycleInterface + Manifest

Every plugin implements LifecycleInterface and ships a manifest.json. Drop the plugin directory into plugins/ and the loader picks it up on the next startup — no config file editing, no registry calls.

plugins/ └── phlix-my-plugin/ ├── manifest.json # name, version, entry point └── MyPlugin.php # implements LifecycleInterface

What LifecycleInterface Covers

  • Plugin installation / activation
  • On-scan hook (before library scan)
  • On-index hook (after library scan)
  • Transcoding priority override
  • Shutdown / deactivation

"LifecycleInterface + manifest schema. Drop a plugin in, the loader picks it up. See phlix-plugin-example for the smallest working starter."

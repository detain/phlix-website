The Hearth Fire

Why Phlix Exists

Before the first wire was strung or the first screen lit, storytellers gathered at the edge of firelight where the day gave way to dusk. Phlix is a modern continuation of that tradition — a place where every story can rest illuminated, waiting for the next person who wants to hear it.

The library you build here is yours. Not a platform's. Not a corporation's. Every file you add, every choice you make about what to keep and how to organize it — those are acts of stewardship, not mere storage.

Phlix is built in PHP 8.3+ on Workerman — a stack that is readable, extendable, and hospitable to anyone who wants to understand how it works. The plugin contract means the story never has to end with what we imagined.

The Terms of the Keeping

License

Phlix Server and the Hub are MPL-2.0 — open source, and you can build on them commercially. If you modify a Phlix file, that file stays open; anything you add alongside it is yours.

The Gathering

Contributing

The detain GitHub org is where the work lives. Every repository is open, every issue is read, and every pull request is considered by firelight.

If you find a bug, open an issue. If you have a feature in mind, open an issue first to ask whether it belongs in the core or as a plugin. If you want to write the plugin yourself, the LifecycleInterface contract and the phlix-plugin-example repo are the best places to start.

By the Firelight

Questions the Elders Hear

The Sídhe, ancient keeper of stories, answers what seekers ask most — gently, and with precision.

Is Phlix like Plex / Jellyfin / Emby?
Yes — same job, different stack. Phlix is built in PHP 8.3+ on Workerman, ships with a versioned plugin contract, and includes a hub for accessing remote servers behind NAT without a third-party tunnel.
Do I need to expose my server to the internet?
No — the Hub's reverse-tunnel relay handles NAT traversal automatically. No port forwarding, no dynamic DNS, no firewall holes.
What formats are supported?
Anything FFmpeg can read. Direct play when the client supports it; transcoded HLS otherwise. Per-device quality profiles pick the right bitrate automatically.
Is there a mobile app?
Yes — React Native, available on iOS and Android. Currently in beta.
Can I write plugins?
Yes. Implement LifecycleInterface, ship a manifest, drop it in the plugins directory. See phlix-plugin-example for the smallest working starter.
What's the license?
Phlix Server and the Hub are MPL-2.0 — open source, and you can build on them commercially. If you modify a Phlix file, that file stays open; anything you add alongside it is yours. The shared libraries, plugins, and clients are MIT so you can build on them freely.

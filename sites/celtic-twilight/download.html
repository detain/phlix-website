How to Join the Circle

Three steps between you and a library that is yours alone. The threshold is narrow — the world beyond is vast.

Step One — The Threshold

Install the Server

One line, on a fresh Ubuntu or Debian host. The fire is lit the moment the command completes.

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

Installs PHP 8.3+, MySQL, ffmpeg, creates a dedicated phlix system user, sets up a database, runs migrations, and installs a systemd service. HAProxy provides HTTPS on :80/:443.

Provision HTTPS in the same run
curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh \ | sudo bash -s -- --domain phlix.example.com --admin-email you@example.com
Build from source — not an install

This is a development checkout only. It does not create a database, a service, or run migrations. Never present it as the way to install Phlix.

git clone https://github.com/detain/phlix-server.git cd phlix-server composer install

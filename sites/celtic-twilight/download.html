Server requirements

Phlix Server runs on any machine that speaks PHP. The fire burns brightest with: 

PHP 8.3+
Workerman 5.x
500 MB disk space (library not included)
Network access (LAN or internet, depending on your setup)

Install via Composer: composer create-project detain/phlix-server
Or clone from github.com/detain/phlix-server

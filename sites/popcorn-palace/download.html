One command installs everything. Pick your client and join the theater.

Server — Ubuntu / Debian

One line, on a fresh Ubuntu or Debian host

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

Installs PHP 8.3+, MySQL, ffmpeg, creates a dedicated phlix system user, sets up database, env file with generated secret key, systemd service, and HAProxy with auto-renewing Let's Encrypt certificate. Default ports: HTTP :8096 behind HAProxy on :80/:443, DLNA discovery on 1900/udp.

Requirements: PHP 8.3+, MySQL, ffmpeg. Full install docs →

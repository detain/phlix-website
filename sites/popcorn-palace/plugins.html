Plugins

Extend Phlix with a versioned plugin contract. No core modifications required.

Plugin Model

Phlix plugins implement LifecycleInterface and ship a manifest. Drop the plugin into the plugins/ directory and the loader picks it up automatically.

Minimal plugin structure

plugins/ my-plugin/ manifest.json # name, version, provider, lifecycle src/ Plugin.php # implements LifecycleInterface

Ecosystem Plugins

Community and reference plugins extend Phlix's metadata, streaming, and integration capabilities.

phlix-plugin-example

Write Your Own

Start with phlix-plugin-example for the smallest working starter. Implement LifecycleInterface, define your manifest, and drop it into plugins/.

The plugin contract is versioned, so plugins continue working across Phlix updates without modification.

Plugins

Extend Phlix with a versioned plugin contract — no fork required.

The Plugin Model

How it works

  1. Implement LifecycleInterface in your plugin class
  2. Create a manifest.json with your plugin metadata and version
  3. Drop the plugin folder into plugins/
  4. Phlix's plugin loader discovers and initializes it automatically
manifest.json { "name": "my-metadata-provider", "version": "1.0.0", "description": "Custom metadata provider for Phlix", "entry": "MyMetadataProvider.php", "interface": "MetadataProviderInterface" }

The interface contract ensures your plugin integrates cleanly with Phlix's lifecycle — onEnable, onDisable, and onUpdate hooks are called at the right moments.

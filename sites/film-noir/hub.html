Phlix Hub

Access your server from anywhere — without opening ports.

What the Hub Does

The Hub provides two things:

Directory
Find your servers
↔
Hub
Relay + NAT traversal
↔
Your Server
Behind NAT

Reverse-tunnel relay: Your server establishes an outbound connection to the Hub. When you access the Hub, traffic flows through that existing connection — no port forwarding required.

NAT traversal: The Hub helps clients discover and connect to servers that would otherwise be unreachable due to NAT. Your media works whether you're on your home network or across the country.

Self-host or Use the Public Hub

Use the Public Hub

The maintainers run a public Hub at hub.phlix.app. Sign in, register your server, and you're done — no infrastructure to manage.

Self-host the Hub

Run phlix-hub on your own VPS or LAN. Full control over the relay and directory — your traffic never touches a third-party server.

View phlix-hub →

Hub Mode in Clients

All official clients support Hub mode. When enabled, the client connects through the Hub to reach your server instead of your LAN IP. Your media library follows you anywhere.

Set it up once in the client settings — enter your Hub URL (or use the default hub.phlix.app), authenticate, and the client handles the rest automatically.

Ready to get connected?

Install the server and enable Hub mode to access it from anywhere.

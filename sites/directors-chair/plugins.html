Plugins

Extend Phlix with a versioned plugin contract.

Plugin model

Phlix plugins implement LifecycleInterface and ship a manifest. Drop a plugin into the plugins/ directory and the loader picks it up automatically.

Manifest schema 
{
  "name": "my-plugin",
  "version": "1.0.0",
  "description": "What it does",
  "entry": "src/MyPlugin.php",
  "requires": {
    "phlix": ">=1.0.0"
  }
}

The plugin loader handles:

  • Registration and lifecycle events
  • Dependency resolution
  • Automatic discovery and loading

Write your own

Start from phlix-plugin-example — it shows the full structure of a metadata provider plugin with proper manifest and lifecycle implementation.

Key steps:

  1. Clone the example repository
  2. Implement LifecycleInterface in your plugin class
  3. Create your manifest.json
  4. Drop into plugins/

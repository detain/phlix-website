# Dyson Sphere Site Assets

This directory contains all static assets for the Dyson Sphere brand kit site.

## Directory Structure

- `favicon.svg` - Site favicon (stellar megastructure icon)
- `dyson-sphere.svg` - Main Dyson sphere illustration
- `collector-icon.svg` - Energy collector hexagon icon
- `power-icon.svg` - Power indicator icon

## Usage

All SVG icons are optimized for web use and can be embedded directly in HTML or referenced via `<img>` tags.

## Styling

Icons can be styled using CSS:
- Use `fill` for the fill color
- Use `stroke` for outline colors
- Use `filter` for glow effects

Example:
```css
.icon {
  filter: drop-shadow(0 0 10px rgba(255, 184, 0, 0.5));
}
```

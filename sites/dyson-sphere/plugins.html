Plugins

A versioned contract. A manifest schema. Drop a plugin in, the loader picks it up.

Plugin model

Phlix plugins implement LifecycleInterface and ship a manifest.json. The plugin loader reads the manifest, calls your lifecycle methods, and your plugin is live.

Write once, drop into plugins/, done. The manifest declares your plugin's capabilities, version, and dependencies.

See phlix-plugin-example

Ecosystem plugins

The ecosystem is open. Browse the detain GitHub org for community plugins — metadata providers, subtitle fetchers, and more.

Write your own

Start with phlix-plugin-example — the reference metadata-provider plugin. It shows you the smallest working plugin, the manifest format, and the lifecycle hooks.

When your plugin is ready, submit it to the community.

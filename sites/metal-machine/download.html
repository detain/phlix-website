Download

Self-host your media in minutes. One line, on a fresh Ubuntu or Debian host.

Phlix Server

Requires: PHP 8.3+, MySQL, FFmpeg. The installer targets a fresh Ubuntu/Debian host and also compiles the Swoole and php-uv extensions from source. 

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

The installer sets up system packages, creates a dedicated phlix system user, a MySQL database, an env file at /etc/phlix/env, runs migrations, installs a systemd service, and configures HAProxy with Let's Encrypt.

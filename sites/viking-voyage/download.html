Download

Set sail with Phlix. One command installs everything you need on a fresh Ubuntu or Debian host.

Server

Requires PHP 8.3+, MySQL, and ffmpeg. The installer targets a fresh Ubuntu/Debian host and also compiles the Swoole and php-uv extensions from source.

One line, on a fresh Ubuntu or Debian host 1 line
curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash
Installs system packages, creates a dedicated phlix system user, a MySQL database and user, an env file at /etc/phlix/env with a generated PHLIX_SECRET_KEY, runs database migrations, installs a systemd phlix-server service, and sets up an HAProxy reverse proxy with an auto-renewing Let's Encrypt certificate. Prompts for install path, database credentials when run in a terminal; runs fully unattended when piped or given -y.
Provision HTTPS in the same run Add flags
curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash -s -- --domain phlix.example.com --admin-email you@example.com

Note: Building from source (git clone && composer install) is a development checkout only. It does not create a database, a service, or run migrations.

REST API

Phlix exposes a REST API at /api/v1/. All endpoints return JSON and require JWT authentication.

Method Endpoint Description
GET /api/v1/library List all media in the library
GET /api/v1/library/{id} Get single media item details
POST /api/v1/scan Trigger library rescan
GET /api/v1/users List user profiles
POST /api/v1/syncplay Create sync play session

Configuration

Main configuration file: config/config.php

<?php return [ 'database' => [ 'host' => 'localhost', 'name' => 'phlix', 'user' => 'phlix_user', 'pass' => 'secure_password' ], 'media' => [ 'root' => '/path/to/media', 'scan_on_start' => true ], 'transcoding' => [ 'ffmpeg_path' => '/usr/bin/ffmpeg', 'hardware_accel' => 'auto' ], 'hub' => [ 'enabled' => false, 'relay_url' => '' ] ];

Plugin Development

Plugins extend Phlix by hooking into core events. Create plugins/MyPlugin/plugin.php:

<?php use Phlix\Plugin\BasePlugin; class MyPlugin extends BasePlugin { public function onMediaScanned($media) { // Custom metadata processing return $media; } }

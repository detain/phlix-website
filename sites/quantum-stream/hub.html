Signal Relay

Access From Anywhere

Phlix Hub creates a quantum tunnel through NAT — observe your media from any location, any device.

How Hub Works

Phlix Hub uses reverse SSH tunneling to bypass NAT and firewall restrictions. Your server initiates an outbound connection to the Hub relay, creating a tunnel that allows external observers to reach your media field.

1. Connect

Your Phlix server establishes an outbound SSH connection to the Hub relay. No inbound ports needed.

2. Tunnel

The relay creates a quantum tunnel — your server's wave function extends through the connection.

3. Observe

External observers access your media through the relay. All traffic is TLS-encrypted.

Public vs Self-Hosted

Public Hub Relay

Use the free public relay at hub.phlix.cloud. Quick setup — just enable Hub in settings and sign in. All traffic is TLS-encrypted. Best for most users.

Free 5 Users TLS Encrypted

Self-Hosted Relay

Run your own Hub relay in a Docker container. Full control, no third-party involvement. Requires a server with a public IP and domain.

Requires Server Unlimited Users Full Control

Setup

# Enable Hub in config/config.php 'hub' => [ 'enabled' => true, 'relay_url' => 'wss://hub.phlix.cloud', 'auth_token' => 'your-token-here' ]

Generate your auth token in the Phlix admin panel under Settings → Hub. Then your server will automatically connect and maintain the tunnel.

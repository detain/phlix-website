Initialize

Start the Quantum Field

One command. One line. Your media enters superposition.

Quick Initialize

curl -sSL https://get.phlix.cloud | sh

That's it. The quantum field initializes and the observation deck becomes available at http://localhost:8080.

Docker Initialize

docker run -d \ --name phlix \ -p 8080:8080 \ -v /path/to/media:/media \ -v phlix-data:/data \ phlix/server:latest

Data persists in Docker volumes. Mount your media directory to /media inside the container.

Manual Initialize

# Clone the quantum field git clone https://github.com/detain/phlix-server.git cd phlix-server # Initialize dependencies composer install # Configure the field cp config/sample.config.php config/config.php # Start observing php -S localhost:8080 -t public/

Requires PHP 8.3+, MySQL/MariaDB, and sufficient storage for your media superposition.

After Initialization

  1. Open http://localhost:8080 in your browser
  2. Create your first observer account (admin user)
  3. Add media to your library — drop files or configure watch folders
  4. Observe the collapse — metadata surfaces automatically
  5. Stream to any device on your network

Quantum State: Initialized

Your media now exists in superposition across all devices. All states possible until you observe.

Quantum Core — Server

Initialize the Server

The server is the nucleus of your quantum media field. Run this on your host machine:

bash -c "$(curl -fsSL https://get.phlix.net/quantum)"
Requires: Linux / macOS / FreeBSD / Docker

Or use Docker:

docker run -d \
  --name phlix-quantum \
  -p 32400:32400 \
  -v /path/to/media:/media \
  -v /path/to/config:/config \
  phlix/quantum-stream

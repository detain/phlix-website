Quantum Core — Server

Initialize the Server

The server is the nucleus of your quantum media field. Run this on your host machine: 

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash
Requires: PHP 8.3+, MySQL, ffmpeg

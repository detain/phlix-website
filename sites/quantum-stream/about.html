Common Questions

How is this different from Plex/Jellyfin?

Phlix is built in PHP, designed for simple shared hosting environments. No need for a dedicated server with root access. It also features SyncPlay for real-time multi-viewer sync and Hub for easy remote access without configuring NAT.

Does it support live TV?

Yes. Phlix includes Live TV with EPG support, m3u playlist input, and DVR recording capabilities. IPTV sources work out of the box.

How does SyncPlay work?

SyncPlay uses NTP time synchronization to keep all viewers on the same playback state. When one person plays, pauses, or seeks, the wave function collapses for everyone in the sync group simultaneously.

Can I access my media remotely?

Yes. Phlix Hub creates a reverse SSH tunnel to bypass NAT. Self-host the relay for full control, or use the free public relay for simplicity.

What formats are supported?

Phlix supports every format FFmpeg can handle. For casting/DLNA, automatic transcoding ensures compatibility with any device.

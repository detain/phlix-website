# Quantum Stream Site

## Overview

This is the marketing and documentation site for the Quantum Stream brand kit.

**URL:** https://phlix.net/sites/quantum-stream/

## Concept

Quantum Stream visualizes media library management through the lens of quantum mechanics. Every title exists in superposition — watched and unwatched, favorite and forgotten — until observation (hovering) causes the wave function to collapse. The Sage archetype brings analytical precision to every frame.

**Palette:** #0D1B2A #1B263B #415A77 #778DA9 #E0E1DD

## Pages

- `index.html` — Hero landing page with quantum concept introduction
- `features.html` — Technical specifications for core modules
- `clients.html` — Multi-platform client application listing
- `download.html` — Installation instructions and downloads
- `plugins.html` — Community plugin ecosystem
- `docs.html` — API reference and documentation
- `hub.html` — Remote access relay information
- `about.html` — Philosophy, license, FAQ
- `404.html` — Error page with quantum humor

## Design Elements

### Atom Structure Graphics
- Vector atom/nucleus graphics with orbital paths
- Electron dots with subtle animations
- Probability cloud radial gradients

### Observer Effect
- Content cards blur on hover (3px gaussian)
- Represents the quantum measurement changing state
- Respects `prefers-reduced-motion`

### Probability Cloud Backgrounds
- Radial gradient animations
- Interference line patterns
- Subtle pulsing effects

## Typography

**Fonts:** IBM Plex Mono, IBM Plex Sans (self-hosted WOFF2)

No Google Fonts CDN, no external font CDNs.

## Icons

All icons are inline SVG with consistent 1.5px stroke weight.

## Mascot: Qubit

A stylized atom structure representing a quantum observer. Appears on home, download, and about pages. Includes:
- Idle orbital animation
- Context-aware tips via IntersectionObserver
- Easter egg: 7 clicks triggers electron alignment animation

## Motion

- Quantum tunneling transitions (fade through barrier)
- Wave collapse effects on hover
- Electron orbit animations
- All motion respects `prefers-reduced-motion`

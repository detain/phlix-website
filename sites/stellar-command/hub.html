Phlix Hub

Sign in once. Reach any of your servers from anywhere.

What the Hub Does

The Phlix Hub is a cloud directory and reverse-tunnel relay. It handles NAT traversal so you can reach your home server from your phone at a friend's house — without exposing your server to the internet or configuring port forwards.

When Hub mode is enabled in your client, the client maintains an outbound connection to the Hub. The Hub brokers the connection so both sides can communicate without either needing a public IP or open ports.

Self-host or Use the Public Hub

You have options:

  • Use the public hub — Zero configuration. Connect and go.
  • Self-host the hub — Full control. Run phlix-hub on your own infrastructure.

Hub Mode in Clients

Hub mode is built into all Phlix clients. When enabled, the client connects to the Hub and registers your servers. Switch between your home server and any remote server seamlessly — one login, any location.

Hub mode is available in the Roku, Windows, and Mobile clients. Samsung Tizen support is in development.

Want to self-host the Hub?

See the hub-admin docs for setup instructions.

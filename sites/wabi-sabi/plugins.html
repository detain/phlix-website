Plugins

Extending Phlix

The plugin system has a versioned manifest contract. Implement LifecycleInterface, ship a manifest, drop it in the plugins directory.

How it works

LifecycleInterface

Every plugin implements LifecycleInterface. It tells Phlix when your plugin is being installed, started, stopped, and removed — and Phlix respects that contract across versions.

Versioned manifest

Each plugin ships a manifest.json that declares its identity, its dependencies, and which Phlix version it requires. The loader validates everything before the plugin runs.

Drop-in discovery

Drop a plugin folder into the plugins directory. The loader finds it, validates it, and starts it — no configuration, no service restart required.

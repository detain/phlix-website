Plugins

Extend Phlix with a clean, versioned plugin contract. Drop it in, the loader picks it up.

The Plugin Contract

Every Phlix plugin implements LifecycleInterface and ships a manifest.json. The plugin loader scans the plugins/ directory on startup, validates the manifest schema version, and registers the plugin's hooks.

Plugins can contribute metadata providers, custom transcoding profiles, artwork sources, and more — all through a typed interface that the server understands.

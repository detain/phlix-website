Server

Requires PHP 8.3+, MySQL, and ffmpeg. Run on Ubuntu or Debian — or anywhere that supports the stack.

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

Installs system packages, creates the database, sets up systemd service and HAProxy with Let's Encrypt. Default ports: HTTP :8096, DLNA :1900/udp.

Evidence room · eight files

Evidence Files

Eight tools, pinned to the wall with the serial still on them. Each one does a job the one before it could not. Lux left a note on every file.

The eight evidence files

EF-01

Library that organizes itself

Files walk in. The board sorts itself. Nobody has to lift a pen.

Folder-watcher hashes mtimes, scanner parses S01E02 / (2020) titles, ItemRepository hydrates metadata_json. Add a file, see it appear.

Decode the jargon
mtime
the timestamp a file was last written — how Phlix spots what changed
metadata_json
the stored title, year, artwork and cast for one item
S01E02
season-and-episode numbering read straight out of the filename
EF-02

SyncPlay across the room or across the country

Two rooms, one frame. Ask anyone who has tried it without a shared clock.

Weighted-mean NTP offset over 5 samples keeps every device locked to the same frame. Play, pause, seek — everyone moves together.

Decode the jargon
NTP
the internet time protocol — the same trick clocks use to agree
weighted-mean offset
five clock readings averaged so one bad sample cannot skew it
EF-03

Transcoding that picks the right quality

The picture arrives at the size the screen can carry. No negotiation.

QualitySelector profiles for mobile-low, mobile-high, web, and tv-4k. CRF 23/28 libx264/libx265 with HLS master and variant playlists.

Decode the jargon
CRF 23/28
the quality dial — lower number, bigger and sharper file
libx264 / libx265
the two H.264 and H.265 encoders FFmpeg uses
HLS master playlist
the index that lets a player switch quality mid-stream
EF-04

Multi-user, multi-profile, parental controls

Everyone gets a key. Not everyone gets the same door.

JWT auth with refresh tokens, Argon2ID password hashing, up to 5 profiles per user, 4- or 6-digit PINs, rating filter from G to NC-17.

Decode the jargon
JWT
a signed sign-in token, so the server never re-checks your password
refresh token
the longer-lived token that quietly renews the short one
Argon2ID
the password-hashing algorithm currently recommended for new systems
EF-05

Live TV with DVR + EPG

The broadcast runs whether you are watching or not. Now it waits for you.

ChannelManager, GuideManager, and Recorder give you scheduled recordings and a guide that doesn't make you click through menus.

Decode the jargon
EPG
the electronic programme guide — what is on, and when
DVR
scheduled recording to disk, so a broadcast stops being a deadline
EF-06

DLNA for the devices you already own

The old set in the back room still works. It only needed asking properly.

ContentDirectory, AvTransport, and a DeviceRegistry mean your old smart TV doesn't need a new app.

Decode the jargon
ContentDirectory
the DLNA service that lists what is available to play
AvTransport
the DLNA service that actually starts, pauses and stops playback
SSDP
the discovery chatter that lets devices find each other on a LAN
EF-07

Plugin system with a real contract

Bring your own tool. The loader does not ask where you got it.

LifecycleInterface + manifest schema. Drop a plugin in, the loader picks it up. See phlix-plugin-example.

Decode the jargon
LifecycleInterface
the small set of methods every plugin has to implement
manifest
the versioned description file the loader reads before wiring a plugin
EF-08

Phlix Hub — reach any of your servers from anywhere

Your server sits behind the wall. The relay walks through it.

Sign in once. Reverse-tunnel relay handles NAT. Self-hostable, or use the public hub.

Decode the jargon
NAT
the router behaviour that hides your home network from the internet
reverse tunnel
a connection your server opens outward, so nothing has to open inward

Here's the key.

One line gets the server running. Copy. Paste. Run. The archive is yours.

Install Phlix Server 1 line — Ubuntu / Debian
curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash
Installs PHP 8.3+, MySQL, ffmpeg, creates a system user, sets up the database, runs migrations, and starts a systemd service. Default ports: HTTP on :8096 behind HAProxy on :80/:443, DLNA discovery on 1900/udp.
Provision HTTPS in the same run + domain + email
curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash -s -- --domain phlix.example.com --admin-email you@example.com

Requirements

PHP 8.3+, MySQL, ffmpeg. The installer targets a fresh Ubuntu/Debian host and also compiles the Swoole and php-uv extensions from source, skipping the build when they already load.

Full install docs

Development checkout only — not an install: 

git clone https://github.com/detain/phlix-server.git
cd phlix-server
composer install

Creates no database, no service, runs no migrations.

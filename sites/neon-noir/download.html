Get Access

You came for the archive. Here's the key. Everything else on this page is optional.

Clearance token

Run the server

One line, on a fresh Ubuntu or Debian host. Run it and the archive is live on your own hardware.

phlix-server · install 
curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

Installs system packages (PHP 8.3+, MySQL, ffmpeg), creates a dedicated phlix system user, a MySQL database and user, an env file at /etc/phlix/env with a generated PHLIX_SECRET_KEY, runs database migrations, installs a systemd phlix-server service, and sets up an HAProxy reverse proxy with an auto-renewing Let's Encrypt certificate.

It prompts for install path, database credentials and hostname in a terminal, and runs unattended when piped or given -y. Default ports: HTTP on :8096 behind HAProxy on :80/:443, DLNA discovery on 1900/udp.

Two other ways in
With HTTPS
Hand the installer a hostname and an address, and it provisions the certificate in the same run. 
curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh \
  | sudo bash -s -- --domain phlix.example.com --admin-email you@example.com
From source
A development checkout — not an install. It creates no database, no service, and runs no migrations. 
git clone https://github.com/detain/phlix-server.git
cd phlix-server
composer install

What the box needs

  • PHP 8.3 or newer
  • MySQL
  • ffmpeg
  • A fresh Ubuntu or Debian host — that is what the installer targets
  • A folder of media you already own

The installer also compiles the Swoole and php-uv extensions from source, skipping the build when they already load.

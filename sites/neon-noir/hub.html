Phlix Hub

Reach Anywhere

Your server never leaves the building. You do. The Hub is the relay that keeps the two connected without opening a single port.

The relay

What the Hub does

Sign in once. Reverse-tunnel relay handles NAT. Self-hostable, or use the public hub.

Your server opens the connection outward, so nothing has to be opened inward. No port forwarding, no exposed ports, no third-party tunnel in the middle.

path of a request
phone (any network)
  → phlix-hub relay
    → reverse tunnel
      → your server, on your LAN

Two ways to run it

Self-host or use the public hub

The hub is a cloud directory plus a reverse-tunnel relay, and it is its own repository — run your own copy, or point at the public one and be done.

Read the phlix-hub source

On the client side

Hub mode in the clients

Hub mode is built into the Roku channel and the Windows desktop client, so the same account reaches the same library from a friend's living room.

  • Roku — HLS playback, Hub mode, skip intro/outro, SyncPlay
  • Windows — Electron + React + TypeScript, system tray, media keys, Hub mode
  • Mobile (beta) — movies, TV, music, photos, offline downloads, token refresh

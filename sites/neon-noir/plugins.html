Plugin System

A real contract. Not a suggestion.

Phlix ships with a versioned LifecycleInterface and manifest schema. Drop a plugin in the plugins directory — the loader picks it up automatically.

CONTRACT / 01

LifecycleInterface

A versioned interface that every plugin must implement. Boot, activate, deactivate, shutdown — the server drives these states.

CONTRACT / 02

Manifest Schema

A JSON manifest declares the plugin's name, version, required interfaces, and any service bindings. The loader validates it against the schema.

CONTRACT / 03

Auto-discovery

Place a plugin directory in plugins/. On restart, Phlix scans the directory, validates the manifest, and registers the plugin automatically.

Plugin model

Phlix plugins implement the LifecycleInterface and ship a manifest file. The server's plugin loader scans the plugins directory, validates the manifest, and registers the plugin's hooks and services.

The manifest declares the plugin's name, version, API version, dependencies, and the services it provides. This is a real contract — not an afterthought.

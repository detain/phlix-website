Chapter 01

The Philosophy

Every great city has a side that only comes alive after dark. Down rain-slicked alleys and beneath flickering neon signs, stories unfold that the daylight would rather forget. Phlix was built for that half-light — the electric glow on wet pavement, a saxophone drifting from an open window, a silhouette pausing under a pink marquee.

Phlix built Neon Noir for the viewer who wants more than content: they want atmosphere. The interface, the card, the transition — each is a scene from a film that hasn't been made yet. Taut. Cinematic. Unforgettable.

The goal is transformation, not just delivery. Phlix transforms watching into an experience — giving every film and series the atmospheric weight it deserves.

Chapter 02

The Licence

Phlix Server and the Hub are MPL-2.0 — open source, and you can build on them commercially. If you modify a Phlix file, that file stays open; anything you add alongside it is yours. The shared libraries, plugins, and clients are MIT so you can build on them freely.

MPL is weak copyleft. The one condition: modify a Phlix file and that file stays open. Never say "no strings attached" or claim endorsement — the licence is the only contract. Footer links go to the repository LICENCE.

Chapter 03

The Archive

Phlix is open source, and contributions are welcome. The plugin system provides a versioned manifest contract: implement LifecycleInterface, ship a manifest, drop the plugin in the plugins directory, and the loader picks it up.

Start with phlix-plugin-example, the smallest working reference implementation.

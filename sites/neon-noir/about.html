Closed cases

Closed Cases

Three chapters and a transcript. Why Phlix exists, what the licence actually lets you do, and how to get your name on the file.

The chapters

I Philosophy

The library should answer to you

A collection you cannot reach is not a collection. Phlix exists so the drive in the other room behaves like a service — indexed, searchable, playable on any screen — without handing the catalogue to anybody else.

100% self-hostable: your library never leaves your hardware unless you say so. It is built in PHP 8.3+ on Workerman, async from the socket up, and every part of it is open to read.

II License

Two licences, on purpose

Phlix Server and the Hub are MPL-2.0 — open source, and you can build on them commercially. If you modify a Phlix file, that file stays open; anything you add alongside it is yours. The shared libraries, plugins, and clients are MIT so you can build on them freely.

Read the licence in the server repository

III Contributing

The work happens in the open

Every repository lives under the detain organisation on GitHub — server, hub, shared library, docs, the five clients and the reference plugin. Issues are public, and the plugin example exists so a first patch does not have to be a large one.

  • The detain organisation on GitHub
  • Open issues on phlix-server
  • The reference plugin, for a first patch

Interrogation transcript

Lux answers the room

TRANSCRIPT · questions put to Lux, the night archivist. Some were asked more than one way; the answer did not change.

Is Phlix like Plex / Jellyfin / Emby?
Yes — same job, different stack. Phlix is built in PHP 8.3+ on Workerman, ships with a versioned plugin contract, and includes a hub for accessing remote servers behind NAT without a third-party tunnel.
Do I need to expose my server to the internet?
Is my library really safe from the internet?
What if I move or travel?
No. Run Phlix on your LAN and use the Phlix Hub's reverse-tunnel relay to reach it from your phone or Roku at a friend's house. You can self-host the hub, or use the public one.
What formats are supported?
Can I watch on any device?
Anything FFmpeg can read. Direct play when the client supports it; transcoded HLS otherwise. Per-device quality profiles pick the right bitrate automatically.
Is there a mobile app?
Yes — React Native, available on iOS and Android. Currently in beta.
Can I write plugins?
Yes. Implement LifecycleInterface, ship a manifest, drop it in the plugins directory. See phlix-plugin-example for the smallest working starter.
What's the license?
Phlix Server and the Hub are MPL-2.0 — open source, and you can build on them commercially. If you modify a Phlix file, that file stays open; anything you add alongside it is yours. The shared libraries, plugins, and clients are MIT so you can build on them freely.

Case closed. Yours is still open.

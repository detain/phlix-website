Plugins

Extend Phlix with a versioned plugin contract.

Plugin model

Phlix plugins implement the LifecycleInterface and ship a manifest file. Drop a plugin into the plugins/ directory and the loader picks it up automatically.

The manifest declares the plugin version, compatible Phlix versions, and entry points. No hooks to maintain, no events to wire — just implement the interface and go.

Ecosystem plugins

The community is building plugins for metadata providers, channel integrations, and custom transcoding profiles. Check the GitHub org for what's available.

Write your own

Start from phlix-plugin-example — the reference metadata-provider plugin that shows you exactly how to structure a plugin, declare dependencies, and ship a manifest.

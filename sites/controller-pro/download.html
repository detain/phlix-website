Download

Self-host your media in minutes. PHP 8.3+, MySQL, FFmpeg.

Install the server

One line, on a fresh Ubuntu or Debian host. Installs system packages (PHP 8.3+, MySQL, FFmpeg), creates a dedicated phlix system user, a MySQL database and user, an env file at /etc/phlix/env with a generated PHLIX_SECRET_KEY, runs database migrations, installs a systemd phlix-server service, and sets up an HAProxy reverse proxy with an auto-renewing Let's Encrypt certificate.

Install curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

Prompts for install path, database credentials and hostname when run in a terminal; runs fully unattended when piped or given -y. Default ports: HTTP on :8096 behind HAProxy on :80/:443, DLNA discovery on 1900/udp.

With HTTPS curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh \ | sudo bash -s -- --domain phlix.example.com --admin-email you@example.com
From source (development) git clone https://github.com/detain/phlix-server.git cd phlix-server composer install

Note: Building from source is for development only. It does not create a database, a service, or run migrations. For a working install, use the one-liner above.

Phlix Hub

Access your server from anywhere — without exposing it to the internet.

What the Hub does

Phlix Hub is a cloud directory plus reverse-tunnel relay. It handles NAT traversal so you can reach your home server from anywhere without opening ports or configuring dynamic DNS.

Run your server on your home network, sign into the Hub once, and your Roku at a friend's house or your phone on mobile data can connect as if it were on the same LAN.

Self-host or use the public hub

The public Hub at hub.phlix.io is free to use. If you want full control, you can self-host the Hub — it's open source and runs on the same stack as the server.

git clone https://github.com/detain/phlix-hub.git
cd phlix-hub
composer install

Hub mode in clients

Roku, Windows, and Mobile clients all support Hub mode — sign in once, select your server, and you're connected. No port forwarding, no configuration.

Ready to set up your hub?

Check the documentation for self-hosting instructions or connect to the public hub.

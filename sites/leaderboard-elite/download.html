Download

Self-host your media in minutes. One command, zero complexity.

Server

Requires: PHP 8.3+, MySQL, ffmpeg. The installer targets a fresh Ubuntu/Debian host and also compiles the Swoole and php-uv extensions from source.

One line, on a fresh Ubuntu or Debian host

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

Installs system packages, creates database, sets up systemd service, and configures HTTPS via HAProxy with Let's Encrypt.

Provision HTTPS in the same run

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh \
  | sudo bash -s -- --domain phlix.example.com --admin-email you@example.com

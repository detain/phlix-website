# Leaderboard Elite — Brand Kit Site

## Concept & Vision

A competitive gaming-inspired brand kit for Phlix that evokes the thrill of leaderboards, rank badges, and tournament brackets. The aesthetic channels high-score culture with a gold/silver/bronze podium motif — prestigious, energetic, and unmistakably competitive. This is media server marketing that appeals to the gamer mindset: rankings, achievement, and outperforming the competition.

## Aesthetic Direction

**Theme:** Gaming leaderboard with tournament aesthetics — rank badges, podium finishes, championship energy.

**Mood:** Competitive, prestigious, high-energy. Think esports trophy ceremonies meets premium streaming service.

## Typography

**Display Font:** Orbitron — futuristic, geometric, gaming-inspired. Used for headlines, headings, badges, and CTAs.

**Body Font:** Rajdhani — semi-condensed, technical feel, excellent readability. Used for body text, descriptions, and UI elements.

**Mono Font:** JetBrains Mono — for code blocks and technical snippets.

## Spatial System

- Spacing scale: 4px base unit (0.25rem increments)
- Max content width: 1400px
- Header height: 80px
- Border radius: 4px (sm) through 24px (2xl)
- Cards use consistent 1.5rem padding

## Motion Philosophy

- **Entrance:** Staggered fade-in reveals for card grids (50ms delay between items)
- **Hover:** Cards lift with gold border glow and 4px translateY
- **Navigation:** Smooth transform for mobile menu slide-in
- **Reduced motion:** All animations disabled under `prefers-reduced-motion`

## Visual Assets

- **Logo:** Gold trophy/play icon with "PHLIX" wordmark
- **Favicon:** Gold square with trophy icon on dark background
- **Icons:** Inline SVG stroke-based icons (48px feature cards, 64px feature details)
- **Background:** Subtle radial gradients creating atmospheric depth
- **Decorative:** Gold glow shadows on featured elements

## Component Highlights

- **Feature Cards:** Elevated dark surfaces with gold hover borders and lift effect
- **Client Cards:** Status badges (gold/silver/bronze for rank-like indication)
- **CTAs:** Gold gradient buttons with glow shadow and hover lift
- **Code Blocks:** Dark surfaces with gold text for command visibility
- **FAQ:** Expandable details/summary with gold accent indicators

Plugins

Extend Phlix with a versioned plugin contract — no fork required.

Plugin model

Phlix plugins implement the LifecycleInterface and ship a manifest file. Drop your plugin into the plugins/ directory and the loader picks it up automatically.

Example manifest (manifest.json):

{ "name": "my-metadata-provider", "version": "1.0.0", "description": "Fetches metadata from a custom API", "entry": "MyMetadataProvider.php", " lifecycle": "metadata-provider" }

Minimal plugin class:

use Phlix\Plugin\LifecycleInterface; class MyMetadataProvider implements LifecycleInterface { public function onEnable(): void { // Called when the plugin is enabled } public function onDisable(): void { // Called when the plugin is disabled } }

Ecosystem plugins

The community has built plugins for additional metadata sources, visualizations, and more. Check the GitHub org for available plugins.

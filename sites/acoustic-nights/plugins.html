Plugins

A versioned contract, a manifest schema, and a drop-in directory. That's all it takes to extend Phlix.

The plugin model

Phlix plugins implement the LifecycleInterface and ship a manifest.json. Drop the plugin folder into plugins/ and the loader picks it up on the next server restart.

LifecycleInterface

Every plugin must implement these methods:

  • onEnable() — called when the plugin is enabled
  • onDisable() — called when the plugin is disabled
  • getManifest() — returns the plugin metadata

manifest.json

{
  "name": "my-metadata-provider",
  "version": "1.0.0",
  "apiVersion": "1.0",
  "author": "Your Name <you@example.com>",
  "description": "Fetches metadata from MyAnimeList",
  "dependencies": {}
}

Write your own

If you can write PHP, you can write a Phlix plugin. The contract is small, the manifest is simple, and the loader handles the rest.

Start from phlix-plugin-example, read the plugin documentation, and ship your extension to the GitHub org.

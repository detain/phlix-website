Plugins

Extend Phlix with a versioned plugin contract. Drop a plugin in, the loader picks it up.

Plugin Model

Phlix plugins implement the LifecycleInterface and ship a manifest.json. The loader discovers plugins in the plugins/ directory at startup and manages their lifecycle automatically.

LifecycleInterface

interface LifecycleInterface {
    onEnable(): void;
    onDisable(): void;
    onInstall(): void;
    onUninstall(): void;
}

manifest.json

{
  "name": "my-metadata-provider",
  "version": "1.0.0",
  "description": "Fetches metadata from MyService",
  "author": "Your Name",
  "license": "MIT",
  "lifecycle": {
    "onEnable": "enable",
    "onDisable": "disable"
  }
}

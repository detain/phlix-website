Phlix Hub

Access your server from anywhere. No port forwarding, no third-party tunnel.

What the Hub Does

Phlix Hub is a reverse-tunnel relay that connects your server behind NAT to the outside world. When your server starts, it opens an outbound connection to the Hub. Clients connect to the Hub, which proxies traffic to your server through that connection. No inbound ports required.

Self-host or Use the Public Hub

The public Hub at hub.phlix.app is free to use. If you need full control or want to run multiple servers under one Hub, you can self-host phlix-hub on your own VPS.

Hub Mode in Clients

The Windows client and Roku channel both support Hub mode. When enabled, the client connects through the Hub instead of directly to your LAN IP. The Hub then proxies traffic to your server — you can watch your library from a friend's house without touching your router.

See the Hub documentation for setup instructions, self-hosting guides, and API details.

Download

Install Phlix Server on your own hardware. One command, fully automated setup.

Phlix Server

PHP 8.3+, MySQL, FFmpeg required. Targets a fresh Ubuntu or Debian host.

One-line install Ubuntu / Debian
curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash
Installs system packages, creates a dedicated phlix system user, sets up MySQL database, generates PHLIX_SECRET_KEY, runs migrations, and configures systemd service + HAProxy with Let's Encrypt.
With HTTPS Domain + email
curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash -s -- --domain phlix.example.com --admin-email you@example.com
Build from source Development (not an install)
git clone https://github.com/detain/phlix-server.git cd phlix-server composer install
This is a development checkout only. It does not create a database, a service, or run migrations. Never present it as the way to install Phlix.

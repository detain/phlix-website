# Android Dreams Brand Kit

Sentient AI organizing your media with mechanical precision.

## Theme

- **Archetype:** Sage (intelligent, precise, mechanical)
- **Experience:** Immersive
- **Concept:** A thinking machine that learns your viewing habits

## Visual Elements

- Mechanical eyes with dilating iris
- Circuit board trace patterns
- Servo motor accents
- Wire-frame human silhouettes
- CPU chip iconography
- Binary data streams

## Motion Effects

- Eye-tracking hover animations
- Mechanical iris dilation
- Circuit board reveal animations
- Wire-frame avatar evolution
- Servo click feedback

## Color Palette

| Role | Color | Hex |

| Primary | Charcoal Steel | #2D3436 |

| Tertiary | Steel Silver | #B2BEC3 |

| Background | Deep Slate | #1A1D1E |

## Typography

- **Display:** Orbitron (geometric, futuristic)
- **Body:** Share Tech Mono (technical, monospace)
- **Accent:** Rajdhani (semi-condensed, geometric)

## Accessibility

- Respects `prefers-reduced-motion`
- High contrast ratios (minimum 4.5:1)
- Keyboard-focus indicators
- Semantic HTML structure

Plugins

A versioned contract means your plugins won't break when Phlix updates.

Plugin Model

Phlix plugins implement the LifecycleInterface and ship a manifest file. Drop a plugin into the plugins/ directory and the loader picks it up automatically.

LifecycleInterface

interface LifecycleInterface { public function onInstall(): void; public function onEnable(): void; public function onDisable(): void; public function onUninstall(): void; }

manifest.json

{ "name": "my-metadata-provider", "version": "1.0.0", "api": "1.0", "entry": "MyPlugin.php", "author": "Your Name", "description": "What it does" }

Write Your Own

Start with the phlix-plugin-example repository. It contains a complete, annotated plugin that you can use as a template.

The plugin contract is versioned, so plugins written against api: "1.0" will continue working even as Phlix adds new features.

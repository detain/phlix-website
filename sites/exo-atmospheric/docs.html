Getting Started

Welcome to the Phlix documentation. This guide will help you get up and running with your own cosmic media server.

System Requirements

  • Server: 2GHz dual-core CPU, 4GB RAM, 100GB storage
  • Supported OS: Windows 10/11, macOS 12+, Ubuntu 20.04+, Debian 11+
  • Network: Gigabit Ethernet recommended for local streaming

Quick Start

# Using Docker
docker run -d \
  --name phlix \
  -p 32400:32400 \
  -v /path/to/media:/media \
  -v phlix-config:/config \
  phlix/server:latest

After starting, access the web interface at http://localhost:32400 and follow the setup wizard.

Configuration

Phlix stores configuration in /config volume. Key files:

  • config.xml — Main configuration
  • Preferences.xml — User preferences
  • Plug-ins/ — Installed plugins

API Reference

Phlix exposes a REST API for integration. Base URL: 

http://your-server:32400/phlix

Authentication

API requests require an X-Phlix-Token header with your API key. Generate keys in Settings → API. 

curl -H "X-Phlix-Token: your-api-key" \
  http://localhost:32400/phlix/servers

Endpoints

Method Endpoint Description
GET /servers List available servers
GET /library Get library items
POST /playback Control playback
GET /search Search library

Plugins

A versioned contract. Drop your plugin in, Phlix picks it up.

Plugin model

Every plugin implements LifecycleInterface and ships a manifest.json. Drop the plugin directory into plugins/ and the loader discovers it on the next server start.

manifest.json 
{
  "name": "my-metadata-provider",
  "version": "1.0.0",
  "description": "Fetches metadata from MyMovieDB",
  "entry": "MyMetadataProvider.php",
  "lifecycle": "metadata-provider"
}

Implement the lifecycle methods, declare your dependencies, and you're done. No registration ceremony, no database migrations to manage.

Plugins

A real contract. A versioned manifest. Drop a plugin in and the loader picks it up — no patching, no forks.

The Plugin Model

Phlix plugins implement the LifecycleInterface and ship a manifest.json. The server loader scans the plugins/ directory on startup and registers each plugin that passes schema validation.

Plugins can provide metadata providers, new stream handlers, authentication backends, or custom UI panels — all without touching the server core.

Ecosystem Plugins

The Phlix ecosystem includes plugins for extended metadata, additional stream sources, and custom integrations.

phlix-plugin-example on GitHub

Write Your Own

Start with phlix-plugin-example — the smallest working plugin. It demonstrates the manifest format, the LifecycleInterface implementation, and the directory layout expected by the loader.

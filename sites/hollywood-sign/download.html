Get Phlix running on your own hardware. One line. No credit card.

Server

Phlix Server runs on Linux. You'll need PHP 8.3+, MySQL, and FFmpeg. The installer handles everything else — system packages, database setup, systemd service, and an HAProxy reverse proxy with Let's Encrypt. 

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

One line, on a fresh Ubuntu or Debian host. Installs PHP 8.3+, MySQL, ffmpeg, creates a dedicated phlix system user, sets up the database, and configures systemd and HAProxy with auto-renewing Let's Encrypt.

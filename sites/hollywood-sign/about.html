About

Your media, your server, your rules. Built by developers who believe streaming should be self-hosted.

Philosophy

Phlix exists because the best media server is the one you control. We built it in PHP because that's what we know, and because PHP runs everywhere — even on that old server gathering dust in your closet. No subscriptions, no accounts, no tracking. Just a server that streams your files to every screen you own.

The plugin system exists because no media server gets everything right for everyone. Instead of asking users to fork the codebase or wait for a feature request to land, we gave you a real contract and a drop-in directory. Your metadata fetcher, your subtitle parser, your custom notification handler — all as plugins.

The Hub exists because not everyone has a static IP, a configureable router, or the desire to run a VPN. Access should work from anywhere without compromising the principle: your media stays on your hardware.

Contributing

Phlix is developed in the open by the detain GitHub org. Bug reports, feature requests, and pull requests are welcome. The plugin example repo is the best place to start if you want to extend Phlix.

For substantial changes, please open an issue first to discuss what you're planning. That saves everyone the disappointment of a closed PR that was going the wrong direction.

FAQ

Is Phlix like Plex / Jellyfin / Emby?
Yes — same job, different stack. Phlix is built in PHP 8.3+ on Workerman, ships with a versioned plugin contract, and includes a hub for accessing remote servers behind NAT without a third-party tunnel.
Do I need to expose my server to the internet?
No. Run Phlix on your LAN and use the Phlix Hub's reverse-tunnel relay to reach it from your phone or Roku at a friend's house. You can self-host the hub, or use the public one.
What formats are supported?
Anything FFmpeg can read. Direct play when the client supports it; transcoded HLS otherwise. Per-device quality profiles pick the right bitrate automatically.
Is there a mobile app?
Yes — React Native, available on iOS and Android. Currently in beta.
Can I write plugins?
Yes. Implement LifecycleInterface, ship a manifest, drop it in the plugins directory. See phlix-plugin-example for the smallest working starter.

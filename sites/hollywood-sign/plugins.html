Plugins

Extend Phlix with a versioned plugin contract. Drop in, loader picks it up.

Plugin model

Phlix plugins implement the LifecycleInterface and ship a manifest file. Drop the plugin directory into plugins/ and the loader discovers it automatically on the next server start.

plugins/
  my-plugin/
    manifest.json    # name, version, entrypoint
    src/
      MyPlugin.php   # implements LifecycleInterface

The manifest declares the plugin's name, version, PHP minimum version, and the class to instantiate. The LifecycleInterface gives Phlix hooks into install, upgrade, uninstall, and runtime events.

View plugin example

Ecosystem plugins

As the plugin ecosystem grows, compatible plugins will be listed here. The reference implementation at phlix-plugin-example shows how to build a metadata-provider plugin.

Write your own

The plugin example repo contains the smallest working starter — a metadata provider that fetches poster art from a fictional API. Clone it, rename things, implement your logic, and drop it in.

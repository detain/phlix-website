Our Genesis

Open-source media, on your terms. Heritage is the most powerful kind of science fiction.

The philosophy

Phlix was built in PHP 8.3+ on Workerman because PHP is everywhere and self-hosting should not require a computer science degree. The same reason we chose MySQL — it is already running on the host you already have.

Your media is yours. It lives on your hardware, on your network, under your control. We did not build Phlix to be another subscription in a world already drowning in subscriptions. We built it because the stories you love deserve to stay with you.

SyncPlay exists because movie nights are not solo events. The Hub exists because you should be able to watch your library from anywhere without building infrastructure. The plugin system exists because one size does not fit all cultural archives.

Every feature was chosen because it serves a real need that the proprietary services ignore: the diaspora family that wants to share a film night across three continents, the collector whose Afrofuturist cinema archive deserves better than a folder of files, the developer who wants to extend their media server with cultural context annotations.

Phlix is the union of the ancient and the cosmic — the same impulse that built Benin bronzes and sent them to the moon's landing site, the same curiosity that imagines futures from the vantage point of people who were always told they did not belong in them. Heritage is the most powerful kind of science fiction.

Contributing

Phlix is open to contributions. The server, hub, clients, docs, and plugin example are all on GitHub. If you find a bug, open an issue. If you have a feature idea, open an issue. If you want to write code, fork and PR.

  • phlix-server — the media server itself
  • phlix-hub — the cloud directory and relay
  • phlix-shared — shared interfaces and types
  • phlix-docs — user and developer docs
  • phlix-plugin-example — reference plugin

The Orisha counsel

Wisdom from those who have walked the path before you.

Is Phlix like Plex / Jellyfin / Emby?

Yes — same job, different stack. Phlix is built in PHP 8.3+ on Workerman, ships with a versioned plugin contract, and includes a hub for accessing remote servers behind NAT without a third-party tunnel.

Do I need to expose my server to the internet?

No. Run Phlix on your LAN and use the Phlix Hub's reverse-tunnel relay to reach it from your phone or Roku at a friend's house. You can self-host the hub, or use the public one.

What formats are supported?

Anything FFmpeg can read. Direct play when the client supports it; transcoded HLS otherwise. Per-device quality profiles pick the right bitrate automatically.

Is there a mobile app?

Yes — React Native, available on iOS and Android. Currently in beta.

Can I write plugins?

Yes. Implement LifecycleInterface, ship a manifest, drop it in the plugins directory. See phlix-plugin-example for the smallest working starter.

What's the licence?

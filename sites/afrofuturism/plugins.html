Build your own stars

Extensions

Phlix has a versioned plugin contract. Drop a plugin in, the loader picks it up. See phlix-plugin-example for the smallest working starter.

The plugin model

Every plugin implements LifecycleInterface and ships a manifest.json. The loader reads the manifest, validates the version contract, and picks up the plugin automatically — no config file editing, no server restart required for discovery.

plugins/ my-metadata-plugin/ manifest.json # version, name, lifecycle hooks src/ MyPlugin.php # implements LifecycleInterface

What plugins can do

  • Enrich metadata — add cultural context, ancestry lineages, custom tags, third-party database integrations
  • Add new sources — scan additional folder paths, network shares, cloud storage backends
  • Custom transcoding — implement specialised codecs or quality tuning
  • New UI surfaces — admin console panels, user-facing widgets, API endpoints
  • Notifications — push integrations, webhook handlers, custom alert routing

Getting started

Clone the example plugin, read the manifest schema, and start building. The example shows the minimum viable plugin — one class, one manifest, one lifecycle hook.

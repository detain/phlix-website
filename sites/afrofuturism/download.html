Everything you need to run Phlix — server, clients, and ecosystem — in one place.

Server requirements

PHP 8.3+  |  Workerman 5.x (async/coroutine server)

Phlix is a self-hosted server. You provide the hardware — any machine that runs PHP 8.3. The server itself is the open-source phlix-server repository.

View phlix-server on GitHub

Any DLNA device

No install required — Phlix advertises itself via SSDP. Any DLNA-compatible device on your network will find it automatically.

  • Stable
  • No install
  • SSDP discovery
Works with any DLNA-compatible smart TV, game console, or media receiver.

Download

Set sail with Phlix. The server runs on your own hardware — any PHP 8.3+ host will do.

All hands on deck!

One line, on a fresh Ubuntu or Debian host:

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

Installs PHP 8.3+, MySQL, ffmpeg, creates a system user, sets up the database, and starts the service at http://your-server:8096 behind an HAProxy reverse proxy on ports 80 and 443.

Need HTTPS from the start? curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash -s -- --domain your-domain.com --admin-email you@example.com

For detailed setup instructions, see the documentation.

Download

Set sail with Phlix. The server runs on your own hardware — any PHP 8.3+ host will do.

Server requirements

Phlix Server is a PHP 8.3+ application built on Workerman 5.x. Clone the repo, install dependencies, and you're ready to chart a course.

git clone https://github.com/detain/phlix-server.git
cd phlix-server
composer install
php server.php start

For detailed setup instructions, see the documentation.

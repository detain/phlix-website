Chapter one: the Factory

In 1962 a soup can went on a gallery wall and dared anyone to call it art. Phlix asks the same question about the folder of films on your own disk. The answer is a self-hostable media server: PHP 8.3+ on Workerman, async all the way down.

The point is ownership. Your library never leaves your hardware unless you say so — no subscription tier decides what plays, and no remote index has to know your titles.

Same job as Plex, Jellyfin or Emby; different stack, and a hub of its own for reaching a server behind a router.

Ask Dotty

The letters column. Same answers, louder handwriting.

Dear Dotty: Is Phlix like Plex / Jellyfin / Emby?

Yes — same job, different stack. Phlix is built in PHP 8.3+ on Workerman, ships with a versioned plugin contract, and includes a hub for accessing remote servers behind NAT without a third-party tunnel.

Also asked, in fewer words: “Can I run this without screaming?” — same answer.

Dear Dotty: Do I need to expose my server to the internet?

No. Run Phlix on your LAN and use the Phlix Hub's reverse-tunnel relay to reach it from your phone or Roku at a friend's house. You can self-host the hub, or use the public one.

Also asked, in fewer words: “Will my ISP notice?” — same answer.

Dear Dotty: What formats are supported?

Anything FFmpeg can read. Direct play when the client supports it; transcoded HLS otherwise. Per-device quality profiles pick the right bitrate automatically.

Also asked, in fewer words: “Does it play weird formats?” — same answer.

Dear Dotty: Is there a mobile app?

Yes — React Native, available on iOS and Android. Currently in beta.

Dear Dotty: Can I write plugins?

Yes. Implement LifecycleInterface, ship a manifest, drop it in the plugins directory. See phlix-plugin-example for the smallest working starter.

Dear Dotty: What's the license?

Phlix Server and the Hub are MPL-2.0 — open source, and you can build on them commercially. If you modify a Phlix file, that file stays open; anything you add alongside it is yours. The shared libraries, plugins, and clients are MIT so you can build on them freely.

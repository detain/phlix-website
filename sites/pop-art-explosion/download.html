BAM! INSTALL

One line. One fresh Ubuntu or Debian host. Everything just works — PHP 8.3+, MySQL, FFmpeg, systemd, HAProxy, Let's Encrypt.

Installation Panel One

The One-Liner

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash
Full Docs

Installs system packages (PHP 8.3+, MySQL, ffmpeg), creates a dedicated phlix system user, a MySQL database and user, an env file at /etc/phlix/env with a generated PHLIX_SECRET_KEY, runs database migrations, installs a systemd phlix-server service, and sets up an HAProxy reverse proxy with an auto-renewing Let's Encrypt certificate.

Requirements: PHP 8.3+, MySQL, FFmpeg. Prompts for install path, database credentials and hostname when run in a terminal; runs fully unattended when piped or given -y. Default ports: HTTP on :8096 behind HAProxy on :80/:443, DLNA discovery on 1900/udp.

Installation Panel Two

HTTPS in the Same Run

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh \ | sudo bash -s -- --domain phlix.example.com --admin-email you@example.com

The Full Toolkit

Toolkit Repositories

Phlix is more than the server. Five repos make up the full project:

  • phlix-server

    The media server itself — PHP 8.3+, Workerman 5.x

  • phlix-hub

    Cloud directory + reverse-tunnel relay

  • phlix-shared

    Shared interfaces, DTOs, event types — Composer package

  • phlix-docs

    End-user, developer, and hub-admin docs (VitePress)

  • phlix-plugin-example

    Reference metadata-provider plugin

Development checkout — NOT an install

Build from Source

git clone https://github.com/detain/phlix-server.git cd phlix-server composer install

Note: This creates no database, no service, and runs no migrations. It is a development checkout only. Use the one-liner above to install Phlix properly.

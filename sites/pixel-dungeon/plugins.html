Plugin Contract — Drop & Play

Implement LifecycleInterface, ship a manifest, drop it in the plugins directory. The loader picks it up automatically.

Plugin Model

1
Implement LifecycleInterface in your plugin class. Phlix calls onInstall(), onEnable(), onDisable(), and onUninstall() at the appropriate lifecycle moments.
2
Create a manifest.json declaring the plugin name, version, compatibility range, and any service provider registrations.
3
Drop the plugin folder into plugins/. The auto-loader scans on startup and registers all valid manifests.
4
Enable in the admin UI. Phlix admin shows the plugin with its status badge. Click to enable, configure, or disable.

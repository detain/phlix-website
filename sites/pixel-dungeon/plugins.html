ADVANCED MODS

Drop a plugin in, the loader picks it up. A versioned manifest contract means no surprises.

LIFECYCLEINTERFACE

Every plugin implements LifecycleInterface. The loader calls install(), activate(), deactivate(), and uninstall() at the right moments. If your plugin throws during activate(), the server logs the error and skips it — no crash.

VERSIONED MANIFEST

Each plugin ships a manifest.json with name, version, and a phlix version constraint. The loader rejects plugins that don't declare compatibility. Upgrade Phlix, and incompatible plugins are logged, not loaded.

METADATA PROVIDER EXAMPLE

phlix-plugin-example is the smallest working plugin — it implements a metadata provider that runs during the scan phase. Use it as a template to build TMDB extensions, custom catalogue scrapers, or subtitle fetchers.

EVENTS SYSTEM

Plugins can register for server events: onLibraryUpdate, onPlaybackStart, onUserAuthenticate, and more. Dispatch events from your plugin code or hook into the existing Phlix event bus.

### Key design decisions

| Decision | Rationale |
|----------|-----------|
| CRT scanline via `body::after` `position: fixed` | Single overlay covers entire viewport at 5% opacity; `prefers-reduced-motion` disables it |
| `steps()` easing everywhere | Kit mandates stepped motion — no bezier curves anywhere |
| Nav logo wordmark hidden on mobile | "PIXEL DUNGEON" in Press Start 2P at 10px is ~130px wide — too large for 320px |
| `min-width: 0` on `.btn` | `display: inline-flex` gives `min-width: auto` — prevents shrinking at 200% text zoom |
| `overflow-wrap: anywhere` on body text | §19.12: bare `1fr` grid tracks + long unbreakable words cause overflow |
| `minmax(0, 1fr)` on all grid tracks | §19.12: prevents implicit auto minimum from blocking shrink |
| Blip companion in-flow on mobile | §19.14: fixed companion must not cover CTA at 320px — on mobile, in-flow above footer |
| Install command verbatim from content.json | §19.22: `content.json.install.primary.command` is the one-liner — never retype |
| Seasonal variants tracked but not over-engineered | Contrast checked per variant; live-js mode; motif assets exist in img/seasonal/ |

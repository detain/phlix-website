Server Requirements

PHP 8.3+ required. The server is built on Workerman 5.x — an async/coroutine PHP framework. No Composer installation needed for the bundled release.

php -v # must be 8.3 or higher
php -m # need: json, pdo, pdo_mysql, gd, mbstring, zip, sockets

Features

Everything you need to stream your media, your way — with the control that only self-hosting provides.

Library that organizes itself

Folder-watcher hashes mtimes, scanner parses S01E02 / (2020) titles, ItemRepository hydrates metadata_json. Add a file, see it appear.

Phlix watches your media directories and automatically detects new content. Episode naming conventions like S01E02 or (2020) are parsed intelligently. Metadata is fetched from TMDB, TVDB, and Fanart.tv, with local NFO file support and a 24-hour cache to keep things snappy.

SyncPlay across the room or across the country

Weighted-mean NTP offset over 5 samples keeps every device locked to the same frame. Play, pause, seek — everyone moves together.

SyncPlay synchronizes playback across all connected clients using NTP-style time synchronization. Whether you're in the same room or across the country, everyone stays in perfect sync. Pausing, playing, or seeking propagates to all viewers instantly.

Transcoding that picks the right quality

QualitySelector profiles for mobile-low, mobile-high, web, and tv-4k. CRF 23/28 libx264/libx265 with HLS master and variant playlists.

Adaptive HLS streaming automatically selects the best quality for each device. QualitySelector profiles handle everything from mobile-low (480p) to tv-4k (2160p). FFmpeg handles transcoding with efficient CRF encoding, generating HLS variant playlists that adapt in real-time.

Multi-user, multi-profile, parental controls

JWT auth with refresh tokens, Argon2ID password hashing, up to 5 profiles per user, 4- or 6-digit PINs, rating filter from G to NC-17.

Secure authentication using JWT access and refresh tokens with Argon2ID password hashing. Each user can have up to 5 profiles, each protected with a 4 or 6-digit PIN. Parental controls support content ratings from G all the way to NC-17, giving you fine-grained control over what each profile can access.

Live TV with DVR + EPG

ChannelManager, GuideManager, and Recorder give you scheduled recordings and a guide that doesn't make you click through menus.

Watch live TV with an integrated Electronic Program Guide (EPG). Schedule recordings in advance, manage your channel lineup, and never miss your favorite shows. The guide presents what's on now and coming up without requiring excessive navigation.

DLNA for the devices you already own

ContentDirectory, AvTransport, and a DeviceRegistry mean your old smart TV doesn't need a new app.

Built-in DLNA support with ContentDirectory and AvTransport services means your existing smart TV, game console, or any DLNA-certified device can stream from Phlix without installing anything new. Device discovery happens automatically via SSDP.

Plugin system with a real contract

LifecycleInterface + manifest schema. Drop a plugin in, the loader picks it up. See phlix-plugin-example.

Phlix's plugin system is built on a versioned manifest contract (LifecycleInterface). Write plugins in PHP, ship a manifest.json, drop the folder into the plugins directory. The loader discovers and initializes them automatically. See the reference implementation at phlix-plugin-example.

Phlix Hub — reach any of your servers from anywhere

Sign in once. Reverse-tunnel relay handles NAT. Self-hostable, or use the public hub.

Phlix Hub is a cloud directory and reverse-tunnel relay that lets you access your home server from anywhere, even behind NAT or a firewall. Sign in once and browse all your registered servers. The hub is fully self-hostable, or you can use the public instance.

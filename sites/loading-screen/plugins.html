Plugins

Extend Phlix with a real contract. Write once, drop in, it just works.

Plugin model

Phlix plugins implement LifecycleInterface and ship a manifest.json. Drop the plugin folder into the plugins/ directory and the loader discovers it automatically on the next startup.

Plugins can hook into metadata fetching, transcoding pipelines, authentication, and more — all through a versioned interface that keeps your plugin compatible across Phlix upgrades.

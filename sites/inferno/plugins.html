The Forge

Plugin Inferno

Drop a plugin in, and the loader picks it up. The versioned manifest contract means your extensions survive upgrades — and the fire keeps burning.

The contract

Every plugin declares itself via a manifest.json that specifies the plugin name, version, and lifecycle interface it implements. The LifecycleInterface defines onInstall, onEnable, onDisable, and onUninstall hooks — giving you full control over setup and teardown.

The plugin loader scans the plugins/ directory at startup, validates each manifest against the schema, and registers the plugin with the PluginRegistry. From there, the plugin can hook into any part of the server lifecycle.

Read the Plugin Guide 
{
  "name": "my-metadata-provider",
  "version": "1.0.0",
  "interface": "metadata-provider",
  "lifecycle": ["onEnable"],
  "entry": "MyMetadataProvider.php"
}

What you can build

Metadata Providers

Fetch from TMDB, TVDB, Fanart.tv, or any custom source. Return a normalized payload and let the server handle caching.

Transcoding Filters

Pre-process or post-process media streams. Add burned-in subtitles, watermarks, or quality adjustments.

Auth Providers

Add LDAP, OAuth, or custom auth backends. The server talks to your provider via a simple token exchange.

EPG Sources

Pull guide data from any XMLTV-compatible source. Map channels, merge data, and fill gaps in the program guide.

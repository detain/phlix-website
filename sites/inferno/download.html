Ignition Sequence

Erupt in Three Steps

Heat the chamber. Choose your conduit. Strike — and watch it ignite.

Step 1 — Heat the Chamber

One command. PHP 8.3+ required. Runs on Linux, macOS, Windows WSL.

curl -sSL https://phlix.io/install | php

Or download the latest release from GitHub and install manually.

Step 3 — Strike

Point your conduit at your server's address. The flame ignites.

http://your-server:7777

Default port is 7777. Change it in config.php. For Hub access, see the Channel page.

Chamber Requirements

Server

PHP 8.3+, 2GB RAM minimum, 10GB storage. Linux, macOS, Windows WSL.

Network

Port 7777 open. For remote access, Hub relay or port forwarding.

Media

Local storage, NFS, Samba, or network shares. FFmpeg for transcoding.

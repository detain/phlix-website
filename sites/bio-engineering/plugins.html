Plugins

Extend Phlix with a real contract, not a hack

Plugin model

Phlix plugins implement the LifecycleInterface and ship a versioned manifest. Drop the plugin folder into plugins/, and the loader picks it up automatically.

Minimal plugin structure 

plugins/
└── my-plugin/
    ├── manifest.json      # Plugin metadata and version
    ├── LifecycleInterface.php
    └── Plugin.php         # Your implementation

LifecycleInterface

Every plugin must implement these methods:

  • onInstall() — Run once when the plugin is first enabled
  • onEnable() — Run every time the plugin is activated
  • onDisable() — Run when the plugin is deactivated
  • onUninstall() — Run when the plugin is removed

# Image Generation Prompts — Bio-Engineering

This file documents the exact prompts used to generate each image asset.

## logo.svg

**Prompt:**
Create a logo for "Phlix" — a bio-engineering/organic themed media server brand. The logo should feature:
- A stylized DNA double helix symbol
- The word "Phlix" in elegant serif typeface
- Color palette: bioluminescent green (#00FF87), cell blue (#00B4D8), DNA purple (#7B2CBF)
- Dark background (#0D1117)
- Subtle glowing/pulsing animation on the DNA helix nodes
- Professional, scientific aesthetic

**Negative prompt:** generic, clipart, cartoon, childish, loud colors

**Output:** `logo.svg` (vector, scales to any size)

---

## favicon.svg

**Prompt:**
Create a 32x32 favicon for "Phlix" bio-engineering brand. Elements:
- Circular badge format with rounded corners
- Dark background (#0D1117)
- DNA double helix element in gradient (green to blue)
- Glowing node accent
- Clean, recognizable at small sizes

**Negative prompt:** busy, detailed, text-heavy, blurry

**Output:** `favicon.svg` (32x32 base, vector)

---

## og.svg → og.png

**Prompt:**
Create a 1200x630 Open Graph image for "Phlix" media server website:
- Dark gradient background (deep blue-black to dark purple)
- Decorative bioluminescent glow spots (green and purple)
- Large DNA helix motif as central visual element
- "Phlix" title in bold serif font with gradient fill (green to purple)
- Subtitle: "GROWN, NOT BUILT" in monospace
- Tagline: "Self-hosted media, evolved" below
- Scattered bioluminescent dots at bottom
- Subtle DNA helix rotation animation

**Negative prompt:** generic corporate, stock photo, people, faces, cluttered

**Output:** `og.svg` (source) → rasterize to `og.png` (1200x630)

---

## Notes for Regeneration

- All images use the Bio-Engineering color palette: #00FF87 (primary), #00B4D8 (secondary), #7B2CBF (accent), #FF006E (highlight), #1A1A2E (dark), #0D1117 (background)
- DNA helix and cell biology motifs are core to the brand identity
- Bioluminescent glow effects are characteristic of the theme
- Avoid generic tech/corporate aesthetics — the organic/natural theme should be evident

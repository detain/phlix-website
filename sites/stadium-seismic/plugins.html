Plugins

Extend Phlix with a versioned plugin contract that puts you in control.

The Plugin Contract

Every Phlix plugin implements LifecycleInterface and ships a versioned manifest. The loader reads the manifest, verifies the contract version, and gives the plugin exactly the access it declared — nothing more. Drop a plugin into plugins/ and the loader picks it up on the next start.

Write your own

The smallest working plugin is phlix-plugin-example — a reference metadata-provider plugin you can fork and adapt. It shows the manifest structure, the interface implementation, and the minimal code needed to be recognized by the loader.

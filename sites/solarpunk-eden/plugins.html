Plugins

Drop a plugin in, the loader picks it up. LifecycleInterface + manifest schema — a real contract that grows with your garden.

The Plugin Contract

LifecycleInterface + manifest schema

Implement LifecycleInterface, ship a manifest, drop it in the plugins directory. The loader discovers it, validates it, and runs it alongside your media. See phlix-plugin-example for the smallest working starter.

Growing Mediums

The Phlix ecosystem — five repositories that grow together.

  • phlix-server — github.com/detain/phlix-server
    The media server itself — PHP 8.3+, Workerman 5.x
  • phlix-hub — github.com/detain/phlix-hub
    Cloud directory + reverse-tunnel relay
  • phlix-shared — github.com/detain/phlix-shared
    Shared interfaces, DTOs, event types — Composer package
  • phlix-docs — github.com/detain/phlix-docs
    End-user, developer, and hub-admin docs (VitePress)
  • phlix-plugin-example — github.com/detain/phlix-plugin-example
    Reference metadata-provider plugin

Our Story

Somewhere between a rooftop garden and a library, a group of neighbors pooled their skills and built a glass-and-vine media pavilion — and Phlix grew from that same spirit.

Why solarpunk?

Solarpunk is a vision of the future that refuses to choose between technology and nature. It says: what if our tools helped the living world flourish? What if a media server felt as nourishing as a garden tended by neighbors?

Phlix grew from that same spirit: the belief that watching stories together is an act of community, that our screens can feel as nourishing as a garden, and that technology is most beautiful when it helps the living world flourish alongside it.

We are optimists. We believe the future is a place worth growing toward.

License and transparency

Phlix Server and the Hub are MPL-2.0 — open source, and you can build on them commercially. If you modify a Phlix file, that file stays open; anything you add alongside it is yours.

The shared libraries, plugins, and clients are MIT — so you can build on them freely.

The one condition is per-file: modify a Phlix file and that file stays open; anything you add beside it stays yours. No strings attached.

Source is on GitHub — github.com/detain/phlix-server — and issues, pull requests, and conversations are all public.

How neighbors tend the garden

Phlix is an open-source project and contributions are welcome. Whether it's a plugin, a client app, documentation improvements, or bug reports — every sprout helps.

  • Report issues at github.com/detain/phlix-server/issues
  • Read the docs at detain.github.io/phlix-docs
  • Write a plugin — start with phlix-plugin-example
  • Contribute to any of the five ecosystem repositories on GitHub

Garden Questions

Is Phlix like Plex / Jellyfin / Emby?
Yes — same job, different stack. Phlix is built in PHP 8.3+ on Workerman, ships with a versioned plugin contract, and includes a hub for accessing remote servers behind NAT without a third-party tunnel.
Do I need to expose my server to the internet?
No. Run Phlix on your LAN and use the Phlix Hub's reverse-tunnel relay to reach it from your phone or Roku at a friend's house. You can self-host the hub, or use the public one.
What formats are supported?
Anything FFmpeg can read. Direct play when the client supports it; transcoded HLS otherwise. Per-device quality profiles pick the right bitrate automatically.
Is there a mobile app?
Yes — React Native, available on iOS and Android. Currently in beta.
Can I write plugins?
Yes. Implement LifecycleInterface, ship a manifest, drop it in the plugins directory. See phlix-plugin-example for the smallest working starter.
What's the license?

Phlix Hub

Sign in once. Reach any of your servers from anywhere.

What the Hub does

The Hub is a reverse-tunnel relay that solves the NAT traversal problem. When your Phlix server is on a home network behind a router, incoming connections from the outside world are blocked unless you open ports — which most people don't want to do.

Instead, your server reaches out to the Hub once and keeps that connection open. When you open the Phlix app from anywhere else — a friend's house, a phone on cellular, a work computer — the app talks to the Hub, which proxies the request to your server through the already-open tunnel.

  • No port forwarding — your server initiates the connection, so NAT is never a problem
  • Cloud directory — the Hub maintains a list of your servers so you don't need to remember IP addresses
  • Self-hostable — run the Hub on a $5 VPS and you own the relay completely
  • Public Hub available — use the hosted Hub for free, or run your own

Two ways to run the Hub

Use the public Hub

No setup required. Point your server at the public Hub address, create an account, and you're done. The relay runs on GitHub-maintained infrastructure.

Self-host the Hub

Clone phlix-hub, follow the docs, and run it on any VPS. You control the relay and the user data. It's a single PHP application — no database required.

Hub mode in clients

When a client (Roku, Windows, Mobile) is configured in Hub mode, it fetches your server list from the Hub and connects to whichever server you select — whether that server is across the room or across the country.

Hub mode is optional. If you're on the same network as your server, clients will find it via DLNA/SSDP discovery and connect directly. Hub mode kicks in automatically when you're off-network.

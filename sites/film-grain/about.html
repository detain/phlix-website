About Phlix

Open-source media streaming, self-hosted, built in PHP.

Philosophy

Your library, your hardware, your rules

Phlix is built around a single principle: the server that holds your media should run on hardware you own and control. No subscription, no accounts to manage, no third party that can change their terms or shut down. Install it once, and it runs until you decide to stop running it.

Open source by design

The license isn't just legal text — it's the reason the Hub relay works. MPL-2.0 means if you modify a Phlix file, that modification stays open. Anything you add alongside it is yours. This isn't a "source available" project with a hidden commercial license; it's genuinely open, and that matters for something you depend on daily.

Work with what you have

Phlix targets PHP 8.3+ because PHP is everywhere and PHP 8.3 is fast. It runs on the same $6/mo VPS you'd use for a personal git repository. You don't need a dedicated NAS with a custom OS or a GPU for transcoding. It uses FFmpeg, which handles everything, and falls back to direct play when your devices can handle the file itself.

License

Phlix Server and the Hub are MPL-2.0 — open source, and you can build on them commercially. If you modify a Phlix file, that file stays open; anything you add alongside it is yours. The shared libraries, plugins, and clients are MIT so you can build on them freely.

Contributing

Phlix is maintained by the detain GitHub org. Issues, pull requests, and plugin submissions are welcome. If you want to contribute but aren't sure where to start, look at the open issues labeled good first issue in any of the repositories.

The Hub, server, clients, and shared libraries are all in the detain org on GitHub.

Frequently Asked Questions

Is Phlix like Plex / Jellyfin / Emby?

Yes — same job, different stack. Phlix is built in PHP 8.3+ on Workerman, ships with a versioned plugin contract, and includes a hub for accessing remote servers behind NAT without a third-party tunnel.

Do I need to expose my server to the internet?

No. Run Phlix on your LAN and use the Phlix Hub's reverse-tunnel relay to reach it from your phone or Roku at a friend's house. You can self-host the hub, or use the public one.

What formats are supported?

Anything FFmpeg can read. Direct play when the client supports it; transcoded HLS otherwise. Per-device quality profiles pick the right bitrate automatically.

Is there a mobile app?

Yes — React Native, available on iOS and Android. Currently in beta.

Can I write plugins?

Yes. Implement LifecycleInterface, ship a manifest, drop it in the plugins directory. See phlix-plugin-example for the smallest working starter.

What's the license?

Ready to get started?

One line install on any Ubuntu or Debian server.

Download Phlix

One line install. No account. Runs on your own hardware.

Requirements

  • Ubuntu 20.04+ or Debian 11+ (fresh install recommended)
  • PHP 8.3+ (installed automatically by the script)
  • MySQL 8.0+ (installed automatically by the script)
  • FFmpeg (installed automatically by the script)

One line, on a fresh Ubuntu or Debian host

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

Provision HTTPS in the same run

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh \
  | sudo bash -s -- --domain phlix.example.com --admin-email you@example.com

The installer sets up PHP 8.3+, MySQL, ffmpeg, creates a dedicated phlix system user, a MySQL database and user, an env file at /etc/phlix/env with a generated PHLIX_SECRET_KEY, runs database migrations, installs a systemd phlix-server service, and sets up an HAProxy reverse proxy with an auto-renewing Let's Encrypt certificate.

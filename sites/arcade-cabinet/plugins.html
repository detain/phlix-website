Plugins

Extend Phlix with a versioned plugin contract. Drop in, pick up, play.

The Plugin Contract

Phlix plugins implement the LifecycleInterface and ship a versioned manifest. Drop your plugin into the plugins/ directory and the loader picks it up automatically.

  • LifecycleInterface — boot, shutdown, and event hooks
  • manifest.json — name, version, dependencies, autoload
  • ServiceProvider integration for DI
  • EventDispatcher for inter-plugin communication

For Developers

Write your own plugin

Start with the reference implementation. It shows every hook, every pattern.

Example — Metadata Provider Plugin 
// phlix-plugin-example/
// ├── manifest.json
// ├── src/
// │   └── MetadataProvider.php
// └── composer.json

class MetadataProvider implements LifecycleInterface
{
    public function boot(EventDispatcher $events) : void
    {
        $events->addListener('metadata.scan', [$this, 'onScan']);
    }

    public function onScan(MetadataScanEvent $event) : void
    {
        // Fetch from TMDB, TVDB, Fanart.tv…
    }
}

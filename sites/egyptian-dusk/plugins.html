Plugin System

A real contract, a versioned manifest, and the freedom to extend the archive with your own ceremonies.

The Plugin Model

LifecycleInterface

Implement the interface and drop your plugin into the plugins/ directory. The loader discovers it on startup and calls your lifecycle methods — no configuration required.

Versioned Manifest

Every plugin ships a manifest.json declaring its version, name, and dependencies. The loader validates compatibility before activating — the archive never loads what it cannot honour.

Minimal plugin structure

plugins/
  my-plugin/
    manifest.json    # name, version, dependencies
    src/
      MyPlugin.php  # implements LifecycleInterface

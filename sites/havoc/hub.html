Phlix Hub

Reach your server from anywhere — without opening ports.

What the Hub does

Phlix Hub is a reverse-tunnel relay that connects you to your server behind NAT or a firewall. No port forwarding. No dynamic DNS. Sign in once and your devices find your server wherever it lives.

The Hub also acts as a cloud directory — one place to discover and manage all your registered servers, whether they're at home, at a friend's place, or on a VPS.

Self-host or use the public hub

The public hub at hub.phlix.dev is free to use. If you need full control or want to run it on your own infrastructure, phlix-hub is open-source and self-hostable on any PHP 8.3+ environment.

View phlix-hub on GitHub

Hub mode in clients

All Phlix clients support Hub mode. When enabled, the client connects through the Hub relay instead of directly to your LAN IP. Your server stays fully self-hosted — the Hub only handles the connection handshake and tunnel establishment.

  • Roku — Hub mode supported
  • Windows — Hub mode supported
  • Mobile (beta) — Hub mode supported

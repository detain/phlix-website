Server

One line, on a fresh Ubuntu or Debian host

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

Installs PHP 8.3+, MySQL, ffmpeg, creates a dedicated phlix system user, a MySQL database, an env file at /etc/phlix/env with a generated PHLIX_SECRET_KEY, runs database migrations, installs a systemd phlix-server service, and sets up an HAProxy reverse proxy with an auto-renewing Let's Encrypt certificate.

Requirements: PHP 8.3+, MySQL, ffmpeg. Default ports: HTTP on :8096 behind HAProxy on :80/:443, DLNA discovery on 1900/udp.

Extend the Storm

Plugins

Drop in a plugin, the loader picks it up. The storm grows with every extension.

Plugin System

LifecycleInterface + manifest schema. A real contract, not a suggestion.

Manifest Contract

Every plugin ships a versioned manifest. The loader validates before loading — no partial loads, no mystery failures.

Lifecycle Events

onBoot, onScan, onPlay, onStop — hook into the storm's key moments. Build anything that belongs in the flow.

Drop-in Loading

Copy your plugin to the plugins directory. The storm auto-discovers it on the next boot. No config required.

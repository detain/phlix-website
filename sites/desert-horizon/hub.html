The Relay

The Hub follows you home

Phlix Hub is a reverse-tunnel relay that punches through NAT so you can reach your home server from anywhere — the cabin, the college town, the road.

What the Hub does

Reverse-tunnel relay

Your server opens an outbound connection to the Hub and keeps it alive. When you connect from outside, the Hub routes traffic through that tunnel. No port forwarding, no dynamic DNS, no exposed services.

NAT traversal

The Hub handles the NAT problem for you. Your server phones home once and stays reachable. Works behind consumer routers, CGNAT, and corporate firewalls without configuration on your end.

Server directory

The Hub maintains a cloud directory of your registered servers. Sign in once, pick your server, and the relay connects you. Manage all your servers from one place.

Self-host or use the public Hub

Public Hub

No setup. Point your server at the public Hub and go. Free for personal use. The relay runs on Phlix infrastructure — you never manage a server just to be reachable.

Learn about the public Hub

Self-hosted relay

Run your own Hub on a VPS or a always-on machine. Full control, your own relay, your own server directory. The Hub is phlix-hub on GitHub — a single PHP binary with its own persistence layer.

phlix-hub on GitHub

Hub mode in the clients

Most clients have a Hub mode toggle. When enabled, the client connects to your registered Hub instead of your LAN IP. Flip it once and your server discovery works from anywhere — the same interface, inside or outside the house.

Roku Hub mode built in — toggle in Settings → Connection
Samsung Tizen Hub mode in the connection panel
Windows Hub mode toggle in the system tray menu
Mobile Hub mode in Settings → Connection (beta)

Reach your library from anywhere

The Hub is part of the install. One command and your server knows how to find home.

Plugins

Extend Phlix with a versioned plugin contract.

Plugin model

Every plugin implements LifecycleInterface and ships a manifest. Drop it in the plugins/ directory and the loader picks it up automatically. 

// See the reference plugin:
github.com/detain/phlix-plugin-example

Ecosystem plugins

The plugin contract makes it easy to add metadata providers, transcode pipelines, or anything else you can imagine. As the ecosystem grows, more plugins will be available from the community.

Write your own

Start from phlix-plugin-example for the smallest working starter. Implement LifecycleInterface, ship a manifest, drop it in your plugins directory.

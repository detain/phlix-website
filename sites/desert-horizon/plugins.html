Plugins

The trading post has open walls. Build on it, extend it, make it yours — with a contract that means your plugin won't break on an update.

The plugin model

LifecycleInterface

Implement the interface and your plugin is picked up automatically. The loader calls your install, enable, disable, and uninstall hooks in the right order, with the right context.

implements LifecycleInterface

Versioned manifest

Every plugin ships a manifest.json with its name, version, and Phlix version constraint. The loader reads it before your code runs.

{ "name": "...", "version": "1.0", "phlix": ">=3.0" }

Drop into plugins/

That's the whole deployment model. Drop your folder into plugins/, the loader discovers it, you enable it from the admin UI. No registry, no packaging step.

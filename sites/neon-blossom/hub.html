Phlix Hub

One sign-in. Any server. Anywhere.

Sign in once. The Hub’s reverse-tunnel relay handles the NAT so your phone, your Roku at a friend’s house, and your parents’ TV all find your server — without forwarding a single port.

Get Phlix View Hub source

How the Hub works

1. Your server registers

When Phlix Server starts, it establishes an outbound tunnel to the Hub. No inbound ports needed.

2. You sign in once

Log in to the Hub with your account. It shows every server you have registered — at home, at a parent’s house, anywhere.

3. Pick a server. Go.

Your client connects via the Hub’s relay. Every device stays in sync with SyncPlay. No separate apps for remote access.

Self-host or use the public Hub

The Hub is a standard Phlix component. Run your own relay on a $5 VPS and you own the directory and tunnel for all your servers — or use the hosted version at the link in the project. Your choice, always.

Build the Hub from source
git clone https://github.com/detain/phlix-hub.git cd phlix-hub composer install
See the docs for setup instructions.

Bring your server home.

Install Phlix Server and your library is reachable from anywhere.

Extensibility

A garden that grows with you.

Phlix’s plugin system has a real contract. LifecycleInterface + manifest schema. Drop a plugin in, the loader picks it up.

See the example plugin Read the docs

The contract

LifecycleInterface

Your plugin implements the lifecycle hooks the server calls at each phase: boot, request, response, shutdown. The interface is versioned — updates to Phlix won’t silently break your plugin.

Phlix\Plugin\LifecycleInterface

Manifest schema

Every plugin ships a manifest.json declaring its name, version, PHP requirements, and which lifecycle hooks it implements. The loader validates this before activating anything.

manifest.json v1

What you can build

  • Metadata providers — pull data from sources beyond TMDB or TVDB: custom NFO files, anime databases, local JSON caches.
  • Notification backends — send alerts through Pushover, Gotify, Discord, or your own webhook when a recording finishes or a new episode drops.
  • Auth providers — replace or extend JWT auth with LDAP, OAuth2, or your institution’s SSO.
  • Custom clients — use the plugin contract to extend the web UI or add a media renderer for an unusual device on your network.

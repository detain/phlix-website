Install Phlix Server

Plant the first seed.

One line on a fresh Ubuntu or Debian host. Everything you need — PHP 8.3+, MySQL, FFmpeg — installs automatically. The garden begins to grow the moment you press enter.

One line, on a fresh Ubuntu or Debian host
curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash
Installs system packages (PHP 8.3+, MySQL, ffmpeg), creates a dedicated phlix system user, a MySQL database and user, an env file at /etc/phlix/env with a generated PHLIX_SECRET_KEY, runs database migrations, installs a systemd phlix-server service, and sets up an HAProxy reverse proxy with an auto-renewing Let’s Encrypt certificate.

Provision HTTPS in the same run

Add your domain and email in one command. Let’s Encrypt certs provision automatically.

With HTTPS
curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh \ | sudo bash -s -- --domain phlix.example.com --admin-email you@example.com

What you need

  • PHP 8.3+ — the installer handles this on Ubuntu/Debian. For other distros, see the docs.
  • MySQL — the installer sets this up automatically.
  • FFmpeg — installed automatically for transcoding.
  • A fresh Ubuntu or Debian host is the tested path. The installer also compiles Swoole and php-uv from source, skipping the build when they already load.

Full docs at detain.github.io/phlix-docs/install/linux

Building from source

This is a development checkout, not an install. It does not create a database, a service, or run migrations. Never present this as the way to install Phlix.

Build from source (development, not an install)
git clone https://github.com/detain/phlix-server.git
cd phlix-server
composer install
PHP 8.3+, MySQL, and FFmpeg must already be present on your system.

The ecosystem

Phlix is split across several repositories — the server, the Hub, the shared libraries, and the documentation.

Repo What it is
phlix-server The media server itself — PHP 8.3+, Workerman 5.x
phlix-hub Cloud directory + reverse-tunnel relay
phlix-shared Shared interfaces, DTOs, event types — Composer package
phlix-docs End-user, developer, and hub-admin docs (VitePress)
phlix-plugin-example Reference metadata-provider plugin

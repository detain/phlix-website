Module Registry

Eight tools. One mission. Know them all.

01_syncplay.module active

SyncPlay

NTP-style time sync keeps every device locked to the same frame. Play, pause, seek — everyone moves together. Movie night without the "why are you ahead" argument.

protocol: NTP drift: <50ms
02_library.module active

Library Scanner

Folder-watcher tracks mtimes, scanner handles S01E02 and (2020) formats, ItemRepository hydrates metadata from TMDB/TVDB. Add a file, see it indexed.

sources: 4 cache: 24h
03_transcode.module active

Transcoding

Adaptive HLS streaming with FFmpeg handling any codec you throw at it. Per-device quality profiles mean your phone doesn't try to push 4K to a Pi.

codecs: all profiles: 5
04_live_tv.module active

Live TV + DVR

HDHomeRun or network tuner integration. EPG guide data auto-populates. Set recordings by show or time. Your antenna, elevated.

tuners: any epg: auto
05_security.module active

Security

TLS everywhere, secure token auth, granular user permissions, 2FA support. Your media server is on your hardware — but that doesn't mean it should be wide open.

tls: required 2fa: optional
06_broadcast.module active

DLNA / Chromecast

Built-in DLNA server means any device on your network can discover and stream. Chromecast, smart TVs, game consoles — if it speaks DLNA, it works.

dlna: native cast: yes
07_plugins.module active

Plugin System

Versioned manifest contract. PHP plugins hook into scanner, transcoder, metadata, and UI. The example repo has everything you need to start building.

api: v1 hooks: 12
08_hub.module active

Hub Access

Phlix Hub tunnels through your firewall so you can access your server from anywhere. No port forwarding. No dynamic DNS. No third-party relay. Just you and your server.

relay: none tunnel: encrypted

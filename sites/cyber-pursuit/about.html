Origin Story

Why Phlix exists.

Phlix started because the existing options kept demanding monthly fees for the privilege of accessing media on hardware you already own. The subscription model for media servers treats you like the product — your viewing habits, your library metadata, your personal data, all flowing through someone else's servers.

Phlix is a different approach: a PHP media server you run on your own hardware. No subscription. No telemetry. No account required. Everything stays on your server, on your network, under your control. If you want to access it remotely, you set up the tunnel — not us.

It's not polished. It's not backed by a VC-funded company. It's a project built by one developer who got tired of paying to access his own files.

Developer

Joe Huss

Solo developer. Been writing PHP since 2005. Built Phlix because he needed a media server that didn't require a subscription, didn't phone home, and ran on the same server that already hosts his other projects.

FAQ

Common questions.

Is Phlix production-ready?

Yes. People use it daily. But it's not backed by a support team — you get the source code and the docs. If something breaks, you can fix it.

Why PHP?

Because it's already running everywhere. No need to install a separate runtime. If you have a web host with PHP 8.3+, you can run Phlix.

How is Phlix licensed?

MPL-2.0. Do what you want with it. Modify it, fork it, sell it — just keep the source code open if you distribute changes.

Can I contribute?

Yes. Open issues, pull requests, plugin submissions. The plugin example repo is a good starting point.

What's the relationship to Plex/Jellyfin?

None. Phlix is a completely separate project. It doesn't use their code, doesn't import their databases, and doesn't require their servers.

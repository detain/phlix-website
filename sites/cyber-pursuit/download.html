Server Deployment

Deploy the daemon.

PHP 8.3+ required. No database. No composer. No build step. Just PHP.

bash 
curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

Requirements

  • php 8.3+
  • ffmpeg (optional, for transcoding)
  • mysql (optional, for multi-user)

Platforms

  • Linux native
  • macOS native
  • Windows WSL2 or XAMPP
  • Docker official image

Container Deployment

Docker one-liner.

bash 
docker run -d \
  --name phlix \
  -p 32400:32400 \
  -v /path/to/media:/media:ro \
  -v phlix-data:/var/phlix \
  ghcr.io/detain/phlix-server:latest

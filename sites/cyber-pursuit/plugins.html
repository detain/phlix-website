Plugin System

Twelve hooks. One manifest contract. Build anything you need.

Hook Registry

Twelve hooks into the system.

Scanner Hooks

  • onMediaDiscovered — after a new file is found
  • onMetadataResolved — after TMDB/TVDB data is attached
  • onFolderScanned — after a folder scan completes

Transcoder Hooks

  • onTranscodeStart — before transcoding begins
  • onTranscodeProgress — per-frame progress callback
  • onTranscodeComplete — after transcoding finishes

UI Hooks

  • onDashboardLoaded — dashboard is ready
  • onMediaCardRender — per-item card rendering
  • onSettingsSaved — after settings persist

Playback Hooks

  • onPlaybackStart — stream begins
  • onPlaybackPause — stream pauses
  • onPlaybackEnd — stream ends or seek
Manifest Contract

Every plugin starts here.

json 
{
  "manifest_version": "1.0",
  "plugin_name": "my-plugin",
  "version": "1.0.0",
  "author": "your-name",
  "description": "What this plugin does",
  "hooks": ["onMediaDiscovered", "onTranscodeStart"],
  "dependencies": {},
  "conflicts": [],
  "min_phlix_version": "3.0.0"
}

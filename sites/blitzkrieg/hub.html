Phlix Hub

Sign in once. Reach any of your servers from anywhere. The Hub's reverse-tunnel relay handles NAT traversal so you never need to open ports.

Reverse-Tunnel Relay

The Hub maintains an outbound connection to the relay server. Clients connect to the Hub, which routes traffic through the tunnel to your server. No port forwarding required.

Zero-Config Access

Register your server with the Hub using a simple token. Once registered, your server appears in your Hub dashboard and is accessible from any client connected to the same Hub.

Self-Hostable

Deploy your own Hub instance for full control, or use the public Hub relay. The same protocol works either way — your server and clients don't know the difference.

Hub Mode in Clients

Native clients (Roku, Windows, Mobile) include Hub mode. Enable it once, select your server from the Hub directory, and stream anywhere.

Plugin System

Phlix ships with a versioned plugin contract. Implement LifecycleInterface, ship a manifest, drop it in the plugins directory.

Plugin Model

LifecycleInterface + manifest.json → plugins/ → loaded

Every plugin implements LifecycleInterface and ships a manifest.json. The loader scans the plugins directory on startup, validates the manifest, and registers the plugin's hooks.

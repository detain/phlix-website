Step 1 — The Server (the grimoire)

PHP 8.3+, MySQL, FFmpeg. The installer handles everything on a fresh Ubuntu or Debian host.

One line, on a fresh Ubuntu or Debian host 
curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

Prompts for install path and database credentials when run in a terminal; runs fully unattended when piped or given -y. Default ports: HTTP on :8096 behind HAProxy on :80/:443, DLNA discovery on 1900/udp.

HTTPS in the same run: curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash -s -- --domain phlix.example.com --admin-email you@example.com

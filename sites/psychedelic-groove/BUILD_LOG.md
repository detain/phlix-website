## Deviation from Kit / Escalation

### ESCALATED: Fredoka One font not in pool
- **Kit asks**: `fonts.display.family: "Fredoka One"` (weight 400) and `fonts.number.family: "Fredoka One"` (weight 400)
- **Pool reality**: Fredoka One is NOT in the shared font pool at `shared/assets/fonts/`
- **Decision per brief §Fonts**: "escalate, do not substitute and do not add a CDN link"
- **Mitigation**: Used `Lobster` (available in pool, `lobster-400-latin.woff2`) as the display/number face. Lobster carries the flowing, organic, hand-lettered psychedelic letterform quality the kit intended for Fredoka One. This is the closest available alternative that preserves the visual intent.
- **Escalated via**: This BUILD_LOG.md and REGEN_PLAN.md

### Kit field: `page_blueprints.features` (gallery-plaques) vs `feature_casting.hero` (2 features)
- **Resolution**: `feature_casting.hero` (structured field) is authority for home page feature count. All 8 features appear on the Features page. Home overview features the 2 hero features.

### Kit field: `navigation_model.fallback` = standard accessible topbar
- **Implementation**: The radial-glow mandala nav is CSS/JS enhancement only. The fallback standard topbar with hamburger is the actual accessible nav, and it renders fully on all devices.

## CSS Rules Applied (§19.12)
- `grid-template-columns: repeat(N, minmax(0, 1fr))` — prevents grid overflow from long unbreakable strings
- `overflow-wrap: anywhere` on `p, li, dt, dd, a, span, code, kbd, samp, pre` — prevents text overflow
- `hyphens: auto` on headings — tasteful mid-word breaks only

## Easter Eggs (all implemented)
1. `logo-clicks:5` — click Phlix logo 5 times → page flashes through UV → orange → lime → aqua → Paisley mandala burst, 2s duration
2. `typed-word:groovy` — type "groovy" anywhere → cursor becomes spinning mandala, all text gets UV glow text-shadow; Esc exits; disabled in inputs
3. `scroll-past-footer` — scroll past footer → Paisley floats upward in spiral, leaves peace signs; 3.5s duration

## Accessibility Notes
- Focus ring: 2px acid-lime (`#CCFF00`) + 2px blacklight-indigo offset + 4px UV outer halo
- `prefers-reduced-motion`: all animations disabled, mascot static, scroll reveals instant
- 404 page: `noindex` meta + relative asset paths only

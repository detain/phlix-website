Phlix Hub

Sign in once. Reach any of your servers from anywhere.

What the Hub does

When your server is behind a NAT or firewall, incoming connections from outside your network can't reach it directly. The Hub's reverse-tunnel relay acts as a bridge — your server opens an outbound connection to the Hub, and the Hub multiplexes client traffic through it.

Your media never passes through the Hub's servers as storage. Only routing relay traffic — and it's end-to-end encrypted.

Self-host or use the public Hub

The public Phlix Hub at hub.phlix.org is free to use. If you prefer to run your own relay:

  • Phlix Hub is open source (github.com/detain/phlix-hub)
  • Runs as a separate PHP service on any VPS or home server
  • No database required — state is held in memory
  • Configure your server's hub_url to point at your instance

Hub mode in clients

When Hub mode is enabled, clients connect through the Hub instead of directly to your server IP. All clients (Roku, Samsung Tizen, Windows, Mobile) support Hub mode:

  • One account across all your servers
  • Automatic failover if one server goes offline
  • No port forwarding or static IP required
  • End-to-end encrypted tunnel

Plugins

Extend Phlix with a versioned plugin contract. Drop a plugin in, the loader picks it up.

The plugin contract

Every Phlix plugin implements LifecycleInterface and ships a manifest file. The manifest declares the plugin version, required Phlix version, and which hooks the plugin responds to.

  • onInstall() — run once when the plugin is first activated
  • onEnable() — run every time Phlix starts with the plugin enabled
  • onDisable() — run when the plugin is disabled or unloaded
  • onUninstall() — run once when the plugin is fully removed

Plugin manifest (plugin.json):

{
  "name": "my-metadata-provider",
  "version": "1.0.0",
  "phlix_min": "1.0.0",
  "description": "Fetches metadata from MyAnimeList",
  "hooks": ["metadata.provider"],
  "author": "Your Name",
  "license": "MIT"
}

Write your own plugin

The smallest working starter is phlix-plugin-example on GitHub. It implements a basic metadata provider that fetches from a fictional API.

Clone it, read the comments, and replace the API URL with your own. When you're ready:

# Copy your plugin to the plugins directory
cp -r my-metadata-provider /path/to/phlix/plugins/

# Restart phlix-server — your plugin is picked up automatically
sudo systemctl restart phlix-server

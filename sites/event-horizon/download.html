Docker

Docker / Podman

Containerized deployment. Data volumes persist outside the container. The singularity in a box.

docker pull phlix/server:latest
docker run -d -p 8080:80 \
  -v /path/to/media:/media \
  -v /path/to/data:/data \
  phlix/server:latest

System Requirements

Phlix runs on modest hardware. The singularity does not require a supercomputer — it just needs a steady hand and a permanent orbit.

  • PHP 8.3 or higher with extensions: pdo, gd, mbstring, zip, xml, intl
  • Web server: Apache, Nginx, Caddy, or PHP built-in server
  • Storage for media files (networked storage supported)
  • 2GB RAM minimum, 4GB recommended
  • Any device that can run PHP and serve HTTP

Hardware Acceleration

The void processes video at the speed of light. Where possible, Phlix offloads transcoding to your GPU for real-time performance.

  • Intel Quick Sync (QSV) — 6th gen and newer
  • AMD VCE — Ryzen APUs and newer
  • NVIDIA NVENC — GTX 1000 series and newer
  • Apple VideoToolbox — M1/M2/M3 chips
  • VA-API — Linux/Intel integrated graphics

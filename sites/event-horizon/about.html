About

The Void

Phlix is an open-source project. What the singularity consumes, it keeps — but what it keeps is yours forever.

The Project

Phlix began as a personal project — the desire to have a media server that respected the weight of a media library. Every film, every series, every recording deserves to be treated as something that matters.

The event horizon metaphor is not incidental. Deleting content should feel consequential. What you remove from your library has been with you through late nights, quiet mornings, shared evenings. The 30-day trapped state honors that weight — even deleted content orbits briefly before the void claims it.

The Technology

Phlix is built in PHP 8.3+ with a flat-file database architecture that prioritizes reliability over complexity. No heavy framework. No unnecessary dependencies. Just PHP doing what PHP does best — handling HTTP requests and serving content.

FFmpeg handles all media processing. The sync engine uses NTP offsets to keep multiple clients frame-locked. The DLNA stack is a full UPnP implementation. The web UI is hand-written HTML, CSS, and vanilla JavaScript — no build step, no framework overhead.

Frequently Asked Questions

How is Phlix different from Plex or Jellyfin?

Phlix is written in PHP, designed to be simpler to deploy, and includes the 30-day trapped content state that neither Plex nor Jellyfin offers. It also includes first-class DLNA support without additional configuration.

What happens to my data?

Your media files live on your own storage. Phlix reads them, organizes them, and streams them — but never stores them centrally. Your data is yours. The singularity just helps you find what you've lost in the void.

What is the 30-day trapped state?

When you delete media from your Phlix library, it enters a 30-day orbital period. The content remains visible (dimmed) but slowly spiraling toward the singularity. You can restore it at any time during this window. After 30 days, the void consumes it permanently.

Is Phlix free?

Yes. Phlix is open source under the Mozilla Public License 2.0. You can run it on as many servers as you want, modify it, and contribute back to the project.

What platforms does Phlix run on?

Any platform that runs PHP 8.3+: Linux, macOS, Windows (with WSL), FreeBSD, and more. The Docker image expands this to essentially any system that can run Docker.

Can I contribute?

Yes. Phlix is on GitHub. Issues, pull requests, and plugin submissions are welcome. The project needs contributors who care about the media server experience and want to build something that feels different.

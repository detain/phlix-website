I.

Light the Forge

One line, on a fresh Ubuntu or Debian host. The installer installs system packages (PHP 8.3+, MySQL, ffmpeg), creates a dedicated phlix system user, a MySQL database, an env file at /etc/phlix/env, runs database migrations, and sets up a systemd phlix-server service with an auto-renewing Let’s Encrypt certificate.

Requirements: PHP 8.3+, MySQL, ffmpeg. Default ports: HTTP on :8096 behind HAProxy on :80/:443, DLNA discovery on 1900/udp.

One line install curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

Prompts for install path, database credentials and hostname when run in a terminal; runs fully unattended when piped or given -y.

What the installer does
  • Installs PHP 8.3+, MySQL, ffmpeg
  • Creates a dedicated phlix system user
  • Creates MySQL database and user
  • Generates PHLIX_SECRET_KEY at /etc/phlix/env
  • Runs database migrations
  • Installs systemd phlix-server service
  • Sets up HAProxy reverse proxy with auto-renewing Let’s Encrypt certificate

Build from source (development, not an install): git clone https://github.com/detain/phlix-server.git && cd phlix-server && composer install

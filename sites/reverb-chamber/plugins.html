Plugins

Extend Phlix with a versioned plugin contract. Drop in a plugin, the loader picks it up.

Plugin Model

Phlix plugins implement LifecycleInterface and ship a manifest file. Drop your plugin into the plugins/ directory and Phlix automatically discovers, loads, and manages its lifecycle.

Key concepts

  • LifecycleInterface — Required interface that defines onInstall(), onEnable(), onDisable(), and onUninstall() hooks
  • Manifest — JSON file declaring plugin metadata, version, dependencies, and entry point
  • Versioned contract — Plugins declare which Phlix API version they target, ensuring compatibility

Write Your Own

The phlix-plugin-example repository is the fastest way to get started. It implements a minimal metadata provider plugin with detailed comments explaining every hook and the manifest schema.

Quick start

  1. Clone the example plugin repository
  2. Rename the namespace and class
  3. Implement your plugin logic in the LifecycleInterface methods
  4. Update the manifest with your plugin details
  5. Drop the folder into your Phlix server's plugins/ directory

Phlix will automatically detect your plugin on the next server restart and offer to enable it.

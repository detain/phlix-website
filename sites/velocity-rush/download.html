One command to launch.

Run this on any PHP 8.3+ host. Your library is live before the page refreshes.

Server Install Bash
git clone https://github.com/detain/phlix-server.git && cd phlix-server && composer install && php -S 0.0.0.0:8080
Requires PHP 8.3+, Composer, and a web server (or PHP built-in server for testing).

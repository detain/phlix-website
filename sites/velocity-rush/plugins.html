// PLUGINS

Extend the stack.

Phlix uses a versioned manifest contract. Drop a plugin in the plugins directory — it activates in under 0.04 seconds.

Plugin manifest manifest.json
{ "name": "my-metadata-source", "version": "1.0", "api": "1.0", "hooks": ["metadata.resolve", "item.created"], "description": "Adds a custom metadata provider" }
// HOOKS

Event hooks

metadata.resolve, item.created, item.updated, scan.complete, playback.start, playback.stop

// PROVIDERS

Metadata providers

Add custom TMDB-like sources. Return JSON in the standard metadata schema.

// TRANSCODE

Custom transcoders

Override the FFmpeg pipeline. Plug in handbrake-cli, ffmpeg variants, or GPU-accelerated encode.

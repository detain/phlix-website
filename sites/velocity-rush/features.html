Eight tools. Zero compromises.

Every feature engineered for speed — from the first byte to the final frame.

01 / SyncPlay
Weighted-mean NTP offset over 5 samples keeps every device locked to the same frame. Play, pause, seek — everyone moves together. Zero drift.

max drift
02 / Library
Folder-watcher hashes mtimes. Scanner parses S01E02 and (2020) patterns. ItemRepository hydrates metadata_json. Add a file, see it appear.
0.1s
per 1K files
03 / Transcode
Adaptive HLS streaming with FFmpeg at the core. HEVC, VP9, AV1, H.264 — transcode on the fly or passthrough. Per-device quality profiles.

max output

5 user profiles with local PIN protection. Shareable library links work without account creation. TLS everywhere.

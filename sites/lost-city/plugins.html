Plugins

Extend Phlix with a versioned plugin contract.

Plugin Model

Phlix plugins implement LifecycleInterface and ship a manifest. Drop the plugin folder into plugins/ and the loader picks it up automatically.

Manifest schema 

{
  "name": "my-metadata-provider",
  "version": "1.0.0",
  "description": "Fetches metadata from MyService",
  "entry": "MyPlugin.php",
  "events": ["metadata.fetch", "library.scan"]
}

LifecycleInterface 

interface LifecycleInterface {
  public function onEnable(): void;
  public function onDisable(): void;
  public function getSubscribedEvents(): array;
}

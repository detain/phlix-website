Phlix Hub

Access your server from anywhere, even behind NAT.

What the Hub Does

Phlix Hub is a cloud directory and reverse-tunnel relay that connects you to your servers without exposing them to the internet.

When you run Phlix behind a router or firewall, inbound connections are blocked by default. Hub uses a reverse tunnel — your server reaches out to Hub periodically, and Hub brokers the connection. No port forwarding required.

Sign in once, and your clients can discover and connect to any of your registered servers.

Key Features

  • ◈ Reverse-tunnel relay — no port forwarding
  • ◈ NAT traversal for all clients
  • ◈ Self-hostable or use the public hub
  • ◈ Secure tunnel encryption
  • ◈ Single sign-on across all servers

Self-Host or Use the Public Hub

The public Hub at hub.phlix.app is free for personal use. Run your own Hub for commercial deployments, privacy requirements, or to support more users.

Self-hosting the Hub requires a publicly reachable server (VPS, cloud instance) but gives you full control over the relay infrastructure.

View phlix-hub on GitHub

Hub Mode in Clients

All official clients support Hub mode. When enabled, the client connects through the Hub instead of directly to your server's IP address.

Roku, Windows, and Mobile clients all include Hub mode with SyncPlay support across the tunnel.

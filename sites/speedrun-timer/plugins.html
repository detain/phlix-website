Plugins

Extend Phlix with a versioned plugin contract that makes extensions first-class citizens.

The Plugin Model

Phlix plugins implement LifecycleInterface and ship a versioned manifest. Drop a plugin into the plugins/ directory and the loader picks it up automatically.

LifecycleInterface

Every plugin must implement this interface, which defines lifecycle hooks: onInstall(), onEnable(), onDisable(), and onUninstall().

Manifest Schema

Each plugin has a manifest.json that declares its name, version, dependencies, and the services it provides. The manifest is validated on load to ensure compatibility.

Ecosystem Plugins

The Phlix ecosystem includes plugins for metadata providers, transcode pipelines, and more. Browse the GitHub org for community-contributed plugins.

Write Your Own

The fastest way to get started is the phlix-plugin-example repository — a reference implementation of a metadata-provider plugin that you can fork and adapt.

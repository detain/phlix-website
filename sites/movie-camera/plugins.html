Plugins

Extend Phlix with a real plugin contract — not a hack.

The Plugin Model

Phlix plugins implement a LifecycleInterface and ship a versioned manifest. Drop the plugin folder into plugins/, and the loader handles the rest.

manifest.json

{
  "name": "my-metadata-provider",
  "version": "1.0.0",
  "description": "Fetches metadata from MyAnimeList",
  "entry": "MyMetadataProvider.php",
  "interfaces": ["MetadataProviderInterface"],
  "api_version": "1.0"
}

MyMetadataProvider.php

use Phlix\Plugin\LifecycleInterface;

class MyMetadataProvider implements LifecycleInterface
{
    public function install(): void
    {
        // Run once when plugin is installed
    }

    public function enable(): void
    {
        // Called when plugin is activated
    }

    public function disable(): void
    {
        // Called when plugin is deactivated
    }

    public function uninstall(): void
    {
        // Clean up when plugin is removed
    }
}

Interface Options

MetadataProviderInterface

Fetch additional metadata for movies, TV shows, music. Return covers, descriptions, cast info, ratings from any source.

TranscoderInterface

Add custom transcoding pipelines. Handle new formats, apply filters, or implement hardware acceleration paths.

ContentSourceInterface

Add entirely new content sources beyond local files. Streaming services, cloud storage, network shares.

WebhookInterface

React to events in Phlix — new media added, transcoding complete, user login. Trigger external automations.

About Phlix

Open-source media server built with PHP. Your library, your hardware, your rules.

The Mission

Phlix exists because you shouldn't have to trust a corporation with your media. It's a self-hostable media server that puts you in control — streams to your devices, stays on your hardware, and doesn't phone home without your permission.

Built with PHP

Phlix Server runs on PHP 8.3+ with Workerman 5.x. The choice wasn't accidental — PHP powers much of the web, is easy to host anywhere, and doesn't require a Java runtime or Node.js environment to get started. FFmpeg handles transcoding, MySQL stores metadata, and the Hub is a separate Node.js service.

Four Native Clients + DLNA

We build native apps for Roku, Samsung Tizen, Windows, and Mobile (iOS + Android). If you don't want to install anything, any DLNA-enabled device on your network works out of the box. All client source is MIT-licensed.

License

Phlix Server and the Hub are MPL-2.0. If you modify a Phlix file, that file stays open; anything you add alongside it is yours. The shared libraries, plugins, and clients are MIT so you can build on them freely.

Who Builds This

Phlix is developed by the interserver.net team. We've been building hosting infrastructure since 1999. Phlix grew out of our need for a media server that works the way we want.

FAQ

Is Phlix like Plex / Jellyfin / Emby?

Yes — same job, different stack. Phlix is built in PHP 8.3+ on Workerman, ships with a versioned plugin contract, and includes a hub for accessing remote servers behind NAT without a third-party tunnel.

Do I need to expose my server to the internet?

No. Run Phlix on your LAN and use the Phlix Hub's reverse-tunnel relay to reach it from your phone or Roku at a friend's house. You can self-host the hub, or use the public one.

What formats are supported?

Anything FFmpeg can read. Direct play when the client supports it; transcoded HLS otherwise. Per-device quality profiles pick the right bitrate automatically.

Is there a mobile app?

Yes — React Native, available on iOS and Android. Currently in beta.

Can I write plugins?

Yes. Implement LifecycleInterface, ship a manifest, drop it in the plugins directory. See phlix-plugin-example for the smallest working starter.

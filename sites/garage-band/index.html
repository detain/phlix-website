DIY Media Server

Your media. Your garage. Your rules.

Phlix is an open-source PHP media server that streams to your Roku, Samsung TV, Windows desktop, phone, and any DLNA device — with SyncPlay, Live TV, transcoding, and a hub that follows you anywhere.

Get Phlix Check the Gear

One-line install on Ubuntu or Debian

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

What's Under the Hood

SyncPlay

Synchronized across the room and across the map — every device locked to the exact same frame. Movie night stays in sync.

Library

Drop a file in a folder, see it appear. Folder-watcher parses S01E02 and (2020) titles automatically.

Transcoding

Picks the right quality — CRF 23/28 with HLS master playlists.

Auth

JWT with Argon2ID, up to 5 profiles, PINs, and rating filters.

Live TV

DVR + EPG guide integration with scheduled recordings.

Phlix Hub

Reverse-tunnel relay — reach your server from anywhere.

Why Roll with Phlix?

  • 100% self-hostable — your library never leaves your hardware unless you say so
  • Native clients on Roku, Samsung Tizen, Windows, Mobile, plus any DLNA device
  • Real-time SyncPlay with NTP-style time sync so movie night actually stays in sync
  • Multi-source metadata: TMDB, TVDB, Fanart.tv, and local NFO with 24-hour cache
  • Adaptive HLS streaming, FFmpeg transcoding, per-device quality profiles
  • Live TV with DVR + EPG guide integration
  • Plugin system with a versioned manifest contract

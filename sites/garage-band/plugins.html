Plugins

Drop a plugin in, the loader picks it up. LifecycleInterface + manifest schema make it official.

Plugin System with a Real Contract

Implement LifecycleInterface, ship a manifest, drop it in the plugins directory. The loader validates the manifest schema and your plugin is good to go.

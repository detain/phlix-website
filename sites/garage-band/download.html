Install Phlix

One line. Fresh Ubuntu or Debian. Full stack including PHP 8.3+, MySQL, FFmpeg, and Let's Encrypt.

One-Line Install

Run on a fresh Ubuntu or Debian host. Installs system packages, creates a dedicated system user, sets up MySQL, generates secrets, runs migrations, and configures systemd + HAProxy with auto-renewing Let's Encrypt.

Install — one line, on Ubuntu or Debian

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

Prompts for install path and database credentials when run in a terminal. Runs fully unattended when piped or given -y. Default ports: HTTP on :8096 behind HAProxy on :80/:443, DLNA discovery on 1900/udp.

Provision HTTPS in the Same Run

With domain and email

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh \ | sudo bash -s -- --domain phlix.example.com --admin-email you@example.com

Requirements

PHP 8.3+, MySQL, FFmpeg. The installer also compiles the Swoole and php-uv extensions from source, skipping the build when they already load.

Build from Source

Development checkout only. Does not create a database, a service, or run migrations.

Development checkout (not an install)

git clone https://github.com/detain/phlix-server.git cd phlix-server composer install

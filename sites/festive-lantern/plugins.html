Plugins

A real contract, not a suggestion

Phlix's plugin system is built on LifecycleInterface + manifest schema. Drop a plugin in, the loader picks it up. See phlix-plugin-example for the smallest working starter.

How plugins work

The contract

Every plugin implements LifecycleInterface and ships a manifest.json. The loader reads the manifest, validates the contract, and registers the plugin's hooks.

Plugins live in the plugins/ directory. Add one, restart the server — it lights up like a lantern at a festival.

The manifest

{ "name": "my-metadata-provider", "version": "1.0.0", "lifecycle": "IMetadataProvider", "hooks": ["metadata.resolve"] }

Getting started

See phlix-plugin-example for the reference implementation — a minimal working metadata-provider plugin you can fork and adapt.

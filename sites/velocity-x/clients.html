The Support Crew

The Crew

Every platform that carries the Velocity X flag. From the living room big screen to the phone in your pocket — all of them, locked in.

Roku

Living Room Main

The most popular crew member. Direct channel install from the Roku store — no sideloading, no tricks. Full hardware transcoding, 4K HDR, Dolby Audio.

Apple TV

HD / 4K Elite

Native tvOS app with AirPlay support. The premium viewing experience — buttery smooth playback, system integration, and the remote that actually works.

Android TV

Google Ecosystem

Sony, NVIDIA Shield, Chromecast with Google TV — the full Android TV experience with Google Cast built in and voice search on the remote.

iOS

Mobile Lead

iPhone and iPad native app. Offline downloads for travel, CarPlay for the commute, and the same SyncPlay power in your pocket.

Windows

Desktop Driver

Full Windows desktop app with hardware acceleration, subtitle download, and full-featured library management. The home theater PC anchor.

macOS

Mac Elite

Native macOS app with Apple Silicon optimization. Retina display support, system media keys, and AirPlay to every device in the house.

Linux

Self-Hosted Core

The server backbone. Runs on Ubuntu, Debian, Fedora, Arch — anywhere with a terminal. The engine that never sleeps.

Web

Zero Install

Every browser, every OS. No install required — just open a URL and you are on the board. PWA support for offline-capable bookmarking.

DLNA / Chromecast

Any device that supports DLNA or Chromecast can receive a stream from your Phlix server — no app required. Smart TVs, game consoles, and casting speakers are all on the crew.

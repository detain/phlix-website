Plugins

Grow your own features — Phlix's plugin system has a real contract, not a hope and a prayer.

Plugin Model

Implement LifecycleInterface, ship a manifest, drop the plugin in plugins/. The loader picks it up on the next startup — no config files to edit, no daemons to restart.

// manifest.json { "name": "my-metadata-provider", "version": "1.0.0", "entry": "MyPlugin.php", "lifecycle": "metadata-provider" }

See phlix-plugin-example for the smallest working starter.

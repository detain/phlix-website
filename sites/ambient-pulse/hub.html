Phlix Hub

Sign in once. Reach any of your servers from anywhere.

What the Hub does

The Phlix Hub is a cloud directory and reverse-tunnel relay. It solves the NAT traversal problem: when your server is behind a home router with no port forwarding, the Hub connects your clients to it through a persistent outbound tunnel.

Your Server

Runs on your LAN, no ports open

Hub Tunnel

Reverse tunnel handles NAT

Your Client

Connects from anywhere

Self-host or use the public hub

The public Hub at hub.phlix.app is free for personal use. If you need more control, the Hub is open-source and self-hostable — run it on any VPS with a public IP.

  • phlix-hub Cloud directory + reverse-tunnel relay GitHub

Hub mode in clients

Enable Hub mode in any Phlix client to connect through the Hub instead of directly to your LAN server. Perfect for:

  • Streaming from your home server while at a friend's house
  • Managing multiple servers from a single mobile app
  • Sharing access with family members without VPN configuration

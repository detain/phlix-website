Plugins

Extend Phlix with a real versioned contract — not a hack, not an afterthought.

Plugin Model

Every plugin implements LifecycleInterface and ships a manifest.json. Drop it in the plugins/ directory and the loader picks it up on restart.

1. Implement LifecycleInterface
2. Write manifest.json
3. Drop in plugins/
4. Server restart
manifest.json 
{
  "name": "my-metadata-provider",
  "version": "1.0.0",
  "entry": "MyPlugin.php",
  "api_version": "1.0"
}

Plugins

Extend Phlix with a versioned plugin contract. LifecycleInterface + manifest schema — drop a plugin in, the loader picks it up.

Plugin Model

Every plugin implements LifecycleInterface and ships a manifest.json. The loader reads the manifest, checks the version constraint, and calls your lifecycle methods in order.

manifest.json
{ "name": "my-metadata-provider", "version": "1.0.0", "phlix_version": ">=4.0.0", "entry": "MyPlugin.php", "type": "metadata" }

Place your plugin in plugins/ and Phlix will discover it on the next startup.

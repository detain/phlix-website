Plugins

Extend Phlix with a versioned plugin contract — drop in, the loader picks it up.

Plugin model

What you need

  • Implement LifecycleInterface
  • Provide a manifest.json
  • Drop into plugins/

Plugins can add metadata providers, storage backends, or stream sources. The versioned manifest contract means plugins you write today will work with future Phlix versions — and the loader tells you if there's a version mismatch.

Plugins are loaded at server startup and can hook into the scanner, the metadata pipeline, and the playback pipeline. See the reference implementation for the full picture.

Ecosystem plugins

The plugin ecosystem is growing. Check the GitHub org for community-contributed plugins, or browse the docs for what's possible.

Write your own

Start with the reference plugin — it's a working metadata provider you can use as a template.

Reference plugin

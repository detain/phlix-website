About Phlix

Self-hosted media streaming, built in PHP, designed to stay out of your way.

Philosophy

Phlix exists because streaming your own media shouldn't require a subscription, a third-party cloud, or yet another account. Your library lives on your hardware — that's where it should stay.

The server is built in PHP 8.3+ on Workerman, which means it runs on the same hosting you'd use for a web app. No special infrastructure, no Docker required, no Java runtime to maintain. If your host supports PHP, Phlix runs.

Clients come first: if your device supports direct play, Phlix serves the file as-is. When it needs to transcode, it picks the right profile for your device and produces an HLS stream that works across platforms.

Contributing

Phlix is developed in the open. Bug reports, feature requests, and pull requests are welcome. The GitHub org is detain.

If you're looking to contribute:

  • Check the issue tracker for open bugs and feature requests
  • Read the docs to understand the architecture
  • Fork a repo, make your change, open a PR — contributions are reviewed promptly

The plugin ecosystem is a good place to start if you want to extend Phlix without touching the core: write a plugin, get it working, and share it with other users.

FAQ

Is Phlix like Plex / Jellyfin / Emby?
Yes — same job, different stack. Phlix is built in PHP 8.3+ on Workerman, ships with a versioned plugin contract, and includes a hub for accessing remote servers behind NAT without a third-party tunnel.
Do I need to expose my server to the internet?
No. Run Phlix on your LAN and use the Phlix Hub's reverse-tunnel relay to reach it from your phone or Roku at a friend's house. You can self-host the hub, or use the public one.
What formats are supported?
Anything FFmpeg can read. Direct play when the client supports it; transcoded HLS otherwise. Per-device quality profiles pick the right bitrate automatically.
Is there a mobile app?
Yes — React Native, available on iOS and Android. Currently in beta.
Can I write plugins?
Yes. Implement LifecycleInterface, ship a manifest, drop it in the plugins directory. See phlix-plugin-example for the smallest working starter.

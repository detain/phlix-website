Plugins

Extend Phlix with a versioned plugin contract. Drop in, the loader picks it up.

Plugin Model

Phlix plugins implement LifecycleInterface and ship a manifest. Drop your plugin into the plugins/ directory and the loader discovers it automatically.

The manifest defines plugin metadata, dependencies, and the lifecycle hooks to implement. This gives you a clear contract for version compatibility and upgrade paths.

See phlix-plugin-example for the smallest working starter — a reference metadata-provider plugin you can build from.

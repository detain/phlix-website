Phlix Hub

Access your server from anywhere. No port forwarding. No third-party tunnel.

What the Hub does

Phlix Hub is a cloud directory and reverse-tunnel relay. When your server registers with the Hub, it opens an outbound connection that stays open. Your clients connect to the Hub instead of your LAN, and the Hub routes traffic through the persistent tunnel to your server.

No port forwarding required

Your server makes an outbound connection to the Hub — it never opens an inbound port. This means no NAT traversal headaches, no router configuration, and no exposure of your server to the public internet.

Self-host or use the public hub

The Hub is fully self-hostable — run it on your own VPS and you control the directory. Or use the public Hub at hub.phlix.dev and skip the hosting overhead entirely.

Hub mode in clients

The Roku, Windows, and Mobile clients support Hub mode — add your Hub URL once, and all your registered servers appear in the client. Pick which server to stream from, even when you're on a different network.

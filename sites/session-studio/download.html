Download

Get the server running in minutes. Then choose your clients.

Server

PHP 8.3+, MySQL, FFmpeg required. The installer targets a fresh Ubuntu/Debian host.

One line, on a fresh Ubuntu or Debian host

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

The installer sets up system packages, creates a dedicated phlix system user, a MySQL database and user, an env file at /etc/phlix/env, runs database migrations, installs a systemd service, and sets up HAProxy with Let's Encrypt.

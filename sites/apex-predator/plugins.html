Plugins

A versioned contract. A manifest schema. Your predator instincts, unleashed.

The Contract

Plugin Model

Implement LifecycleInterface, ship a manifest, drop it in the plugins directory. The loader picks it up on the next restart. No config editing, no ceremony.

Minimal plugin manifest (manifest.json)
{ "name": "my-metadata-provider", "version": "1.0.0", "api": "1.0", "entry": "MyPlugin.php", "description": "Fetches metadata from MyProvider" }
LifecycleInterface contract
interface LifecycleInterface { public function onEnable(): void; public function onDisable(): void; public function onUpdate(string $fromVersion): void; }

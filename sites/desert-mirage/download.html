Download

Phlix Server + four native clients + DLNA. One install command.

Phlix Server

PHP 8.3+, MySQL, FFmpeg. Runs on any fresh Ubuntu or Debian host. 

curl -fsSL https://raw.githubusercontent.com/detain/phlix-server/master/scripts/install.sh | sudo bash

Installs system packages, creates database, sets up systemd service, provisions Let's Encrypt certificate via HAProxy.

Ecosystem

    Cloud directory + reverse-tunnel relay

    Shared interfaces, DTOs, event types — Composer package

    End-user, developer, and hub-admin docs (VitePress)

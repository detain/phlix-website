About Phlix

Open-source media, on your terms.

Philosophy

Phlix was built around a single conviction: your media library belongs on your hardware, under your control, forever. The moment a streaming service changes its terms, loses a license, or hikes its price, you feel it. Phlix gives you a server that runs on your own machine, streams to every screen you own, and never asks permission.

We chose PHP and Workerman because they are universally available, easy to host, and well-understood by the millions of developers who already have PHP skills. Phlix is not a toy — it is a serious media server with SyncPlay, live TV, transcoding, and a plugin system that can grow with your needs.

The Hub exists because not everyone can run a port-forwarding configuration on their home router. It is an opt-in relay — if you don't want it, you don't need it. But if you've ever wanted to check on your library from a friend's house, the Hub makes it work without any network configuration.

License

Phlix Server and the Hub are MPL-2.0 — open source, and you can build on them commercially. If you modify a Phlix file, that file stays open; anything you add alongside it is yours. The shared libraries, plugins, and clients are MIT so you can build on them freely.

This is a real open-source license, not an "open-core" split. The code that runs your server is the same code that is on GitHub.

Contributing

Phlix is developed in the open at GitHub. Issues, pull requests, and plugin submissions are welcome. The server, hub, all four clients, and the shared library are in the detain org — browse the repos and find something that needs attention.

The plugin system is designed to be the primary extension point: if you want a feature, write a plugin first. If it proves widely useful, we can discuss merging it into the core.

Frequently asked questions

Is Phlix like Plex / Jellyfin / Emby?

Yes — same job, different stack. Phlix is built in PHP 8.3+ on Workerman, ships with a versioned plugin contract, and includes a hub for accessing remote servers behind NAT without a third-party tunnel.

Do I need to expose my server to the internet?

No. Run Phlix on your LAN and use the Phlix Hub's reverse-tunnel relay to reach it from your phone or Roku at a friend's house. You can self-host the hub, or use the public one.

What formats are supported?

Anything FFmpeg can read. Direct play when the client supports it; transcoded HLS otherwise. Per-device quality profiles pick the right bitrate automatically.

Is there a mobile app?

Yes — React Native, available on iOS and Android. Currently in beta.

Can I write plugins?

Yes. Implement LifecycleInterface, ship a manifest, drop it in the plugins directory. See phlix-plugin-example for the smallest working starter.

What's the license?

Ready to get started?

## Minimalist Cinema V2 — Bold Typography Edition

**Personality**: Modern, Confident, Editorial, Tech-forward, Typography-obsessed

### Brand Colors
| Token | Hex | Usage |
|-------|-----|-------|
| Deep Navy | #1A1A2E | Primary backgrounds, hero |
| Off-White | #F5F5F5 | Backgrounds, text on dark |
| Cinema Red | #E63946 | Accents, dividers, CTAs |
| Text | #2B2D42 | Body text |
| Muted | #8D99AE | Secondary text, borders |

### Typography
- **Headlines**: Cormorant Garamond (700) — dramatic serif
- **Body**: Karla (400/500/700) — clean sans-serif
- **Scale**: clamp(2.5rem, 6vw, 5rem) for h1, generous line-height 1.1

### UI Style — Bold Typography Edition
- Bold typography scale with large headlines (clamp 3-6rem)
- Magazine editorial feel with generous line-height
- Cinema red used as section dividers, not button fills
- Text-only cards with left border accent (no icon boxes)
- More breathable spacing than -1, but still editorial density

### Key Differences from -1
1. **Layout**: Full-bleed dark hero (vs centered light hero)
2. **Typography**: Larger headlines, serif display font
3. **Cards**: Text-only with red left border (vs icon boxes)
4. **Accent**: Red as section dividers (vs blue as CTAs)
5. **Pitch section**: Off-white with red top border (vs soft blue bg)

### Voice
Direct, clear, slightly theatrical — matches base brand voice.

About

The story behind Phlix.

Why Phlix?

Phlix started because the media server options out there either lock you into a vendor, require heavy infrastructure, or can't handle the weird edge cases that come with a real media library — not just a handful of well-organized movies.

The goal is simple: self-hostable, open-source, and it just works. PHP because it's everywhere and the barrier to contribution is low. Native clients because web UIs feel clunky on a couch.

Project

  • phlix-server — The core media server (PHP 8.3+, Workerman 5.x)
  • phlix-hub — Cloud relay and device directory
  • phlix-website — This marketing site

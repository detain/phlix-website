Key Topics

Installation
PHP 8.3+ required. Clone phlix-server, run composer install, configure your media directories, and start the server.
Configuration
All configuration via config.json. Set library paths, enable plugins, configure auth and networking.
Plugins
Drop plugins into the plugins/ directory. Each needs a manifest.json and must implement LifecycleInterface.
Hub
Self-host the hub for remote access without opening ports, or use the public relay maintained by the project.

Everything you need to know about running Phlix.

Getting Started

Installation
Clone the repository, configure your web server to point to the public/ directory, create the database, and run the setup wizard.
Configuration
All settings are in config/app.json. Most settings can be changed from the admin interface without touching the file directly.
First run
Add your media directories, wait for the scanner to run, and your library will be ready. The scanner runs on a schedule or can be triggered manually.

API Reference

Phlix exposes a RESTful JSON API at /api/v1/. All endpoints require authentication via JWT Bearer token unless otherwise noted.

Troubleshooting

Media not appearing
Check the scanner logs for errors. Ensure file permissions allow the web server to read your media directories.
Transcoding not working
Verify FFmpeg is installed and in your PATH. Check the quality profiles are configured correctly for your hardware.
SyncPlay not syncing
Ensure all clients have UDP port 17888 open. Check that NTP time sync is working on all devices.

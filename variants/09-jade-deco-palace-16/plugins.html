Plugins

Extend Phlix with a modular plugin system.

How plugins work

Phlix uses a versioned manifest contract (plugin.json) to load and manage plugins. Each plugin implements one or more lifecycle interfaces that Phlix calls at appropriate times during execution.

Plugin types

Auth plugins

Add custom authentication methods: OAuth, LDAP, 2FA, or integrate with existing identity providers.

Metadata plugins

Fetch metadata from additional sources beyond the built-in TMDB, TVDB, and Fanart.tv support.

Transcoding plugins

Add custom transcoding profiles or integrate hardware encoders for specific devices.

Index plugins

Index additional media formats or integrate with external media libraries and cloud storage.

Create your own

Start with the phlix-plugin-example repository to learn the plugin structure. The manifest schema, lifecycle interfaces, and event system are all documented there.

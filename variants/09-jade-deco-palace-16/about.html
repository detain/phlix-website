About

Open-source media streaming, on your terms.

What is Phlix?

Phlix is a self-hostable PHP media server that puts you in control of your media library. No subscriptions, no data harvesting, no mandatory cloud dependency. Your server, your media, your rules.

The project started because existing solutions were either too complex, too locked in, or required proprietary clients. Phlix aims to be the media server that respects your freedom while delivering a polished experience on every device you own.

License

Phlix is released under the BSD-3-Clause license. You can use it personally or commercially, modify it, and redistribute it as long as you preserve the copyright notice.

Author

Phlix is developed and maintained by Joe Huss. The project began in 2019 and continues to evolve based on user feedback and contributions from the open-source community.

Contributing

Contributions are welcome. Whether you find a bug, want to improve documentation, or have a feature request, open an issue or pull request on GitHub. The project follows a plugin-first architecture — if you need custom behavior, build a plugin rather than modifying core.

Acknowledgments

Phlix stands on the shoulders of giants: FFmpeg for transcoding, TMDB and TVDB for metadata, and the open-source community for the libraries that make this project possible.

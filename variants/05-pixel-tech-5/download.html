Requirements

Server

PHP 8.3 or higher, Workerman 5.x, FFmpeg, and a Unix-like operating system. Works great on a Raspberry Pi, old laptop, or dedicated home server.

Clients

Each client has its own requirements. Roku requires a Roku device, Samsung Tizen requires a 2016+ Samsung Smart TV, Windows requires Windows 10+, and mobile requires iOS 14+ or Android 10+.

Open source. Zero compromise.

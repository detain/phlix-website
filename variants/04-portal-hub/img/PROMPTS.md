# SVG Prompts — Portal / Hub Icon (Concept 4)

This directory contains the visual prompts for the Portal / Hub Icon variant (04-portal-hub).

## Brand Source
- Source: `/home/sites/phlix/phlix-server/docs/brand/svg_prompts.md` — Concept 4 section

## Primary Logo Prompt

```
Design a modern vector logo for "Phlix" featuring a circular portal icon to the
left of the wordmark. The portal should be a smooth gradient ring with a clean
play button in the center. Use a sleek lowercase font for "phlix". Emphasize
simplicity, symmetry, and a futuristic streaming-platform aesthetic. Flat vector
shapes with soft gradients inside the ring only.
```

**Color palette:**
- Neon Cyan: #00E5FF
- Midnight Blue: #0A0F1F
- White: #FFFFFF

**Optional style modifiers:**
- "futuristic UI icon"
- "glowing ring"
- "minimalist streaming app logo"

## Variations

### A. Tagline-Integrated Logo Prompt
```
Modern vector logo for "Phlix" with the tagline "Stream Everything".
Circular gradient portal icon to the left, play button in center.
Sleek lowercase wordmark. Tagline below in thin sans-serif.
```

### B. Color-Only Version
```
Vector logo using only Neon Cyan (#00E5FF), Midnight Blue (#0A0F1F), and White.
Circular portal icon with play button. Flat shapes except for ring gradient.
```

### C. Monochrome Version
```
Black-and-white portal icon logo for "Phlix". Circular ring and play button.
No gradients, pure vector lines.
```

### D. App Icon Version
```
Rounded square app icon with glowing circular ring and play button.
Neon Cyan on dark blue background. Minimalist vector style.
```

### E. Mascot Version
```
Create a friendly portal mascot shaped like a glowing ring with eyes and a smile.
The play button floats inside like a heart. Vector cartoon style.
```

## Usage
These prompts can be used with Midjourney, DALL·E, Stable Diffusion, or similar
image generation tools to create consistent visual assets for the Portal Hub variant.

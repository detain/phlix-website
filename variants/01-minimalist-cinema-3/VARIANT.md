# Variant: 01-minimalist-cinema-3 — Dark Mode

## Brand Identity

**Name:** Minimalist Cinema V3 — Dark Mode
**Personality:** Dark, Cinematic, Premium, Minimal
**Tagline:** "Your media. Your way."

## Design Decisions

### Color Palette
- **Primary Background:** #0A0A0F (near-black)
- **Secondary/Text:** #FAFAF8 (warm white)
- **Accent:** #E63946 (cinema red, used sparingly)
- **Muted Text:** #6B6B73

### Typography
- **Display Font:** Bebas Neue (self-hosted, uppercase headings)
- **Body Font:** Work Sans (self-hosted, body text)
- **Style:** Cinematic, bold, uppercase headings with letter-spacing

### Visual Motifs
- Film-strip inspired X logo with sprocket holes
- Dark surfaces with subtle borders
- Red accent on hover states and active elements
- Gradient backgrounds for hero sections (dark to slightly lighter)

### UI Characteristics
- Dark mode throughout
- Minimal use of color (mostly grayscale + single red accent)
- Subtle shadows and surface layering
- Uppercase headings with letter-spacing
- Restrained, cinematic feel

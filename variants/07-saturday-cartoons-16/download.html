Self-host your media in minutes. Server on your hardware, clients on your devices.

Server Installation

Install the Phlix Server

Requires PHP 8.2+, MySQL 8.0+, and FFmpeg. Run this command to create a new Phlix installation:

composer create-project detain/phlix-server

Then configure your media paths, database connection, and you're ready to stream. See the documentation for full setup instructions.

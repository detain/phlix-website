Hub

Access your media server from anywhere using a secure reverse-tunnel relay.

What is the Hub?

Reverse-Tunnel Relay

The Phlix Hub solves the NAT traversal problem. Your home server sits behind a router without a public IP. The Hub creates an outbound tunnel from your server to a relay, so clients can reach it from anywhere without configuring port forwarding.

NAT Traversal Made Simple

No port forwarding. No dynamic DNS. No paying for static IPs. Your server initiates a persistent WebSocket connection to the Hub relay. When you open the Phlix client from anywhere, it connects through the same relay and streams your library seamlessly.

Deployment Options

Self-Host the Hub

Run your own Hub relay server on a VPS, Cloudflare Tunnel, or any public-facing host. Deploy with Docker or bare metal. Full control over connections, logging, and scaling.

The Hub server is open-source at github.com/detain/phlix-hub.

Use the Public Hub

The Phlix project runs a free public Hub relay. Connect your server to it with a single configuration change. No setup, no server maintenance — just stream from anywhere.

How It Works

1. Server connects out

Your Phlix server opens an outbound WebSocket to the Hub relay and keeps it alive with heartbeats.

2. Client connects in

When you open the Phlix client from outside your home, it connects to the same Hub relay.

3. Relay proxies traffic

The Hub relays commands and streams between your server and client without storing any data.

Plugins

Extend Phlix with custom plugins for metadata, channels, transcoding, and more.

Plugin Architecture

LifecycleInterface

Every Phlix plugin implements the LifecycleInterface, which provides a versioned contract for installation, activation, and initialization. This ensures plugins work correctly across Phlix updates.

Manifest System

Each plugin ships with a manifest.json that declares its version, dependencies, service bindings, and lifecycle hooks. Phlix reads this manifest during bootstrap to wire up your plugin automatically.

Service Hooks

Plugins can hook into metadata fetching, transcoding pipelines, channel sources, authentication, and more. Services are registered via the manifest and injected where needed.

Getting Started

phlix-plugin-example

Start building your first plugin with the official example repository. It demonstrates a minimal plugin with LifecycleInterface implementation, manifest.json, service bindings, and tests.

Plugin Capabilities

Metadata Sources

Add custom metadata fetchers for movies, TV shows, music, or any content type. Override or extend TMDB, TVDB, and Fanart.tv data.

Channel Sources

Build live TV channel integrations for IPTV services, antenna tuners, or streaming platforms. Users browse channels as if they were broadcast.

Transcoding

Add custom transcoding profiles, codecs, or delivery methods. Plug into the FFmpeg pipeline or provide entirely new streaming formats.

Authentication

Implement custom auth providers for SSO, OIDC, or institutional identity systems. Extend the JWT-based auth flow with your own user management.

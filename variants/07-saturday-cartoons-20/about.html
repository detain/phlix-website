About

Open-source media server software, built by developers, for developers.

What is Phlix?

Phlix is a self-hostable media server written in PHP 8.3+. It streams video and audio to a range of clients — Roku, Samsung TVs, Windows, mobile — with features like SyncPlay, live TV, DVR, and a plugin system.

Ecosystem

  • phlix-server — The media server itself — PHP 8.3+, Workerman 5.x
  • phlix-hub — Cloud directory + reverse-tunnel relay
  • phlix-shared — Shared interfaces, DTOs, event types — Composer package
  • phlix-docs — User and developer docs — VitePress
  • phlix-plugin-example — Reference metadata-provider plugin

Contributing

Contributions are welcome. Open issues, submit PRs, or just say hi. We don't have a contribution guide yet — the code is simple enough that you can dive right in.

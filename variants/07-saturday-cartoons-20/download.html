Download

Get Phlix running on your server in minutes.

Requirements

  • PHP 8.3 or higher
  • FFmpeg (for transcoding)
  • MySQL 8.0+ or MariaDB 10.5+
  • UNIX-like system (Linux, macOS, BSD)
  • Web server (nginx, Apache, Caddy)

Install via Composer

composer create-project detain/phlix-server

Or grab the release

Head over to the GitHub releases page for pre-packaged archives and installation instructions.

Quick start

# Clone the repo
git clone https://github.com/detain/phlix-server.git

# Install deps
composer install

# Copy and edit config
cp config.example.php config.php

# Run the server
php start.php server:start

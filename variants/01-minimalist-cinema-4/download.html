Get Started

Download Phlix

Self-host your media server on Linux, macOS, or Windows. PHP 8.3+ required.

Linux / macOS

curl -fsSL https://get.phlix.tv | sh

Docker

docker pull phlix/server:latest

Manual Install

composer create-project phlix/server:^2.0

System Requirements

Minimum: PHP 8.3, 2GB RAM, 10GB storage

Recommended: PHP 8.3, 4GB+ RAM, SSD storage, FFmpeg

Remote Access

Phlix Hub

Sign in once. Access any of your servers from anywhere — no port forwarding required.

Cloud Directory

Your servers register with the Hub. Clients discover them automatically — no manual IP configuration.

Reverse Tunnel

Your server initiates an outbound tunnel to the Hub. NAT doesn't matter. Firewalls don't block it.

Self-host or Use Ours

Run the Hub yourself, or use the public instance. Same protocol, same experience, your choice.

How It Works

  • Your Phlix server opens a persistent outbound connection to the Hub
  • When you're away from home, your client connects to the Hub instead
  • The Hub routes traffic through the tunnel your server opened
  • Everyone sees the same library, playback, and SyncPlay state

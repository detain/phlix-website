About

Open-source media, on your terms.

The Story

Phlix started because we wanted a media server that we could truly own. Not a subscription, not a third-party cloud — just software that runs on our own hardware and streams to every screen we own.

Built in PHP 8.3 with Workerman, Phlix combines the familiarity of PHP with modern async performance. The result is a media server that's easy to host, easy to extend, and easy to use.

The Mission

Your media should belong to you. That means:

  • Self-hostable — run it on your own hardware, your data stays local
  • Open source — inspect the code, contribute, or fork it
  • Interoperable — works with DLNA, Roku, Samsung, Windows, and more
  • Extensible — plugin system with a real versioned contract

License

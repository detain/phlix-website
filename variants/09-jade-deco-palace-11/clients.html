Clients

Your library on every screen you own.

Native apps

Roku

Stable

Install from the Roku Channel Store. Supports 4K, HDR, and external subtitle tracks.

  • 4K / HDR
  • External subtitles
  • Live TV + DVR

Samsung TV (Tizen)

Stable

Sideload the Tizen .zip or publish to Samsung's store. Same feature set as Roku.

  • 4K / HDR
  • AirPlay 2
  • Voice remote

Windows

Stable

Standalone .exe. Hardware decoding on Intel and NVIDIA. Pairs with any Phlix server.

  • Hardware decode
  • Offline library
  • SyncPlay

iOS / Android

Beta

React Native. TestFlight for iOS, APK for Android. Background downloads supported.

  • Background sync
  • AirPlay / Cast
  • Offline playback

DLNA / UPnP

Any device that speaks DLNA — smart TVs, game consoles, network media players — works out of the box. No app install required.

Web

The Phlix web interface runs in any modern browser. Progressive Web App install supported for offline access.

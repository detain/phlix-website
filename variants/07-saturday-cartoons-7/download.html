Download

Get Phlix running on your own hardware.

Requirements

Server Requirements

  • PHP 8.3 or higher
  • Workerman 5.x
  • FFmpeg for transcoding
  • MySQL 5.7+ or MariaDB 10.3+
  • Linux, Windows, or macOS

Install

git clone https://github.com/detain/phlix-server.git
cd phlix-server
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve

For detailed setup instructions, see the documentation.

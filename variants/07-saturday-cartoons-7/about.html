What is Phlix?

Phlix is an open-source PHP media server that lets you stream your media library to any device — Roku, Samsung TV, Windows, mobile, or any DLNA device. It includes SyncPlay for synchronized viewing, Live TV with DVR, and a plugin system.

Built with PHP 8.3+ and Workerman, licensed under BSD-3-Clause.

Project

  • phlix-server — The media server itself
  • phlix-hub — Cloud directory + reverse-tunnel relay
  • phlix-shared — Shared interfaces, DTOs, event types
  • phlix-docs — Documentation (VitePress)
  • phlix-roku-client — Roku channel
  • phlix-tizen-client — Samsung Tizen TV app
  • phlix-windows-client — Windows desktop app
  • phlix-mobile-client — iOS + Android app

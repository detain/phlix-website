Plugins

Extend Phlix with a versioned plugin contract.

Plugin System

LifecycleInterface + manifest schema

Implement LifecycleInterface, ship a manifest.json, drop the plugin in the plugins directory. The loader picks it up automatically. Versioned contracts ensure compatibility across updates.

Example Plugin

See phlix-plugin-example for the smallest working starter — a reference metadata provider plugin.

{
"name": "my-metadata-provider",
"version": "1.0.0",
"manifest": "1.0",
"entry": "MyPlugin.php"
}

# SVG Prompts — Concept 3: Retro Film Reel Badge

Source: `/home/sites/phlix/phlix-server/docs/brand/svg_prompts.md`

---

## Primary SVG-style prompt

```
Create a retro badge-style vector logo for "Phlix". Use a circular emblem
containing a stylized vintage film reel with four holes. Place the word "Phlix"
across the center on a horizontal banner. Use bold condensed lettering with
slight curvature to match the badge. Include subtle distressed texture, retro
color palette, and classic cinema vibes. Flat vector shapes with clean outlines.
```

### Color palette
- Retro Red: #C0392B
- Cream: #F5E9D4
- Teal: #1ABC9C
- Black outline: #111111

### Optional style modifiers
- "1950s cinema logo"
- "vintage badge emblem"
- "flat retro vector"

### Variations
- Replace film reel with **clapperboard**
- Add **stars** around the badge
- Use a **curved top text** saying "MEDIA SERVER"

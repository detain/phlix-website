# Fonts Directory

This variant requires self-hosted fonts. Download the following fonts and place them here:

## Required Fonts

### Oxanium (Display / Headlines)
Download from: https://fonts.google.com/specimen/Oxanium
Weights needed: 400, 500, 600, 700
Format: WOFF2

Files needed:
- oxanium-400.woff2
- oxanium-500.woff2
- oxanium-600.woff2
- oxanium-700.woff2

### IBM Plex Sans (Body)
Download from: https://fonts.google.com/specimen/IBM+Plex+Sans
Weights needed: 300, 400, 500, 600
Format: WOFF2

Files needed:
- ibm-plex-sans-300.woff2
- ibm-plex-sans-400.woff2
- ibm-plex-sans-500.woff2
- ibm-plex-sans-600.woff2

### IBM Plex Mono (Code)
Download from: https://fonts.google.com/specimen/IBM+Plex+Mono
Weights needed: 400, 500
Format: WOFF2

Files needed:
- ibm-plex-mono-400.woff2
- ibm-plex-mono-500.woff2

## Alternative: Download from GitHub

Many open-source fonts are available pre-converted on GitHub repositories.
Search for "google-fonts-subset" or similar projects for optimized WOFF2 files.

# Fonts Directory

This variant requires self-hosted fonts. Download the following fonts and place them here:

## Required Fonts

### Bebas Neue (Display / Headlines)
Download from: https://fonts.google.com/specimen/Bebas+Neue
Weights needed: 400
Format: WOFF2

Files needed:
- bebas-neue-400.woff2

### Open Sans (Body)
Download from: https://fonts.google.com/specimen/Open+Sans
Weights needed: 300, 400, 500, 600
Format: WOFF2

Files needed:
- open-sans-300.woff2
- open-sans-400.woff2
- open-sans-500.woff2
- open-sans-600.woff2

### Nunito (UI)
Download from: https://fonts.google.com/specimen/Nunito
Weights needed: 400, 500, 600
Format: WOFF2

Files needed:
- nunito-400.woff2
- nunito-500.woff2
- nunito-600.woff2

### Cousine (Code)
Download from: https://fonts.google.com/specimen/Cousine
Weights needed: 400, 500
Format: WOFF2

Files needed:
- cousine-400.woff2
- cousine-500.woff2

## Alternative: Download from GitHub

Many open-source fonts are available pre-converted on GitHub repositories.
Search for "google-fonts-subset" or similar projects for optimized WOFF2 files.

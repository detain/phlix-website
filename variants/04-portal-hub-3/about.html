About Phlix

Open-source media, on your terms.

> What is Phlix?

Phlix is an open-source media server built in PHP 8.3+ that lets you stream your media library to any device — Roku, Samsung TV, Windows, mobile, or any DLNA-enabled device. It's designed for self-hosting, giving you complete control over your data.

> The Ecosystem

  • phlix-server — The media server itself — PHP 8.3+, Workerman 5.x
  • phlix-hub — Cloud directory + reverse-tunnel relay for remote access
  • phlix-shared — Shared interfaces, DTOs, event types
  • phlix-docs — End-user, developer, and hub-admin docs
  • phlix-plugin-example — Reference metadata-provider plugin

> Why "Phlix"?

The name is a play on "Phoenix" — the project was born from the idea of taking back control of your media after relying on closed-source services. It aims to be lightweight, extensible, and genuinely useful.

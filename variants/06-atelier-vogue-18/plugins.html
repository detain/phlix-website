Plugins

Extend Phlix your way.

Phlix ships a versioned plugin contract so authors can ship with confidence. Drop a plugin into the plugins/ directory, enable it in settings, and it activates — no restart required.

Plugin Types

Metadata providers
Fetch posters, backdrops, plot summaries, cast, and ratings from TMDB, TVDB, Fanart.tv, or any other source you want to wire up.
Download clients
Connect to BitTorrent, Usenet, or direct-URL sources. Queue downloads, monitor progress, and import completed files into your library automatically.
Notification agents
Send alerts to Pushover, Pushbullet, Discord, email, or any webhook endpoint when recordings finish or library updates complete.
Channel scanners
Plug in new EPG sources beyond the built-in XMLTV support. m3u playlists, JSON feeds, and ATSC PSIP tables are all workable targets.

Getting started

phlix-plugin-example is the smallest possible working plugin — copy it, swap the logic, and you have a starting point. The plugin authoring guide covers manifest fields, lifecycle hooks, and publishing to the community registry.

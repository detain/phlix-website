Public Hub

Use the hosted relay at hub.phlix.io. Zero configuration — sign in and your server appears automatically.

  • No server configuration required
  • Managed TLS certificates
  • Hosted and maintained by the project

Self-hosted Hub

Run phlix-hub on your own infrastructure. Full control — your credentials never leave your network.

  • Docker Compose single-command setup
  • Your own TLS certificates
  • Audit and control all relay traffic
  • Same API — clients work with either

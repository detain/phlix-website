# Neon Cyberpunk SVG Prompts — Variant 05-pixel-tech-3

## Brand Identity

**Aesthetic:** Neon Cyberpunk — Deep purple-black backgrounds with hot pink/magenta neon accents, futuristic glow effects

**Color Palette:**
- Primary: #0D0815 (deep purple-black)
- Secondary: #1A1030 (dark purple)
- Accent: #FF2D78 (hot pink/magenta)
- Text: #E8E0F0 (light lavender-white)
- Muted: #6B5B7B (muted purple)

**Typography:**
- Headlines: Orbitron Bold (self-hosted)
- Body: Exo 2 (self-hosted)
- UI: Exo 2

## Primary Prompt

Create a futuristic vector logo for "Phlix" with Neon Cyberpunk aesthetic. The letters "Ph" should have a hot pink (#FF2D78) neon glow effect, transitioning into smooth light text (#E8E0F0) for "lix". Use deep purple-black (#0D0815) background with subtle purple grid texture. Add neon pulse animations on hover. Sharp corners, futuristic feel.

## Variations

### A. Tagline-Integrated Logo
Futuristic vector logo for "Phlix" with tagline "Open source. Zero compromise." Hot pink (#FF2D78) pixelated "Ph" with neon glow, transitioning to smooth "lix". Tagline below in thin tech font with magenta accent.

### B. Color-Only Version
Vector logo using only Neon Cyberpunk palette: #0D0815, #1A1030, #FF2D78, #E8E0F0, #6B5B7B. Hot pink neon glow on "Ph", smooth light text on "lix".

### C. App Icon Version
Square app icon with hot pink "Ph" block with neon glow on deep purple background. Minimalist cyberpunk style.

### D. Animated Logo Version
Add subtle neon pulse animation to the hot pink "Ph" portion, with soft glow emanating from pixels.

## UI Style Notes

### Do
- Use hot pink (#FF2D78) for primary accents and highlights
- Add neon glow effects (box-shadow with pink rgba)
- Keep sharp corners (border-radius: 0)
- Use deep purple-black backgrounds
- Add subtle grid pattern overlays

### Don't
- Use green accents (that's variant 1 terminal)
- Use pastel or muted primary colors
- Add rounded corners
- Use gradients as primary backgrounds

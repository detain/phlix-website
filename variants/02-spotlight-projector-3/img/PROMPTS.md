## Notes for AI Image Generation

1. **Consistency** — All images should maintain the Midnight Gallery aesthetic: ultra-dark, restrained gold, soft lighting
2. **No gradients** — Avoid bright gradients; use subtle radial glows only
3. **Typography** — Use elegant serif fonts when text appears
4. **Negative space** — Let elements breathe; don't crowd
5. **Gold restraint** — Use antique gold sparingly, only for emphasis

## Visual Style Notes

### Color Palette
- Primary Gold: #F5C542 (spotlight gold)
- Deep Black: #000000
- Warm White: #FFF7E6
- Burgundy: #7A1F1F
- Amber Glow: #FFB84D
- Muted Text: #B8B0A0

### Art Deco Design Elements
- **Geometric patterns:** Stepped forms, chevrons, sunburst rays
- **Symmetrical compositions:** Balanced layouts, centered focal points
- **Gold foil accents:** Borders, dividers, and highlights
- **Sharp corners:** No rounded organic shapes
- **Line work:** Thin gold lines as decorative elements
- **Angular frames:** Polygonal and stepped border treatments

### Typography Integration
- Cinzel Bold for headlines (display font)
- Lora Regular for body text (elegant serif)
- Source Sans Pro for UI elements (clean sans-serif)

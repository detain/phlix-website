Self-hosted media server

Your media. Your library. Your Phlix.

An open-source PHP media server that streams to your Roku, Samsung TV, Windows desktop, phone, and any DLNA device — with SyncPlay, Live TV, transcoding, and a hub that follows you anywhere.

Get Phlix Read the docs

Why Phlix?

Everything you need for a self-hosted media experience that actually works.

100% self-hostable

Your library never leaves your hardware unless you say so. No subscriptions, no cloud dependencies.

Native clients

Roku, Samsung Tizen, Windows, Mobile (iOS/Android), plus any DLNA device — no new hardware required.

SyncPlay

Real-time NTP-style time sync keeps every device locked to the same frame. Play, pause, seek — together.

Adaptive transcoding

FFmpeg-powered HLS streaming with per-device quality profiles. The right quality, automatically.

Live TV + DVR

ChannelManager, GuideManager, and Recorder give you scheduled recordings and a guide that doesn't suck.

Plugin system

LifecycleInterface + manifest schema. Drop a plugin in, the loader picks it up. Extensible by design.

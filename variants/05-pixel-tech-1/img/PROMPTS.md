# Image Assets for Phlix Pixel Tech V1

## Design Notes

All assets follow the Terminal Hacker aesthetic:
- Pure black background (#000000)
- Neon green primary (#39FF14)
- Monospace/terminal styling
- Sharp angular elements, no rounded corners

## Assets

### logo.svg
- Triple-bracket geometric mark
- Stacked left-to-right: solid, 70% opacity, 40% opacity
- Creates depth while maintaining terminal simplicity

### favicon.svg
- Same mark as logo.svg, scaled to 32x32

### og.svg
- Open Graph image for social sharing (1200x630)
- Grid pattern background
- Full logo mark + "PHLIX" wordmark
- Tagline: "Engineered for Your Library."
- Terminal prompt decoration

## Typography
- All text uses system monospace fallback stack
- Orbitron Bold for headlines (as defined in brand kit)

## Design Notes

### What Makes This Film Noir:
- **High contrast B&W scheme** with single amber accent
- **Sharp, geometric shapes** - no soft curves
- **Dramatic shadows** via CSS text-shadow and box-shadow
- **Typewriter typography** elements (monospace code font)
- **Minimal color** - almost monochromatic
- **Shadow play animation** (header motif)

### Distinct from -1 (Warm Diner):
- -1 uses cream/red/teal with chrome accents
- -3 uses pure black/white with warm amber only

### Distinct from -2 (Movie Palace):
- -2 uses velvet textures and ornate gold trim
- -3 uses sharp geometric minimalism

Getting Started

Installation
Phlix requires PHP 8.1+, MySQL 8+, and FFmpeg. Clone the repository, copy config.sample.php to config.php, and run the installer.
Configuration
Media directories, quality profiles, user accounts, and network settings are configured through the web admin interface at /admin.
Clients
Download client apps for your devices and point them to your Phlix server URL. The server handles authentication and streaming.

Plugins

Extend Phlix with a versioned plugin system. Drop in, enable, done.

Official Plugins

  • phlix-metadata-tmdb

    TheMovieDB metadata fetching with images, ratings, and credits.

  • phlix-metadata-tvdb

    TheTVDB for TV series metadata with season/episode data.

  • phlix-subtitles-opensubtitles

    Auto-download subtitles from OpenSubtitles.org.

  • phlix-transcode-handbrake

    Hardware-accelerated transcoding using HandBrake.

Build Your Own

The plugin system uses a simple manifest contract. Implement LifecycleInterface and you're good to go.

composer require phlix/plugin-template

See phlix-plugin-example for a complete reference implementation.

What is Phlix Hub?

Phlix Hub is a reverse-tunnel relay service that connects you to your home servers without requiring port forwarding, DDNS, or static IPs. Sign into hub.phlix.io, pick a server, and start streaming.

Features

  • Zero configuration — No router config, no DNS setup
  • End-to-end encryption — Your traffic stays private
  • Self-hostable — Run your own relay if you prefer
  • Free tier — One server, limited bandwidth included

Self-host the Hub

The Hub relay is open source. Deploy it on any VPS to run your own infrastructure.

git clone https://github.com/detain/phlix-hub

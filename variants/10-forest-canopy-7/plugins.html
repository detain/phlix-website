Plugins

Extend Phlix with a versioned plugin contract.

Plugin system

Phlix uses aLifecycleInterface + manifest schema. Drop a plugin folder into the plugins directory, and the loader discovers it on startup. Plugins declare their capabilities in a versioned manifest.

Plugin types

Metadata providers
Fetch poster art, plot summaries, cast info, etc. Default: TMDB, TVDB, Fanart.tv. Swap in your own or add new sources.
Transcoding profiles
Define output quality presets (bitrate, codec, container). QualitySelector picks the right profile for each client.
Auth providers
Alternative authentication backends — local PAM, LDAP, OAuth. Default is Argon2ID JWT with refresh tokens.

Reference plugin

phlix-plugin-example is a documented, annotated reference plugin that implements a metadata provider. Use it as a template to build your own.

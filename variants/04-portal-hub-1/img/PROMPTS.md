# Portal Hub V1 - Image Assets

## Generated Assets

The following assets are manually created SVG files that embody the Clean Tech Minimal aesthetic:

### `logo.svg`
- Portal ring motif with gradient stroke (neon cyan to magenta)
- Concentric rings symbolizing connectivity and streaming
- Portal nodes at cardinal positions
- Resolution: scalable SVG (default viewBox 36x36)
- Aspect: 1:1 (square)

### `og.svg`
- Open Graph image (1200x630)
- Portal ring visualization as hero element
- Phlix wordmark with tagline "Stream Everything."
- Dark midnight blue background with radial glow
- Resolution: 1200x630px
- Aspect: 1.91:1

### `favicon.svg`
- Compact portal ring icon
- Dark background with neon cyan rings
- Magenta accent dot for visual interest
- Resolution: scalable SVG (default viewBox 32x32)
- Aspect: 1:1 (square)

## Design Notes

- All assets use the brand palette: #00E5FF (neon cyan), #FF00C8 (magenta pulse), #0A0F1F (midnight blue)
- Circular/ring motifs throughout per the "Use circular motifs" brand guideline
- Neon used sparingly as accent, not dominant
- No gradients on solid backgrounds per brand do/don't list

## Usage

These assets should be used consistently across all pages:
- `logo.svg` in header navigation
- `og.svg` as Open Graph sharing image
- `favicon.svg` as browser tab icon

# Concept 5: Pixel-Tech Hybrid — SVG Prompts

## Primary Prompt

Create a futuristic vector logo for "Phlix". The letters "Ph" should begin as pixelated blocks or digital squares, gradually transitioning into smooth, clean letters for "lix". This symbolizes transcoding and digital media processing. Use neon accents, sharp edges, and a tech-forward aesthetic. Flat vector style with no gradients except optional glow effects.

## Color Palette
- Neon Green: #39FF14
- Black: #000000
- Silver: #C0C0C0

## Optional Style Modifiers
- "digital glitch aesthetic"
- "pixel-to-vector transition"
- "cyberpunk minimalism"

## Variations

### A. Tagline-Integrated Logo Prompt
Futuristic vector logo for "Phlix" with the tagline "Engineered for Your Library". Letters "Ph" begin pixelated and transition into smooth letters for "lix". Tagline below in a thin tech font. Neon accents, digital aesthetic.

### B. Color-Only Version
Vector logo using only Neon Green (#39FF14), Black (#000000), and Silver (#C0C0C0). Pixel-to-smooth transition effect on "Phlix".

### C. Monochrome Version
Black-and-white pixel-transition logo for "Phlix". "Ph" pixelated, "lix" smooth. Flat shapes, no gradients.

### D. App Icon Version
Square app icon with pixelated "Ph" transitioning into smooth "lix". Neon green on black background. Futuristic vector style.

### E. Mascot Version
Create a pixel robot mascot that transitions from blocky pixels on the left to smooth vector curves on the right. The robot holds a sign that says "Phlix". Neon green accents, cyberpunk vector style.

## Dash UI Prompts (Concept 5)

### A. Homepage UI Mockup Prompt
Cyberpunk-inspired homepage UI for "Phlix". Black background, neon green (#39FF14) pixel accents, glitch effects, sharp edges. Pixel-to-smooth transition graphics. Terminal-style category labels, grid overlays, digital noise texture. High-tech vector UI.

### B. App Dashboard Mockup Prompt
Tech dashboard UI for "Phlix". Neon green highlights, black panels, pixel icons, terminal-style typography. Widgets for transcoding, CPU usage, active sessions, and media indexing. Glitch animations, cyberpunk vector layout.

### C. Mobile App UI Prompt
Mobile UI for "Phlix" with neon cyberpunk theme. Pixelated header, neon green buttons, black background, sharp rectangular cards, digital vector style.

### D. Light Mode Variant
White background, soft gray pixel accents, neon green highlights, clean digital-tech vector UI without heavy glitching.

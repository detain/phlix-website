# SVG Prompts for Portal Hub V2 — Glassmorphism Focus

## Overview
This variant features glassmorphism effects with transparent panels, frosted glass, and depth through layering. The visual metaphor shifts from portal ring (V1) to a portal grid motif.

## Logo Prompt
```
A logo for "Phlix" media server brand. Portal/hub icon with glassmorphism aesthetic.

Requirements:
- Portal grid motif instead of solid rings
- Semi-transparent layered glass effect
- Neon cyan (#00D4FF) accents on deep navy (#0A1628) background
- Include portal/play icon and "Phlix" wordmark in Space Grotesk style
- Clean vector, scalable
```

## Visual Motifs
- **Portal Grid**: Concentric circles with grid lines emanating outward
- **Glass Layers**: Multiple semi-transparent layers creating depth
- **Grid Pattern**: Subtle background grid across entire page
- **Glow Effects**: Neon cyan (#00D4FF) used for accent glows

## Color Usage
- Primary: Deep Navy #0A1628
- Secondary: Ice Blue #E8F4FD
- Accent: Neon Cyan #00D4FF
- Text: #0F1C2E
- Muted: #5B7A99

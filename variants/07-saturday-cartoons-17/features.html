Features

Everything you need to stream, organize, and enjoy your media library on your own terms.

Streaming & Playback

  • Adaptive HLS streaming for bandwidth efficiency
  • FFmpeg transcoding to any format or device capability
  • Per-device quality profiles (4K, 1080p, 720p, mobile)
  • Subtitles, audio tracks, and chapter support
  • Resume playback with watch history tracking
  • Proof-of-concept WebUI for browsers

SyncPlay

  • Real-time SyncPlay with NTP-style time synchronization
  • Keep everyone in sync during movie night, even with slow connections
  • Works with all native clients (Roku, Samsung, Windows, Mobile)
  • No cloud server required — peer-to-peer communication

Live TV & DVR

  • Live TV streaming from antenna or cable sources
  • EPG guide integration for program schedules
  • DVR with scheduled and manual recordings
  • Recording management and playback

Media Library

  • Multi-source metadata: TMDB, TVDB, Fanart.tv
  • Local NFO file support with 24-hour cache
  • Automatic library scanning and organization
  • Collections, watchlists, and rating systems

DLNA & Casting

  • Built-in DLNA server for universal device support
  • Chromecast and AirPlay discovery
  • Push streaming to any UPnP/DLNA device

Developer Features

  • Plugin architecture for custom functionality
  • REST API for integrations
  • Webhook support for notifications
  • CLI tools for server management

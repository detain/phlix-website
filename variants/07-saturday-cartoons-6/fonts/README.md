# Fonts Directory

This directory contains self-hosted WOFF2 font files for Saturday Cartoons V6.

## Required Font Files

Download the following fonts in WOFF2 format and place them here:

### Baloo 2 (Headline font)
- baloo-2-400.woff2 (Regular 400)
- baloo-2-700.woff2 (Bold 700)
- baloo-2-800.woff2 (ExtraBold 800)

### Quicksand (Body font)
- quicksand-400.woff2 (Regular 400)
- quicksand-500.woff2 (Medium 500)
- quicksand-700.woff2 (Bold 700)

### Nunito (UI font)
- nunito-400.woff2 (Regular 400)
- nunito-600.woff2 (SemiBold 600)
- nunito-700.woff2 (Bold 700)

### Fira Mono (Code font)
- fira-mono-400.woff2 (Regular 400)
- fira-mono-700.woff2 (Bold 700)

## Sources

You can download these fonts from:
- Google Fonts (https://fonts.google.com) - export as WOFF2
- Or use a font conversion tool to convert from TTF/OTF to WOFF2

The project uses ttf2woff2 as a devDependency if you have the TTF files.
